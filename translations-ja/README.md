# translations-ja — 日本語訳 PDF

0-Sphere Model 論文の**日本語訳 PDF** の置き場。ここに行けば和文の資料がある、という目印の棚。

- **全論文は訳さない。** 著者が必要と思ったときに、思った論文だけ追加する。
- 英語原文が正。訳は読む便宜のためのもので、引用・DOI は原文（Zenodo）を指す。
- 原文の一次資料（main.tex・図版）は `../tex-sources/NN/`。ここには訳の PDF だけを置く。

## 命名

`NNN_vK_ja.pdf` — NNN は論文番号を 3 桁にそろえる（並び順のため）、K は訳した原文の版。
同じ論文の版が上がって訳し直したときは、新しい版を足し、古い版は消す（履歴は git に残る）。
