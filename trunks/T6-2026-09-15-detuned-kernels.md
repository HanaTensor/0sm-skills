## 概要 — この幹は何を問うているのか

この幹が扱うのは、**二核の振動数が揃っていないとき（ω_A ≠ ω_B）に何が変わるか**である。corpus（#9・#50・#68 の O11／O15）が提起しているのは**振動数差**であって振幅差ではなく、この二つを混ぜないことが本幹の一貫した制約である。閉包は振動数比のみで決まり（比が有理数なら閉じ、無理数なら永久に閉じない）、**振幅は外接矩形の縦横比を変えるだけ**である（T6.2）。この系が対応するのはニュートリノで、質量固有状態どうしが離調した二核として読まれる。

本幹の主要な成果は、**#9 に対する三つの訂正と、離調系についての三つの定理**である。第一に、**#9 の式は振幅 1 のままでは運動エネルギーが負になる**（離調すると sup(T_A + T_B) → 2 に漸近するため）。振幅係数を入れて **a² + b² ≤ 1**、等振幅なら **a ≤ 1/√2** を課す必要がある ── これは式そのものの訂正である（T6.4）。第二に、**床 E₀/2 は 1:1 逆位相ロックの帰結であり、離調で消える**（inf → 0）── #9 が仮定として置いていた「相互作用は T_ν1 = T_ν2 = 0 のときに起きる」は、**仮定から定理に昇格した**（T6.5）。第三に、**#9 の希少性の論証は成り立たない** ── 二重零点近傍の滞在率は**比に依らず ε に比例する**（Weyl の一様分布定理）ので、「閉包に時間がかかるから相互作用が稀」は言えない。希少性は結合の小ささから来る（T6.6）。あわせて、うなりの帰属も訂正された ── **寿命ではなく風味振動**である（寿命と読むと 11 桁外れる、T6.7）。

**外部の事実と 0SM の主張を分ける規律がこの幹では特に効く。** 静止系のうなり **2–12 THz** は振動実験の測定値だけで決まり、β も 0SM も使っていない（T6.8）。一方、内部振動子が遠赤外（m₃ で **492 GHz**）に落ちるという主張は **β_ν = 0.0405 の外挿**に乗っており、そこは弱い（T6.9）。宇宙背景ニュートリノは非相対論的である（p/mc = 0.0105、T6.10）。最大の未解決点は **K1**（Δm/m̄ は離調そのものか ── 幹 T2 の T2.4 により「質量固有状態はロック系であってはならない」と読みが一方に絞られた）と **K3**（比ごとの a_max と混合角の対応。#50 が「PMNS を借りるのは循環であり、混合角は ω_A/ω_B から導出されるべきだ」と明記している）である。

## 現在地 — 何が閉じ、何がまだ開いているか

**閉じた問題**：**自由なニュートリノの磁気モーメント μ_ν は 0SM では厳密に零である**（μ = (q/2m)·L で、保護された巻き数が無い系では q = 0。幹 T2 の T2.4 帰結 (3)）── これは本幹が外界と繋がる返済先として期待されていた枝で、**閉じたことで期待の方が撤回された**。残るのは「中性系の μ は二系の交差項としてしか存在しない」という構造の言明で、それは幹 T2 の K5 の領分である。#9 の希少性論証は成り立たない。「振幅差がリサジューを閉じなくさせる」も採らない（閉包は振動数比のみ。振幅の役割は**原因ではなく成立条件**である）。「黄金比は最も近似しにくいので訪問が最も稀」は**逆**で、最も規則的に訪れる（KAM の文脈では標準的な結果）。

**残っている土台**は、振動数差と振幅差の切り分け、閉包条件、振幅上限、床の消失、滞在率の普遍性である。**この範囲は確定しており検算済みで、しかも既発表論文の誤りを正すという明確な役目を持つ** ── #69 の候補として切り出せる形になっている（#66 の Corrections Log が先例）。

**まだ開いている問題**は、**離調を実測の質量差に結びつける一歩**である。**Δm/m̄ は離調か**（K1）、**1/√2 の四度目**（K2）、**比ごとの a_max と混合角**（K3 ── 射程は長いが当たれば大きい）、**リサジュー螺旋の固定端点線積分**（K4 ── #51 付録 (iii) の未解決項目）、**三世代の構成**（K5 ── #9 は三対という案と三状態同時という案を並記して決めていない）。**結合の本体は幹 T5 に移った**（T5.19）が、離調系に固有の部分は K6 に残る。**結合ができるまで論文にしない**のが本幹の方針である。

## 1. 前提 — 読み込んだ一次資料の骨組み

E_ν = E_ν [ cos⁴(ω_ν1 t/2) + sin⁴(ω_ν2 t/2) + K.E. ]

で、K.E. は「二つの引数が違うので ½E_ν sin²(ωt) に簡約できない」と明記される。主張は四つ ──（a）二核は直交・独立で互いの放射を吸収しない、（b）リサジュー曲線が閉じるまで相互作用が起きない、（c）だから相互作用が稀である、（d）閉じるのに時間がかかるから質量が極端に軽い。§5 に「この仮定を裏づける数学的根拠の構築は将来の課題」と記されている。包む boson の候補として W±, Z⁰ を挙げる。seesaw 機構の重い右巻きニュートリノを要求しない点を利点として述べる。

**#50（2026）** 同じ構造を自由度の数え上げから整理する。閉包時間は **2π/|ω_ν1 − ω_ν2|**、比が無理数なら永久に閉じない。**ω_A/ω_B は量子数ではなく軌道の形を決める連続パラメータ**で、スピノルの次元は 4 のまま。位相的分岐として ── ω_A = ω_B は閉測地線・安定粒子・χ が大域的に定義される・自由度 4、ω_A ≠ ω_B は開（リサジュー）測地線・振動する粒子・χ は局所的にのみ・自由度 4 ＋ 形のパラメータ。**PMNS 行列を借りることは方法論的に許されない**（置き換えようとしている枠組みから結論を借りることになる）と明記し、逆に**混合角は ω_ν1/ω_ν2 から導出されるべき**だとして将来課題に置く。

**#51** 付録 (iii) で、螺旋構成は電子（ω_A = ω_B）にのみ適用され、**リサジュー螺旋とその固定端点線積分は未解決**と記帳する。

**#68** O11「二振動数（リサジュー）拡張 ── 安定性起源テーマ（O15）の幾何学的入口」、O15「ω₁ = ω₂ が安定粒子、不等なら不安定または振動する粒子。#9 の二振動数足場を数学的基礎とする」。三つの困難を挙げる ── 異なる振動数の二振動子の束縛の起源、振動数比と異常磁気モーメントの橋、初期足場と現行枠組みの整合。

**#4（2019）** 電子の二重スリットで左右の振幅が等しくないという仮説。重み係数は A_spinor1 = A cos²θ、A_spinor2 = A sin²θ で、**同じ A に相補的な重みが付く形**であり、核固有の振幅非対称ではない。T2.7 が D ≠ 0 として回収済み。

## 2. 確立した命題（T6.1–T6.10）

### T6.1 corpus が提起しているのは振動数差である（旧 T3.1）

#9・#50・#68（O11, O15）はすべて ω_A ≠ ω_B で書かれている。振幅については一語も変えていない。**振幅の不等性を言っているのは #4 で、それは電子の側の話であり、T2.7 の D ≠ 0 として既に回収されている。** corpus の配置は「振幅差は電子の側、振動数差はニュートリノの側」である。記憶がこの二つを融合しやすいので、幹として明記しておく。

### T6.2 リサジュー曲線の閉包は振動数比のみで決まる（旧 T3.2）

x = A cos(ω₁t), y = B sin(ω₂t) の閉包条件は ω₁/ω₂ が有理数であること。**A, B は外接矩形の縦横比を決めるだけで、閉包の条件式に入らない。** 数値確認済み ── 振幅を 7 倍にしても閉包は不変（比 1:1 と 2:3 の両方で検証）。したがって「振幅差がリサジューを閉じなくさせる」という形の主張は成立しない。

### T6.3 振幅差がすること — 規格化を ω で変調する（旧 T3.3）

振動数を共通にして振幅だけ変えると

𝒯_A + 𝒯_B = A cos²(θ/2) + B sin²(θ/2) = **(A+B)/2 + ((A−B)/2)·cos θ**　（残差 厳密に零）

**これはうなり（包絡線）ではなく、振動数 ω そのものでの変調である。周期は変わらない。** 変調の大きさは **(A−B)/2 · D**（D = cos θ）なので、**振幅差は差 D に直結する**。T2.3 の「D の六つの顔」に七つ目を足す形になる。

### T6.4 #9 の式は振幅 1 のままでは運動エネルギーが負になる（要訂正）（旧 T3.4）

#9 の式は K.E. = 1 − cos⁴(ω₁t/2) − sin⁴(ω₂t/2) を意味するので、**K.E. ≥ 0 は sup(T_A + T_B) ≤ 1 を要求する**。ところが離調させると、二つの位相がトーラス上で稠密になるため**いつか必ず両核が同時に最大になり**、sup → 2 となる。振幅 1 のままなら **K.E. = −1**。

**したがって a² + b² ≤ 1、等振幅なら a ≤ 1/√2。** 比ごとの上限（a = b として、許される等振幅 a_max = 1/√sup）──

| ω₁:ω₂ | sup(T_A+T_B) | a_max |
|---|---|---|
| **1:1（逆位相）** | **1.000** | **1.000** |
| 1:2 | 1.286 | 0.882 |
| 1:3 / 3:1 | 1.586 | 0.794 |
| 3:2 | 1.654 | 0.777 |
| 1:4 | 1.740 | 0.758 |
| 5:4 | 1.883 | 0.729 |
| 2:1 / 2:3 / 4:3 | 2.000 | 0.707 |
| **無理数比**（黄金比・√2−1・π/4） | **2.000**（漸近） | **0.7071 = 1/√2** |

> **1:1 の逆位相ロックだけが、核を「満身」のまま保てる唯一の配置である。離調した粒子は必ず軽い。**

これは #9 §4.3 の軽さの論証（「閉じるまで時間がかかるので運動エネルギーのまま長く留まる」）の定量的な置き換えになる。**ただし方向は正しいが桁が足りない** ── 上限は最大でも 30% の減少であって、ニュートリノに要る 10⁷ 倍ではない。また上限を課すだけで値を決めないので、答えているのは「なぜ軽いか」ではなく「なぜ同じ重さにはなれないか」である。

**1/√2 はこれで四度目**である ── #10 の RMS 置換（a → a/√2）、T1.3 の相対揺らぎ std(KE)/⟨KE⟩、T1.12 補の √2、そして本項の「位相ロックを外す代価」。機構の候補として記帳する（→ K3）。

### T6.5 床 E₀/2 は 1:1 逆位相ロックの帰結であり、離調で消える（旧 T3.5）

電子では inf(cos⁴(θ/2) + sin⁴(θ/2)) = **1/2**（θ = π/2、T1.2／T2.2 の床）。離調させると inf → 0 ── 数値で黄金比 1.4×10⁻¹⁴、√2−1 で 1.1×10⁻¹⁴、π/4 で 1.3×10⁻¹⁷。

> **床 E₀/2 は恒等式の性質ではなく、位相ロックの性質である。**

**#9 が「T_ν1 = T_ν2 = 0 となり全エネルギーが運動エネルギーに変わったときに相互作用が起きる」と仮定した瞬間は、床の消失として定理になる。** #9 はこれを仮定として置いていた。

### T6.6 #9 の希少性の論証は成り立たない（要訂正）（旧 T3.6）

#9 §4.1／§5 は「リサジューの閉包に一回の相互作用を割り当てれば、閉包時間が長いことが相互作用の稀少さを説明する」とする。これは成立しない。

二重零点の近傍（T_A + T_B < ε²）の滞在率 ──

| 比 | ε = 0.3 | ε = 0.2 | ε = 0.1 |
|---|---|---|---|
| 黄金比 | 1.246×10⁻¹ | 8.014×10⁻² | 3.876×10⁻² |
| √2 − 1 | 1.246×10⁻¹ | 8.014×10⁻² | 3.876×10⁻² |
| π/4 | 1.246×10⁻¹ | 8.016×10⁻² | 3.873×10⁻² |

**三つの比で三桁まで一致する。** 滞在率は ε に比例し（四乗のため）、**比に依らない** ── Weyl の一様分布定理の要求である。**曲線が閉じないことは、二重零点を稀にしか訪れないことを意味しない。**

比に依るのは**最大待ち時間**のみ（閾値 0.04、同一区間での比較）──

| 比 | 平均間隔 | 最大間隔 |
|---|---|---|
| 黄金比 | 0.06 | **18.3** |
| √2 − 1 | 0.06 | **29.6** |
| π/4 | 0.06 | 23.4 |

**黄金比が最小**である（最も近似しにくい無理数は最も規則的に訪れる）。直感の逆。#9 が「将来の課題」とした数学的根拠はディオファントス近似（三距離定理・連分数）の問題として定式化できるが、**平均率が普遍なので希少性の説明にはならない**。希少性は結合の小ささから来るしかない。

### T6.7 うなりの帰属訂正 — 寿命ではなく風味振動（旧 T3.7）

T2.5 は離調によるうなりの包絡線周期を**粒子の寿命**と同定しようとして 11 桁外れ、支持されないと記帳された（幹 T2 §4）。帰属先を変えると三点が揃う。

1. **うなりは本来コヒーレントな周期現象**である。寿命は非コヒーレントな減衰なので器が違っていた。風味振動はまさに周期的な拍で、うなりが説明すべき対象の形をしている。
2. **T2.5 は「規格化 𝒯_A + 𝒯_B = 1 ⟺ ω_A = ω_B」を証明済み**である。離調した二核系は規格化を周期的に破る、すなわち**定常状態ではない**。そして**風味固有状態はハミルトニアンの固有状態ではない**。同じ形の言明である。
3. **#9 はニュートリノを非対称な振動数（閉じないリサジュー）として置いている。** 非対称＝離調、非閉性＝拍。

これにより **幹 T2 の K4**（2:1 ロックを破る機構、必要な離調 4.4×10⁻¹⁶ の正体）の形が変わる ── 問いは「4.4×10⁻¹⁶ の正体は何か」ではなく「**Δm/m̄ が離調そのものか**」になる。正常順序の m₃ と m₂ なら Δm/m̄ = 0.83 で **order 1 の離調**、準縮退なら小さい離調。突き合わせは未了（→ K1）。

### T6.8 静止系のうなりは 2–12 THz である（0SM に依らない）（旧 T3.8）

質量固有状態どうしの静止系うなり Δmc²/h は、振動実験の測定値だけで決まる。**β も 0SM も使っていない。**

| 組 | Δmc² | ν | λ |
|---|---|---|---|
| m₃ − m₂（正常順序） | 41.6 meV | **10.1 THz** | 29.8 µm |

## 付録A — セッション検証規則（本セッションで増えたもの）

- **非整数冪を扱うときは底が負にならないか確認する。** `cos(θ/2)**(2p)` は θ > π で底が負になり、非整数 p では複素数を返す。占有数の層（𝒯 = cos²(θ/2) ≥ 0）で定義し直すこと。実際に一度この誤りを出した。
- **零点を符号変化の走査で数えるとき、格子点上の零点を取り落とす。** dD/dθ の零点（θ = 0, π）を二度取り落とした。周期境界の零点と、格子点にちょうど乗る零点の両方に注意する。閉形式が得られるなら解析的に数えること。
- **離散性の観察が出たら、それが位相幾何なのか代数なのか解析なのかを分ける。** 本セッションでは三つが同じ顔をしていた（調和性＝代数、臨界点とメビウス＝位相幾何、分解の大域性＝解析）。2026-09-07 の規則（符号や大小の観察が出たら背後の位相幾何か代数を探す）の逆向きの型である。
- **「閉じない」と「稀に訪れる」を混同しない。** 非閉軌道でも一様分布定理により訪問率は普遍である。#9 の希少性論証がこの混同だった。
- **柔らかさのような性質は、利点と欠点を同時に供給していないか確かめる。** 低振動数モードの密度は、低い閾値の理由でもあり熱容量の理由でもあった。

## 付録B — #9 の素材は揃っていたのに、なぜ繋がらなかったか

- **(1) K.E. の非負性が検査されていなかった。** #9 は「K.E. はもう簡約できない」と書いて先に進んだ。簡約できない項は**中身を問われなくなる**。記号が消えた量は検査されない ── 幹 T2 付録A の (1)（差 D に記号がなかった）と同じ型である。
- **(2) 「閉じるのに時間がかかる」が三つの別の主張に使われていた。** 希少性（§4.1, §5）、軽さ（§4.3）、相互作用のタイミング（§4.1）。**一つの直感を三箇所の論証に使うと、どこが弱いかが見えなくなる。** 実際には一つ（タイミング）が定理になり、一つ（軽さ）が置き換わり、一つ（希少性）が成立しなかった。

- **(4) 振動数差と振幅差が「質量差」として一括されていた。** #9 は「ν1 と ν2 に質量差がなければならない」と書き、それを振動数差として実装した。**振幅差という別のつまみがあることは意識されていなかった**（T3.3 の変調、T3.4 の上限）。E = ħω を採れば両者は連動するが、連動することと同一であることは違う。
