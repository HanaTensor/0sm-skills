## 概要 — この幹は何を問うているのか

この幹が扱うのは、**いくらか**である。0SM の内部振動子の速度 **v_ZB = 0.04047c** は、異常磁気モーメントのみから導出された**パラメータフリーの、未測定の第一義的予言**であり、本幹はこの値を既定値として立つ ── **0.04047c が観測された後の世界**で議論する、というのが著者の方針である。この一つの数から、エネルギーが **β の冪で三層に分かれる**（T3.1）。第一層 **511 keV**（mc²、β⁰）、第二層 **20.7 keV**（βmc²、内部線 ν_ZB = 5.00×10¹⁸ Hz）、第三層 **419 eV**（½β²mc²、#46 の床）である。三層はそれぞれ別の顔を持つ ── 第二層は「**角を ½ rad 回すエネルギー**」であり（T3.7）、同時に**内部時計の Brillouin 帯の端**でもある（T3.8）。第三層は**混合の代価** ½β²mc² と一致する（T3.6）。

もう一つの柱が**橋渡し方程式**である。異常磁気モーメントは一つの不変量に二つの表現を持ち（外部 ＝ Penning trap の時間比、内部 ＝ 弧の長さ比）、**γ_L = 1 + a_e がその翻訳子**になる ── Lorentz 変換が時間の遅れと長さの収縮を一つの γ で結ぶのと同型である。ただし**現状これは「関係式」であって「導出」ではない**（T3.4）。一次で **v_ZB/c ≈ √(α/(√2π)) = 0.04053** なので、「**なぜ亜光速か**」は「**なぜ α か**」と同じ問いに帰着する（T3.2）。橋渡しの余剰エネルギーも α で書ける ── (γ−1)_peak mc² = a_e mc² = (α/2π)mc² = **αħc/λ_C = 593.5 eV**（T3.3）。

**そして本幹は、測定された後に何が起きるかまでを扱う。** v_ZB が実測されたとき、それは「隠れた変数が実在する」ことの間接証明ではなく、**変数が形式に編入される**ことである（**T3.12**）── 測定の後、v_ZB はもはや隠れた変数ではない。「隠れた」は場（オイラー）の側の語であって、**平滑化で消える粒子の属性を、場の側がそう呼んでいる**にすぎない。これは `README.md` §0.2 のラグランジュ宣言の直接の帰結であり、**原子・核の大きさ・クォークが辿った唯一の勝ち筋**でもある。ここから枝が二本出る ── **K11**（率の測定か位相の測定か。ハウトスミット＝ウーレンベックの分岐）と **K12**（反証条件の明文化）である。

**バイアス境界がきつい幹である。** 導出に使ったのは **#10 の Eq. (III.9) まで**と **#62 の §2 まで**で、#62 §3 以降（速度レベル RMS、2^(1/4) 残差）は**封印**してある ── 解禁は K2 の仕事である。最大の未解決点は **K4**（橋渡しの次の項。相対次数 α の補正の機構）で、その役割は確定している ── **β_ZB を独立に決めることが、橋渡しを「関係式」から「導出」に上げる唯一の道である。** 次いで **K1**（速度規約。#10 の v = cos ωt を採るか #49 の |v| ∝ sin θ を採るか。**著者判断待ち**で、index §5・#49 の未決課題 (viii)・#66 の C3 と同一問題）と、**K7**（p ≠ 0 のとき混合角 θ₀ は運動量で変わるのか。旧 T5 と旧 T6 に同一の問いが二重に立っていたのを統合した）である。

## 1. 前提 — 読み込んだ一次資料の骨組み

**#10（2023）** Thomas 歳差 Ω = (1/2c²)[a × v] に、等速円運動ではなく単振動 v = cos ωt, a = −sin ωt を代入 → Ω ∝ −½ sin 2ωt（角速度の周期が変位の半分）。回転座標系の Lorentz 収縮（Einstein 1912、自転車の車輪）で 1π の円周が縮み、その縮み分を異常磁気モーメント a = (g−2)/2 と同一視。L/L₀ = 1/(1+a) [III.4] → 「平均速度」を求めるため a を RMS 値 a/√2 に置換 [III.5]（交流電圧の実効値との類推、根拠は保留） → √(1−v²/c²) = 1/(1 + a/√2) [III.7] → β² = 0.00163798087、**v = 0.04047197635c** [III.9]。

**#62 §2（2026）** 異常磁気モーメントは一つの不変量で二つの表現を持つ：外部＝Penning trap の時間比 a_e = T_c/T_a、内部＝弧の長さ比 a_e = (L₀−L)/L₀。**γ_L = 1 + a_e はその翻訳子**（Lorentz 変換が時間の遅れと長さの収縮を一つの γ で結ぶのと同型）。長さ比は v² にしか依らないので非負 → modulus |a| の起源。場非依存性は「整合」であって「証明」ではない（claim boundary）。

**#28** #14 の GR 補正（0.040374c）は G/c² 脱落で 27 桁過大。**0.040472c は SR のみで決まり無傷**。

**#46** TPE = 1 − ½sin²(2θ) ≥ E₀/2（AM–GM、等号 θ = π/4）を ħω/2 の幾何学的対応物と提案。E₀ = ħω = 20.7 keV（ZB 振動数 5.0×10¹⁸ Hz）と同定し、mc² の残り 96% を open と明記。

## 2. 確立した命題（T3.1–T3.12）

### T3.1 亜光速がすべてを決める（三層 β 階層）（旧 T1.4）

β = v_ZB/c = 0.0405 として、エネルギーは β の冪で三層に分かれる。

| 層 | 式 | 値 | 何か |
|---|---|---|---|
| β⁰ | mc² | 511 keV | 動かない質量（床） |
| β¹ | β mc² = h v/λ_C | 20.7 keV | photon sphere の量子（#46 の ħω） |
| β² | ½β² mc² = (γ−1)mc² | 419 eV | 核の反跳の運動エネルギー＝橋渡しの a_e/√2 |

β¹ と β² は独立でない：20.7 keV の光子に質量 m が反跳する運動エネルギー E_γ²/(2mc²) = 418.5 eV は (γ−1)mc² = 419.0 eV と 0.1% で一致。異常磁気モーメントは β² 層に住み、**a = γ − 1 ≈ β²/2 → 0（β → 0）**：v ≪ c なら AMM は生じない（著者の見立て、確認済み）。「mc² の 96% は何か」は問いとして成立せず、答えは**動かない質量**。恒等式が mc² の尺度で適用されないこと（KE_max = mc²/2 なら v = 0.7c で Dirac 領域）が、亜光速の意味そのもの。

### T3.2 「なぜ亜光速か」は「なぜ α か」（旧 T1.11）

一次で v_ZB/c ≈ √(√2 a_e) ≈ **√(α/(√2π)) = 0.04053**（高次込み 0.04047 と 0.15%）。恒等式は形（1/√2 の比）、α は尺度。質量非依存 → **レプトン普遍性**：μ は 0.04058c（電子と 0.27% 差、質量比 207）。ハドロンは |a| で 0.9c 台（p 0.898、n 0.905）——点状／複合の区別が内部速度の二つの島として現れる。「電子に内部構造がある」の内実は**エネルギー分配の構造であって電荷分布の構造ではない**（形状因子上限 < 10⁻¹⁸ m と λ_C = 2.4×10⁻¹² m の両立）。Dirac の v = c を覆すのではなく**振幅と振動数の割り当て**を覆す（Dirac：振動数 2mc²/ħ を固定し振幅 λ̄_C/2；0SM：振幅 λ_C を固定し振動数を 0.04 倍）。内部線は 10–20 keV。

### T3.3 一つの恒等式（旧 T1.12）

(γ−1)_peak mc² = a_e mc² = (α/2π)mc² = **αħc/λ_C = 593.5 eV**：橋渡しの余剰エネルギーは、電荷 e 二つを λ_C 離した静電エネルギーに一次で厳密に一致（λ_C = 2πħ/mc、Schwinger の 2π と Compton の 2π が同じ 2π）。二核間距離 λ_C（#1/#10）と合わせ「γ−1 は二核間の Coulomb 的結合エネルギー」という読みが浮上。機構は後（#28 の作法）。**補（2026-09-14）** ── 幹 T2 の T2.13 により電荷は核に局在しない巻き数なので、「電荷 e 二つを λ_C 離した」という読みは**採らない**。数値の一致 αħc/λ_C = (γ−1)_peak mc² は無傷で、読みは「**α × 搬送体のエネルギー尺度 ħc/λ_C**」── 結合定数 α が構成関係 ⋆ の側から入る唯一の場所（幹 T2 の K12）。K8 と一緒に扱う。

### T3.4 橋渡し方程式の機構（2026-09-07）（旧 T1.12 補）

現状の T1.12 は γ_v = 1 + |a|/√2 という**関係式**である。ここに機構を付ける。

**思考実験** ── 搬送体（光子球）の共動系で電子を観測すれば、異常磁気モーメントは現れず **g = 2 が厳密に成り立つ**のではないか。数値では β_ZB = 0.040472 → γ − 1 = 8.19999×10⁻⁴ → **√2(γ−1) = 1.15965355×10⁻³**、a_e（実測） = 1.15965218×10⁻³ で**一致 1.2×10⁻⁶**。すなわち **a = √2(γ_ZB − 1)** であり、**γ_ZB = 1 のとき a = 0、g = 2**。**思考実験と橋渡し方程式は同じ命題の表と裏である。** √2 は周期にわたる γ の変動を RMS で拾うことに対応し、T1.3 の相対揺らぎ 1/√2 と同じ因子である（→ K9）。

**述べ方の制約（必ず守ること）** ── a は共変な Pauli 項 (a·e/4m)ψ̄σ^{μν}ψF_μν の係数であり **Lorentz スカラーである。慣性系を取り替えて消えるものではない。** したがって「ブーストで a を消す」とは書けない。**書ける形は一つ ── 共動系は搬送体が振動しているので非慣性であり、a はその非慣性共動系から実験室系へ移ることの運動学的残差である。** 前例がある ── **Thomas 歳差（1926）** は電子の共動系が回転していることだけから磁気的相互作用に因子を与え、微細構造の因子 2 の食い違いを解決した。**磁気モーメントの因子が力ではなく系の取り方から出た実例**であり、本命題はその型に属する。

**現状の限界** ── (1) **予言ではなく整合性である**。β_ZB は a_e から 6 桁決められているので循環であり、予言に変えるには β_ZB の独立決定が要る（→ K8）。(2) **QED は a を 10 桁与える**。Schwinger 項 α/2π だけでは実測から 0.152% ずれ、高次項が計算されて一致している。(3) **三世代の予言にはなっている**（§3 の β_ZB 表）。ただし β_μ/β_e − 1 = 2.70×10⁻³ を μ の寿命に使うと 11 桁外れる（幹 T2 の T2.5）ので、同じ差が二つの現象を同時に説明できるかは未解決。

### T3.5 v_ZB の一次表現（T1 との接点）（旧 T5.10）

本幹の読みでは

$$\frac{v_{ZB}}{c} = \sin 2\theta_0,\qquad \beta^2 = \sin^2 2\theta_0$$

で、θ₀ は負エネルギー成分の混合角。正準値 $v_{ZB} = 0.04047c$（#10、β² = 0.00163798087）を入れると

$$\sin 2\theta_0 = 0.04047,\qquad \theta_0 = 1.160^\circ,\qquad \sin^2\theta_0 = 4.10\times 10^{-4}$$

**「0SM の β² は、ディラック静止状態における正負エネルギー成分の交差項 sin²2θ₀ である」** は #10 の Eq. III.9 と照合可能な具体的言明である → K2。

### T3.6 混合の代価は β² 層（三層 β 階層との照合）（旧 T5.11）

θ₀ の混合状態のエネルギー期待値は

$$\langle H\rangle = mc^2\cos 2\theta_0 = mc^2\left(1 - 2\sin^2\theta_0\right) \approx mc^2\left(1-\frac{\beta^2}{2}\right)$$

すなわち混合のためにエネルギーが $\tfrac12\beta^2 mc^2$ だけ下がる。数値で $\tfrac12 \times 0.00163798 \times 511.0\,\mathrm{keV} = 418.5\,\mathrm{eV}$。これは T1 の三層 β 階層の第三層（419 eV）と一致する。**第三層は、正負成分の混合による静止エネルギーの欠損として一次から出る。**

### T3.7 角の硬さ ── 第二層 20.7 keV は「角を ½ rad 回すエネルギー」（旧 T6.4）

p = 0 の二準位の範囲で、光子エネルギー ħω_γ を吸って ⟨H⟩ = mc² cos 2θ が上がるとすると

$$\delta\theta = \frac{\hbar\omega_\gamma}{2\,mc^2\sin 2\theta_0} = \frac{\hbar\omega_\gamma}{2\,\beta mc^2} = \frac{\hbar\omega_\gamma}{2\times 20.7\ \mathrm{keV}}$$

可視光 2 eV で δθ ≈ 4.8×10⁻⁵ rad、1 keV で 0.024 rad、20.7 keV でちょうど ½ rad。T5 見直しで出た ΔH = mc² sin 2θ₀ = βmc²（混合状態のエネルギー幅）と合わせ、第二層は「エネルギー幅」であると同時に「角の硬さ」である。**ただし実際の吸収は運動量を伴い p ≠ 0 になる**ので、これは玩具模型の見積もりであり、T5 の K8（FW 角）を通らないと本物にならない → K3。

### T3.8 第二層 20.7 keV は内部時計の Brillouin 帯の端（旧 T6.13）

離散な刻み Δτ を持つ時計は、Fourier 双対として振動数に周期性（Brillouin 帯）を持つ。内部周期 1/ν_ZB の時計では帯の端が ν_ZB = 5.00×10¹⁸ Hz、エネルギーで hν_ZB = βmc² = **20.7 keV、第二層**。帯の外（20.7 keV 以上の光子）で何が起こるかは開いた問い → K6。kr = 1 は 163 keV で、帯の端とは 8 倍離れており同一視しない。Compton 散乱が MeV まで精密に検証されていることが制約。

### T3.9 二つの ½（旧 T1.8）

**エネルギーの ½**（#46 の床。β² 層に置けば床 = (γ−1)mc² = (a_e/√2)mc² = 419 eV → 「内部振動子の零点エネルギー＝異常磁気モーメントのエネルギー」）と、**作用の ½**（スピン ħ/2、ΔxΔp ≥ ħ/2、Bohr–Sommerfeld (n+½)h、Nelson の拡散係数 ħ/2m）は別物。弧（λ_C、0.0405c）が作用の ½ を供給できる割合は、どの量で測っても **2πβ = 0.254 = 1/3.93**：

### T3.10 自由電子の ½＝自己閉じ込め（旧 T1.9）

従来 QM に自由粒子の ½ はない（E = p²/2m、床なし）。ħω/2 は井戸の壁が Δx を強いた結果。0SM は電子が**自分自身の壁**（A–B の弧）を持つがゆえに外部の井戸なしに ½ を持つ——#33「幾何学的閉じ込め＝静止質量」の ½ による言い直し。**S⁰ は唯一弧状連結でない球面**（二点）。0SM とは「S⁰ を一本の弧で弧状連結にしたもの」であり、弧の有限な長さ λ_C が井戸の壁の代わりに Δx を与える。弧状連結をブラウン運動の由来と採るのは Nelson（1966）・Feynman checkerboard（±c のジグザグ → Dirac）の系譜で、0SM は「決定論的」「亜光速」の二点で踏み込む。連続性（跳びがない）は弧状連結が、乱雑さの量（ħ/2m）は弧と核の両方が担う（T1.8）。

### T3.11 零点の取り出し不能性（旧 T1.10）

π/4（#46 記法）で KE = E₀/2 を全部取り出すと TPE = E₀/2 で T_A = T_B、勾配零、振動子は凍結——取り出した先は「より低い電子」ではなく「電子でないもの」。標準理論の「下の状態がない」と同じ言明。さらに 0SM 固有の一文：**電子の内部エネルギーを取り出す唯一の過程は対消滅（#8）であり、½ ではなく全部を、負エネルギーの相方（#7）と一緒でなければ取り出せない**。n + ½ の階段では n が井戸（外側、創発的波動関数の節）、½ が振動子の床——井戸に入れても内部の床は変わらない。井戸の ħω_well/2 は井戸の振動数で決まり ZB の床とは数値が違う（同じ構造的理由で各階層に ½ が付く、が正確な言い方）。井戸の中の電子は折り返し点 ±a を二核とする外側の二核構造をもう一つ持つ（入れ子）。

### T3.12 測定は隠れた変数を編入する（2026-09-15c 新設）

**命題。** v_ZB が実測されたとき、それは「隠れた変数が実在する」ことの間接証明ではない。**変数が自由度として形式に編入される**ことである。測定の後、v_ZB はもはや隠れた変数ではない。

#### (1) 「隠れた」は場の側の語である

`README.md` §0.2 は 0SM を**ラグランジュ記述**（Madelung–Bohm の系譜）と宣言している。本項はその宣言の、語の側への帰結である。

流体力学の粒子法（SPH）で、粒子は密度・速度・内部エネルギーを属性として担う。場（オイラー）の記述は、それを核関数で**平滑化して再構成**したものであり、平滑化の過程で粒子ごとの属性は消える。このとき誰も「SPH 粒子は隠れた変数を持つ」とは言わない ── 粒子が属性を持つのは粒子法では当たり前だからである。

**「隠れている」という述語は、場の記述を基準に取ったときにだけ生じる。** 平滑化で消える量を、場の側がそう呼んでいる。0SM の θ₀（固定の混合角）と φ（内部振動子の位相）は、この意味での「隠れた変数」である。

#### (2) したがって二つの意味を分ける

| | 意味 | 何が制約するか | v_ZB 測定の効き方 |
|---|---|---|---|
| **A** | **形式に無い自由度**。平滑化で消える粒子の属性 | 測れば編入される。それで決着 | **直撃する** |
| **B** | **Bell の意味の局所隠れた変数** | 二粒子相関の不等式 | **効かない** |

**A と B は独立である。** A が真で B が偽という世界はあり得る（中性子は内部構造を持つが、中性子対の相関は Bell の不等式を破る）。

`README.md` §0.2 の「**一粒の範囲では安全である**（Bell 1966 の単一スピン 1/2 の構成が足場）／**二粒子系では非局所でなければならない**（選択ではなく帰結、幹 T7 の T7.1）」という既存の分割は、**この A/B の分割と同一の切り口**である。本項は新しい分割を導入するのではなく、**既にある分割が語の二義に対応していることを明示する**。

**運用上の要請** ── 「0SM は隠れた変数の理論である」と無限定に書くと、読者は B で読む。**A を意図するときは必ず明示する。** 明示しないと、A の主張（v_ZB という量子力学にない予言）が B の困難（二粒子の非局所性）で減点される。

#### (3) 編入は、隠れた変数が歴史上唯一勝ってきた形である

| 対象 | 「観測にかからない」とされた時期 | 編入した測定 |
|---|---|---|
| **原子** | マッハ・オストヴァルトの批判（19 世紀末） | Einstein 1905（ブラウン運動）→ **Perrin 1908–13**：十数個の独立経路から同一の Avogadro 数 |
| **原子核の大きさ** | Rutherford 以来、点として扱われた | **Hofstadter 1950 年代**：電子弾性散乱の形状因子で有限の大きさと電荷分布（1961 年ノーベル賞） |
| **クォーク** | 提唱時は「数学的な便法」 | **SLAC 深非弾性散乱 1968–69**：Bjorken スケーリング、陽子内部の点状構成要素 |

三つとも同じ型である ── **提唱 → 「観測にかからないものを論じるな」という批判 → 測定 → 自由度として編入。**

**隠れたまま（観測に差をつけないまま）の隠れた変数が実験で勝った例は一つもない。** 構造的な理由がある：定義上、観測に差をつけないからである。0SM が v_ZB という**量子力学にない予言**を持つことは、`README.md` §0.2 が既に立場の要請として書いている。本項はその予言が当たった場合の**身分**を確定させる。

**EPR 論文（1935）の題は "Can Quantum-Mechanical Description of Physical Reality Be Considered *Complete*?" である。** 求められたのは**完備性**であって、隠れていることではない。編入は立場の後退ではなく、要求の成就である。

#### (4) 編入されるのは大きさではない

本幹の既存の言明との整合を明示しておく。0SM が言う「電子に内部構造がある」の内実は、**エネルギー分配の構造であって電荷分布の構造ではない**（本幹 §2 の T3.2 系、形状因子上限 < 10⁻¹⁸ m と λ_C = 2.4×10⁻¹² m の両立。幹 T5 も同じ制約を「核は電荷を担えない」として持つ）。

したがって編入される自由度は **Dirac に対する振幅と振動数の割り当ての変更**である（Dirac：振動数 2mc²/ħ を固定し振幅 λ̄_C/2 ／ 0SM：振幅 λ_C を固定し振動数を 0.04 倍）。**大きさではない** ── 複合性の上限は「内部構造は a_e に小さな補正を足す」という前提の上に立つので、a_e そのものが内部運動であるという読みには、その形のままでは掛からない。**掛からない理由を書く義務は 0SM の側にある**（本項 (4) と T3.2 系がその答えである）。
