## 概要 — この幹は何を問うているのか

この幹が扱うのは、**何が動くか**である。骨格は著者の一行 ── **熱の双極子 ＝ 質量の双極子** ── にある。孤立系の質量双極子 D = ΣE_i x_i/c² は dD/dt = P（全運動量）で保存するので、**核を固定したまま熱を A から B へ移すことはできない**。核を止めるには搬送体が u(θ)/d = cos θ/sin²θ という発散する位相速度で走らねばならず、これは不可能である（T4.4 で定理化）。**核は動かざるを得ず、これが Zitterbewegung を導く**（T4.1）。ただし**電荷の双極子ではない** ── e·λ_C ≈ 2.4×10⁻¹⁰ e·cm に対して電子 EDM の実験上限は 4.1×10⁻³⁰ e·cm（JILA 2023）で、**20 桁**離れている（T4.2）。動いているのは質量（熱）の双極子である。

双極子が保存則で禁じられた後に**四重極が残る**。ここが本幹の要で、同じ配置の二階モーメントは閉じた形を持ち、**奇数次高調波は恒等的に零**（理由はパリティで解決済み、幹 T1 の T1.5）、**支配的高調波は 4ω ＝ 2.00×10¹⁹ Hz（82.7 keV）で出力の 79.11%** を担う（T4.5）。重力波出力は 1.00×10⁻⁴³ W ＝ 宇宙年齢で 2.7×10⁻⁷ eV なので安定性に問題はない。核における軌道は**三階まで平坦**（X′ = X″ = X‴ = 0、X⁗(0) = −9/2）で、A → B → A′ が滑らかに繋がる（T4.6）。内部固有加速度は最大 **2.07×10²⁷ m/s²** で、等価原理によりこれは**内部重力場**である（T4.7）── ただし**描像であって荷の定義ではない**（#67 の凍結を守る）。

**本幹は前線 A（幾何学プログラム）への直通口である。** **K1 ＝ N1**（#24 §5.1 のモーメント階層を ℓ=1 から ℓ=2 へ延ばす）であり、T4.2／T4.4 の「双極子は質量双極子保存則で禁じられ、四重極が残る」はそのまま N1 の出発文に使える。**門は開いている** ── テンソルビリアル恒等式の境界項 S^{jk} が閉じ込め力のビリアルであり**無条件で使える**ことは 2026-09-07 に確定した（T4.3）。入力（#33, #51, #57, #24, #30）も全部揃っている。**ただし着手の前に幹 T1 の K4 を決めること** ── 核の空間トレースを輻射と読むか物質と読むかで **⟨S⟩ が 4 倍変わる**からである。

## 現在地 — 何が閉じ、何がまだ開いているか

**閉じた問題**：境界項の身元は決着した（テンソルビリアル恒等式の閉じ込め力のビリアル。無条件で使える）。「核を固定したまま質量双極子の拘束を満たせる」は撤回された。「異常磁気モーメントから軌道の非閉性 A ≠ A′ が導かれる」は**弱められた** ── 異常磁気モーメントは QED の輻射補正であり、非閉性は**許容されるのであって導出されない**。「許容」を「導出」に上げる作業は幹 T3 の K4 に属する。四重極出力の数値も修正済みである（3.8×10⁻⁴⁴ W は単一高調波の見積もりで、正しくは 1.00×10⁻⁴³ W。桁と安定性の結論は変わらない）。

## 2. 確立した命題（T4.1–T4.8）

### T4.1 質量双極子の保存則が ZB を導く（旧 T1.5）

熱の双極子＝質量の双極子（著者）。孤立系の質量双極子 D = ΣE_i x_i/c² は dD/dt = P（全運動量）で保存則に縛られ、静止系では定数——**質量双極子は振動できない**（重力波が四重極から始まる理由そのもの）。0SM に持ち込むと拘束式 E_A x_A + E_B x_B + E_γ x_γ = 一定。熱が A→B に移るとき核の位置が固定ならエネルギー中心が動いて運動量保存を破るので、**核（質量側）が反跳しなければならない**。この反跳が ZB（Dirac の「位置演算子がエネルギー中心の周りで振動する」と同じ意味）。反跳速度 v/c = E_γ/(E₀ − E_γ) から E_γ = 19.9 keV（厳密）≈ 20.7 keV（非相対論）。独立の仮定（遷移率 f = v/λ_C → hf = 20.68 keV）と一致。

### T4.2 双極子的幾何——何の双極子か（旧 T1.6）

電荷の双極子ではない：e·λ_C ≈ 2.4×10⁻¹⁰ e·cm に対し電子 EDM 上限 4.1×10⁻³⁰ e·cm（JILA 2023）で 20 桁排除。**エネルギー（熱）の双極子**である：#1 の勾配 ∇(T_B − T_A) ∝ E₀ sin θ が向きを持つ双極子モーメント。ただし半周期ごとに反転する振動双極子で、**平均は零、二乗平均は非零**——EDM 零・磁気モーメント非零と整合。役割分担：極性ベクトル（A→B 軸 n̂、平均で消える）／軸性ベクトル（循環の向き、スピン・磁気モーメント）。**直線往復（#10「最短直線経路」、#19「共線」）だけでは軸性ベクトルが出ない**（古典的に a ∥ v、共線ブースト列の Thomas 回転は零）。#62 §2 Fig. 1 は既に弧 L₀ = 2πr と循環の向きを描いており、幾何は変わっている（K6）。双極子が平均で消えたあと残る最低次のエネルギー多重極は**四重極**（rank-2）で、振動するのはエネルギー層（2π 周期）であって振幅層（4π 周期）ではない。重力波出力 ≈ 4×10⁻⁴⁴ W（宇宙年齢で 10⁻⁷ eV）、安定性は無傷。輻射核・吸収核の対は遠方場を持たない閉じた放射交換（自己吸収する二素子アンテナ）。

**補（2026-09-14、幹 T2 の T2.13 より）** ── 「電荷の双極子ではない」に構造的な理由が付いた。電荷は核に局在する量ではなく、振幅平面 (a, b) の軌道が原点のまわりを回る**保護された巻き数**（系全体に一つ付く整数）である。核に電荷が無い以上、核対が作る双極子は電荷双極子になりようがなく、EDM 零は上限との整合ではなく構造からの帰結になる。**二つの ℤ₂ を混ぜないこと** ── 本項の軸性ベクトル（実空間の循環の向き＝スピン）と、電荷共役（内部平面の反射 b → −b）は別の ℤ₂ である。両者の独立性の証明は幹 T2 の K16。

### T4.3 K13 の決着 — 境界項は閉じ込め力のビリアルである（旧 T1.13）

テンソルビリアル恒等式 d²M^{jk}/dt² = 2c²∫T^{jk}dV + S^{jk} を局所保存則から導き、0SM の内部配置に適用した。境界項の周期平均は

⟨S⟩ = −(E₀/2)[1 + (405π²/256)β²] = −0.51278774 E₀ （d = λ_C）

形状因子は厳密有理数 **405/4096**。補正項は O(β²) で 2.56%、先頭項 −E₀/2 は核間距離の規約にも搬送体の閉包の取り方にも依らない（四通りの閉包で 0.5% 以内）。**この値は偶然ではない** ── 恒等式から床 E₀/2 を除いた残りは変位 D の単位調和振動子であり（幹 T2 の T2.2）、調和振動子のビリアル定理 2⟨T⟩ = E_osc が要求する値と厳密に一致する。**境界項は領域の境界が供給する閉じ込め力のビリアルそのものである。**

S(θ) は核の位置 θ = 0, π で厳密に消え、θ = π/2, 3π/2 で最大 |S| = 1.0768 E₀ となる。**これは #58 が位相安定対の放出事象を置いた二点と一致する。** 全周期を通じて符号を変えない。核の空間トレースを輻射（トレースレス）と採ると ⟨S⟩ = −2E₀ となり **4 倍変わる**（→ K12）。

### T4.4 T1.5 の定理化 — 核固定は不可能である（旧 T1.14）

核を固定したまま質量双極子の拘束 Σ E_i x_i = 一定 を満たすには、搬送体が u(θ)/d = cos θ/sin²θ の位置にいなければならず、これは θ = 0, π（核の位置）で**極を持つ**。大きな値ではなく発散であり、搬送体は領域の外に出る。**核固定は排除される。** T1.5 は解釈の一つではなく保存則からの帰結である。

反跳を許すと閉包は一意に決まる ── X(θ)/d = ½cos θ[1 + ½sin²θ]、双極子残差 D(θ) ≡ 0（記号的に厳密）。幾何学的な意味は **エネルギーを持っている側の核が常に重心の位置に座る**ことで、核対は ±d/2 だけ振れる。**Zitterbewegung の振幅は核間距離そのものであり、自由に選べるパラメータではない。** 主要項は ½D（幹 T2 の T2.3 の質量双極子）。

### T4.5 四重極の高調波構造（旧 T1.15）

同じ配置の二階モーメントは閉じた形を持つ。

Ĵ(θ) = sin⁴θ(1 + sin²θ)/16 = [22 − 31cos 2θ + 10cos 4θ − cos 6θ]/512

その三階微分の自乗平均は厳密に **4045/4096**。重力波出力は P = 1.00×10⁻⁴³ W（宇宙年齢で 2.7×10⁻⁷ eV、安定性は無傷）で、単一高調波の見積もり 3.8×10⁻⁴⁴ W の 2.6 倍。**内訳が要点である** ── 出力の 11.88% が 2ω、**79.11% が 4ω（2.00×10¹⁹ Hz、82.7 keV）**、9.01% が 6ω に乗り、**奇数次は恒等的に消える**。奇数次が消えるのは四重極が核入れ替えに対して偶パリティだからである（幹 T2 の T2.4）。ただし高調波の振幅は搬送体の閉包に敏感で、閉包を変えると P は最大 8 倍動く ── **四重極出力を数字として主張するには、点質量の戯画ではなく #57 の a_ℓm による実分布から T_μν を組む必要がある**（N1 への直接の指示）。

### T4.6 核における三階平坦性 — A → B → A′ は滑らかに繋がる（旧 T1.16）

反跳閉包の軌道 X(θ) = ¼(sin²θ + 2)cos θ を核で展開すると

X′(0) = X″(0) = X‴(0) = 0、　最初に消えないのは X⁗(0) = −9/2（θ = π では +9/2）

**速度だけでなく加速度も躍度も消える。** X − X(0) ≈ −(3/16)θ⁴ で、**核において軌道は三階まで平坦**である。これは自明ではない ── 単振動なら折り返し点で加速度は最大である。**反跳閉包という条件がこの平坦性を作っている。**

**帰結** ── 自由電子が並進するとき A → B → A′ で A ≠ A′ となってよく（保存則は非閉性を禁じない）、その軌跡は核で折れ曲がっても **C³ で繋がる**。一般論としては「速度が消える点では像に角があってもパラメータ付き曲線は C¹ になれる」（r = (t³,|t|³) で片側速度は両方零、C¹ だが C² ではない）だけだが、0SM の軌道はそれより二階良い。

**論拠の指定** ── 「KE = 0 だから搬送体が止まる」は搬送体が質量を持つ場合の推論である。搬送体が光子ならエネルギー零は「静止」ではなく「不在」を意味する。**論拠はエネルギー重心 X(θ) の三階平坦性に置くこと。**

**歩幅について（誤りを一つ記帳しておく）** ── 「一周期あたりの前進 β_ZB c T_ZB が λ_C に一致する」という読みは**採らない**。ν_ZB ≡ v_ZB/λ_C は定義（#67 Eq. nuZB）なので同語反復であり、さらに **v_ZB は螺旋の横断速度であって並進ドリフトではない**（§0）。正しく残るのは ── 静止系では X(θ) は周期的で **A = A′**、歩くのはブーストした系だけで、実験室系の歩幅は **(βγ/β_ZB)·λ_C**（β は並進速度）。β = 0.999999 で 1.7×10⁴ λ_C。Dirac の自由電子の位置演算子が「一様なドリフト＋ Zitterbewegung」に分かれるのと同じ形である。

### T4.7 内部固有加速度 — 等価原理により内部重力場である（旧 T1.17）

同じ軌道の二階微分は閉じた形を持つ。

**X″(θ) = −(9/4)sin²θ cos θ** 　（最大値は厳密に **√3/2**、θ ≈ 234.7°、**核では零** ── T1.16 と整合）

固有加速度の最大値は **a = ω²λ_C·(√3/2) = 2.07×10²⁷ m/s²**。**電子の内部には、核で零・赤道近くで最大となる 10²⁷ m/s² の加速度場がある。** 等価原理を通せばこれは電子の内部重力場であり、**T1.12 補の「共動系は非慣性である」と同一の扉**である。

**重力時間遅れとの接続** ── 内部時計を ν_ZB と同定すると、高度による時計の進みの差が内部振動数のずれとして書ける（§3 の高度表）。機構としては E₀ → E₀(1 + Φ/c²)、すなわちアインシュタイン 1911 年の論法の再導出であって**新しい機構ではない**。文献上の住所は Müller–Peters–Chu（*Nature* 2010）と Wolf らの論争である。

**検査の在処は #67 が既に確定している** ── a は無次元で ν_ZB と測定時計が同じ因子で偏移するので**一次の試験は無く**、これは #67 が「Penning トラップの比 ν_a/ν_c では装置の共通赤方偏移が厳密に相殺する」と述べているのと同じ言明である。β_ZB が Φ に応答する読み（#67 の Reading B）は k_a ≡ (c²/a)(da/dΦ) = 2 を要求し、Lange ら（2021）の k_α = 14(11)×10⁻⁹ に対して**八桁で排除済み**（Ferrell ら 2007 でも既に五桁）。**β_ZB は局所不変量である。** 残る識別実験は年周変調 Δ(g/2) = 7.65×10⁻¹³（ΔΦ/c² = 3.299×10⁻¹⁰、Fan ら 2023 の不確かさ 1.3×10⁻¹³ に対し比 5.9）ただ一つで、#67 がそれを記帳している。**幹はこれを未確認事項として持たない。**

これにより **幹 T2 の K6 は「なぜ内部位相が一様に進むのか」から「何が位相の進む速さを決めるのか」へ変わる**（400 km で ν_ZB は毎秒 2.06×10⁸ 回多い）。

### T4.8 Kerr 読み（#51 との接点、点検待ち）（旧 T5.14）

T2.0 の読み替え（四次は振幅について）を #51 の n(T) に及ぼすと、n は熱力学的温度ではなく振幅の二乗（強度）の関数になる。強度依存の屈折率は Kerr 媒質（n = n₀ + n₂ I）であり、熱 Fermat 計量は Kerr 媒質の Fermat 原理になる。交差項 $2\cos^2\theta\sin^2\theta = a_A^2 a_B^2$ は相互位相変調の項。ただし §7.9 により 4 次元共形の n は光を曲げないので、効くのは 3 次元 Fermat 計量＝物質の経路の側 → K3。
