## §0 セッションの経緯（四手）

1. **著者の提案**: カルマン渦列が交互にできる点を Ising（スピンの上下が交互）に対応させ、上先行か下先行かは初期値のスピンで決まる、と読めないか。→ 対応は Landau 1944 の乱流遷移の設計図そのもの。磁性体側の相手は強磁性でなく**反強磁性（Néel 状態の二重縮退）**。「初期値のスピン」の正体は初期擾乱の随伴モードへの射影の符号。ずれは一点、Ising の Z₂ に対し Hopf 分岐は U(1)（位相拡散、記憶は拡散型）。2:1 の対称強制を入れると U(1) → Z₂ に落ち本物の Ising（パラメトロン）になる。
2. **著者の問い**: この Landau の発想を 0SM に敷衍し、時間位相でスピンが反転するモデルとして論文化できるか。→ できる。ただし「Landau の発想」は三部品（L1 分岐そのもの／L2 対称性の構造／L3 同期・ロック）に割れ、独自性が立つのは L2 と L3。L1（振幅選択）は 0SM では規格化が先に済ませている。
3. **著者の主眼**: 対称な円柱に対称に当たる点粒子には上下を決める席が形式に無く、種は外からしか来ない（量子力学では Born の規則がその「外」の名）。0SM は席を持つ ── 到着の瞬間に核 A・B 間の輻射流がどちら向きかは決まっており、t = 0 をどこに置くか（到着時の内部位相）が上下の幾何学的条件を初期値として与える。→ 補題と一粒の Malus 検定で検証（§2・§3）。

## §1 確定した対応（検算済み。幹 T1 への書き戻し候補）

### 1.1 恒等式の対称性 ＝ 渦列の (鏡映 × 半周期) 対称性

幹の記法 θ で E₀(θ) = cos⁴θ + sin⁴θ + ½ sin²2θ。

- **E₀(θ + π/2) = E₀(θ)** ── A↔B の札の付け替えと占有の半周期ずらしを同時に行うと不変。渦列の「鏡映 y→−y × T/2 並進」、反強磁性鎖の「スピン反転 × 一格子並進」と同じ構造。
- 層ごとの周期と偶奇（検算 [1]）:

| 0SM の層 | 式 | θ の周期 | A↔B で | 円柱後流 | 周波数 |
|---|---|---|---|---|---|
| 差 D（双極子） | cos 2θ | π | 奇 | 揚力 C_L | f₀ |
| エネルギー層／交差項 | (3+cos 4θ)/4 ／ (1−cos 4θ)/4 | π/2 | 偶 | 抗力 C_D | 2f₀ |
| 振幅 (cos θ, sin θ) | ── | 2π | 四分の一回転 | **対応物なし** | f₀/2 |

抗力が剥離周波数の二倍で揺れる古典的事実の理由は (κ, T/2) 対称性だけ。**歯車比 2（T2.1）の実物が揚力と抗力の比。**

- **振幅層は後流に無い。** 後流の複素振幅 A = R e^{iωt} に対し、0SM の振幅 z は **z = √A**。A が原点を一周（周期 T）する間に z は半周 ＝ Floquet 乗数 −1 ＝ メビウス帯 ＝ 720°（周期倍分岐の捻れ周期軌道の標準構造）。
- **接合**: T1.23–T1.25（ジューコフスキー、0-Sphere ＝ 点粒子の平方根の分岐点）の分岐点は、まさに z = √A の分岐点 A = 0。Hopf 分岐では A = 0 は**反発する原点**（σ > 0）で、極限周期軌道はその周りを巻き数 1 で回る。したがって「平方根の分岐点（T1.23–25）／Hopf の反発原点／二核は原点を避ける（#1 §3、T2.4 の必要条件）／巻き数の保護（T2.4）／メビウス（T2.1）」は同じ一点の話。**09-24 に「一本の線が通らない」として見送られた T1.23–25 は、この原点を軸にすれば線が通る可能性がある。**
- **振幅層を埋める古典物理 ＝ パラメトロン**（後藤 1954、縮退 OPO のコヒーレント・イジングマシン）。2:1 ポンプ下の副調波は位相 0 か π の二状態しか取れず、副調波自身の符号 ±z でしか区別されない。0SM では**観測量の層（周期 π）が振幅層（周期 2π）を 2:1 でポンプしている**と読める。中性子干渉計の 4π（Rauch 1975、Werner 1975）と同じ構造。→ 独自性候補「0SM の三層 ＝ 抗力（2f₀）・揚力（f₀）・パラメトロン（f₀/2）の三段、フェルミオンの符号は副調波の位相ビット」。

### 1.2 二つの Z₂（幹 T2 への書き戻し候補、K16 の変形）

0SM には Z₂ が二つあり、Kármán に対応するのは一つだけ。

- **(a) 順序の Z₂**: 周回のどこから始まるか。A 先行か B 先行か。上先行／下先行、著者の「初期スピン」、φ(0) で選ばれる。
- **(b) 向きの Z₂**: 振幅平面を回る向き。Wronskian の符号（T2.5）、e∓（T2.4）。

後流には (b) に当たる選択肢が無い（散逸系の極限周期軌道は時間反転で不変でなく、回る向きは ω の符号として最初から決まる）。Landau を持ち込むなら**電荷共役は分岐で選ばれるものではなく系のパラメータ ω の符号**。帰結: 「電荷は時計の向き、スピン（の順序）は時計の針の初期位置」。T2.4 の二解 δ ∈ {0, π} は Claude の読みでは (b)、著者の交互描像は (a)。**混ぜると T2.4 と衝突して見えるので分離を明文化する枝が要る。**

### 1.3 用語の地雷（§2「借用語は二義を疑う」への追加候補）

- **Hopf**: #65 の Hopf は Hopf **束**（S³→S²、二重被覆）、本セッションの Hopf は Hopf **分岐**（固定点から周期軌道）。同一人物だが数学的に別物。必ず書き分ける。
- **スピン**: Ising 側は符号変数 σₙ = ±1（渦の循環の符号）、0SM 側は SU(2) の 1/2（720°）。著者の交互描像はこの二つの橋。Ising 側を「符号」、SU(2) 側を「スピン」と書き分ける。
- **位相**: 時間位相（phase）と位相幾何（topology）。メビウス・巻き数は後者、A/B の順序を選ぶのは前者。英訳で分かれる箇所を国語の段階で分けておく。
- **隠れた変数**: 本セッションの「初期値の種」は **A 型**（形式に無い自由度、φ(0) と循環の軸 n̂）。B 型（Bell の局所隠れた変数）ではない。一粒の範囲。明示が要る（README §0.2、T3.12）。

## §2 開始時刻の補題（検算 [3][4]。幹 T4／T5 への書き戻し候補）

**問い**: 遅い増幅器（成長率 σ、不安定平衡）が、速い種 F₀ sin(Ωt + χ)（Ω ≫ σ）に駆動されるとき、何が選ばれるか。

$$
y(T)=\int_0^T e^{\sigma(T-t)}\sin(\Omega t+\chi)\,dt
= e^{\sigma T}\,\frac{(\sigma\sin\chi+\Omega\cos\chi)-e^{-\sigma T}\bigl(\sigma\sin(\Omega T+\chi)+\Omega\cos(\Omega T+\chi)\bigr)}{\sigma^2+\Omega^2}
\;\approx\; e^{\sigma T}\,\frac{\cos\chi}{\Omega}
$$

数値積分と閉じた式は相対 10⁻¹² で一致。読み方は三つ。

1. **選ばれる符号は cos χ**、すなわち増幅が始まった瞬間（到着）の種の位相。終端の位相は e^{−σT} で消える。「t = 0 をどこに置くか」は恣意でなく**不安定化の開始時刻**。
2. **種は強さを要らず、符号だけを要る。** σ > 0 の不安定平衡はどんな小さな種でも増幅する。A 型の隠れた変数が仕事をするのに大きさの議論が要らない ── Landau の構図を借りる値打ちはここ。
3. 重みは静的な種の **σ/Ω 倍**。F₀ ≈ mc²/(λ_C/2) ≈ 6.7×10⁻² N（Stern–Gerlach の μ_B×10³ T/m ≈ 9.3×10⁻²¹ N の 10¹⁹ 倍）だが、Ω = 2ω = 1.55×10²¹ rad/s なので、σ = 10 s⁻¹ で 4×10⁻²² N、10⁵ で 4×10⁻¹⁸ N、10⁹ で 4×10⁻¹⁴ N。**流体の後流（σ ∼ 1–10 s⁻¹）では装置のどんな非対称にも負ける** ── 後流は構造の例えであって、電子が円柱の剥離を決めるという話ではない。測定の側で「増幅器」が何かは別に言う必要がある（T5 の新枝候補）。

**#1 の式で読み直す（検算 [2]）。** #1 は θ = ωt を**全角**に取り、核は θ/2 に乗る（幹の θ は #1 の θ/2。記法注意）。

- T_e1 = E₀ cos⁴(θ/2) δ(x − a)、T_e2 = E₀ sin⁴(θ/2) δ(x + a)（#1 e3_delta_and_electron_position_cos/sin）。分離 2a、光子球の半径 λ_C、t = 0 で光子球は x = a（#1 本文）。
- grad(T_e2 − T_e1) = E₀ sin θ（#1 e3_simple_harmonic_motion）、u_γ* = −E₀ sin θ（e3_simple_harmonic_motion_-sin）。
- D ≡ T_e1 − T_e2 = E₀ cos θ。**(D, F/E₀) = (cos θ, sin θ) は複素振幅 E₀e^{iθ} の二つの直交成分。** Kármán の初期値 A(0)（随伴モードへの射影、複素数）に当たるのが #1 の (D(0), F(0)) の対。Landau の初期値が複素数でなければならない理由が、0SM では「エネルギーの偏りと流れの二つが要る」として出る。
- F の時間積分は (E₀/ω)[cos χ − cos(ωt + χ)] で直流成分 (E₀/ω) cos χ を持つ。**増幅器が読むのはこの直流成分 ＝ D(t₀) ＝ 到着時にどちらの核がエネルギーを持っているか**。u_γ* を積分すれば光子球の位置 x_γ ∝ cos θ なので、同じことは**「到着時に光子球が A 側にいるか B 側にいるか」**。変位の上限 λ_C/2 ≈ 1.2 pm。
- **帰結（意外な形）**: 流れ F が最大の瞬間（θ = π/2、赤道、D = 0、T2 の K10 の点）に到着すると積分は零の周りで対称に振れ**種は零**。流れが止まった瞬間（極、どちらかの核が全エネルギーを持つ、#1 の t = 0 の状態）に到着すると**種は最大**。
- **著者の主張の判定**: 「輻射流が生じるために上下が決まる」は半分正しい。F は scalar の D を n̂_AB 方向の変位（光子球の位置）に変える仕事をしており、F が無ければ D は向きを持てない。しかし符号を与えるのは F の瞬間値でなく D、つまり光子球の位置。
- **ゲージ不変性**: A↔B の札の付け替えで D も n̂_AB も符号を変えるので、種 D(t₀) n̂_AB は付け替えで不変。
- **T4.2 との整合**: F の向きは 2ω で反転するので EDM の平均は零（T4.2 の 20 桁排除と矛盾しない）。同じ理由で F は Malus を担えない（§3）。この二つは一つの性質の表裏。

**T4.2 との関係（新規でない部分を明示）**: T4.2（旧 T1.6）は 09-06 の時点で既に「#1 の勾配 ∝ E₀ sin θ は向きを持つ双極子、平均零・二乗平均非零、極性ベクトル（A→B 軸 n̂、平均で消える）／軸性ベクトル（循環の向き、スピン・磁気モーメント）、直線往復だけでは軸性ベクトルが出ない（K3）」を置いている。本セッションで新しいのは二点のみ: (i) F の役割が「平均で消える双極子」から「開始時刻の補題の種」に変わる ── 消えるのは φ 平均であって、σ > 0 の増幅器は到着時刻の一回分を読む。対称配置では 50/50、個々の事象では決定。(ii) 種の実体は D(t₀)、幾何学的には光子球の位置。

**#51 との整合（§4 訂正 1 を参照）**: 分離ベクトル x_B − x_A は空間（#51 191・568 行）、遷移の変数 θ は内部配位空間（#51 869 行）。F が空間の x 軸に沿うことは #51 と矛盾しない。

## §3 一粒の Malus 検定（検算 [5]。幹 T7 への書き戻し候補）

**問い**: Kármán の読み出し規則「種を反対称モードに射影した符号」で、種が時間位相 φ 一つ（円周上一様）だと、傾けた検出器の統計はどうなるか。

| a（度） | 円周一様・符号読み出し | KS 1967 模型 | cos²(a/2) |
|---|---|---|---|
| 30 | 0.833 | 0.933 | 0.933 |
| 45 | 0.750 | 0.853 | 0.854 |
| 60 | 0.667 | 0.750 | 0.750 |
| 90 | 0.500 | 0.500 | 0.500 |
| 120 | 0.333 | 0.250 | 0.250 |
| 150 | 0.167 | 0.067 | 0.067 |

（N = 4×10⁶、乱数種 0。KS と cos²(a/2) の最大差 2×10⁻⁴）

- **位相だけでは線形**になる。T7.1 で二粒子について確認した Bell 1964 の反例が、**一粒で既に現れる**。
- **読み出し規則は正しい。** Kochen–Specker 1967 の一粒模型は同じ sign(a·λ) を使い、隠れた変数 λ を **S² 上の方向**、密度を準備方向 p 側の半球で (p·λ) に比例、と置くと cos²(a/2) を厳密に出す。足りないのは種が円周でなく球面上の方向であること。
- **0SM への割り当て**: 種のベクトルは二つの積。**軸 n̂**（S² 上、周回の間は不変、遅い、μ ∝ L の向き ＝ T4 の K3 の軸性ベクトル）が Malus を担い、**位相 φ**（円周上、10²¹ Hz、速い）が「最初の半周期がどちら側か」を担う。φ で平均すると速い符号は消える。
- **著者の主張の判定**: 「t = 0 の位相が上下を決める」は**対称配置（準備 ⟂ 測定、50/50）では位相だけで正しく**、傾けた配置では軸 n̂ を加えないと統計が合わない。「上下の幾何学的位相条件」は幾何（軸）と位相（φ）の二つに分かれる。
- **K13／T7 の K3 との接合**: KS 模型の二つの応答関数 {Θ(a·λ), Θ(−a·λ)} は球面を半球二つに分ける **1 の分割** ＝ 著者の直感「表と裏 ＝ 1 の分割」そのもの。0SM 側で新たに言うべきことは一点だけ ── **p で準備した後、循環の軸が p に揃うのではなく、p 側の半球に余弦の重みで分布する**こと。これは 0SM の動力学が出すべき言明で、検証可能。
- **F を入れても変わらない**: D(t₀) n̂_AB も φ で平均すると零。Malus は n̂ の仕事のまま。
- **T7.1 は不変**。本セッションの拡張は受動的な位相共有の範囲にあり、2:1 ロックの二安定も出力が sign(cos(φ − a)) になる以上、相関は線形。論文では「本理論の範囲と限界」に一段落で置き、Bell に触れる主張を本文に入れない。

**位置づけ（論文の序の一段落として）**: Landau が「対称な方程式は種なしに分極しない」と書き、量子力学が「形式に種は無い」と Born の規則で認め、0SM が「種はある、A 型の隠れた変数である」と言う。種の正体は、対称配置では位相 φ、一般の配置では軸 n̂ と φ の積、読み出し規則は Kármán ＝ KS の符号射影。

## §4 訂正（Claude がこの会話で二度訂正した。消さずに残す）

**訂正 1 ── 「A↔B の輻射流それ自体には空間の上下が無い」（13:42 の発言）**
正しいのは「**向きの無い軸**（A と B を結ぶ線、RP² の点）には上下が無い」であり、**流れ F は向きを持つ**（#1 の勾配力）。F = −(d/dt)(TPE_A − TPE_B) n̂_AB は札の付け替えで不変の物理的ベクトル。
さらに、幹に引かれている「#51『A–B 軸は内部配位空間であって空間方向ではない』」（T2 の K16 の材料、`T1-2026-09-24` の注、§7.10）は **#51 の半分しか引いていない**。#51 の本文には二つが同居する:

- **191 行・568 行**: 「核 A と核 B の空間的分離は伝播軸に沿って Δx ∼ λ_C」「x = ±a に置かれた二核の配置で片道 (−a → +a) が内部スピノル位相 2π を積む」── **分離ベクトルは空間の x 軸**（#1 を継承）。
- **869 行**: 「A→B の遷移は内部の場（配位）空間の最小作用経路。空間の伝播過程ではなく抽象的な状態空間の遷移。v_ZB はその内部経路を辿る速さ」── **遷移の変数 θ は内部配位空間**。

答えは「どちらか」ではなく「#51 自身が両方を書いている」。**分離は空間、遷移は内部。** 幹の引用は 869 行の圧縮で 191・568 行が落ちている。§7.10 の閉鎖（W8）は分離が空間でも「カーネル向きの等方性」の条件で立っているので動かない（偏極した集団は別途点検 ── 一行で記帳する枝）。**当該三箇所に「#51 の 191・568 行も見よ」を付けること。**

**訂正 2 ── 「出力の符号 = sign(sin χ)、到着時の F の向き」（13:42 の発言）**
