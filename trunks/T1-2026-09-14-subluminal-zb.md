## 2. 確立した命題（T1.1–T1.17）

**T1.1 恒等式の素顔** 保存恒等式 E₀ = E₀[cos⁴(θ/2) + sin⁴(θ/2) + ½sin²θ] は **1 = (cos²(θ/2) + sin²(θ/2))² の展開**で、数学的には無内容。物理はすべて三項を TPE_A, TPE_B, KE に割り当てる側にある。E = mc²（p^μp_μ = m²c² は定義、物理は慣性質量との同一視）と同型。共通の型は「**変換で作られた無次元因子を、測定可能な二量の比と等置する**」。橋渡し方程式の裸の形は **g/2 = γ_L**（g = 2γ_L）。π の話を経由する必要はない。

**T1.2 何が単振動しているか（2026-09-07 に語義訂正）** 二核は**温度** 𝒯_A = cos²(θ/2), 𝒯_B = sin²(θ/2) を持ち、**𝒯_A + 𝒯_B = 1**（これが規格化そのもの）。エネルギーはその **2 乗** T = 𝒯² である。恒等式は (𝒯_A + 𝒯_B)² = 𝒯_A² + 𝒯_B² + 2𝒯_A𝒯_B であり、**KE = 2𝒯_A𝒯_B = ½sin²θ は二核の温度の交差項**。質量項は一周期を通じて E₀/2 を下回らない。

**訂正の内容** ── 旧版は「温度振幅 T_A = cos(θ/2) のエネルギーは 4 乗（Stefan–Boltzmann）」と書いていた。**四乗は振幅についてであって温度についてではない。** 振幅 a = cos(θ/2) と温度 𝒯 = a² の間にもう一段の二乗があり、四乗はその合成である。温度を振幅の層に置けない理由は符号にある ── 振幅を温度と読むと θ > π で**負温度**になり、観測にかからない χ → −χ で温度の符号が反転する。占有数の層なら 𝒯 = a² ≥ 0 が常に成り立ち符号も不変で、**温度の総和が保存する**という言明が立つ。**これは語義のみの訂正であって構造の変更ではない**（恒等式・数値・全命題は一切動かない）。四次の根拠は Stefan–Boltzmann の類推ではなく置き場の勘定と調和性である。導出と論拠は**幹 T2 の T2.0 と T2.8**、位相幾何の本体は **T2.10**（観測可能量は偶数次でなければならない）。

**⟨TPE⟩:⟨KE⟩ = 3:1 の扱い** ── 旧版の「ビリアル定理（1:1）は成り立たない」は**撤回**（§4）。床 E₀/2 をポテンシャルに含めていたための見かけの比であり、床を除けば 1:1 で厳密に成立する（幹 T2 の T2.2）。

**T1.3 観測可能性＝交差項結合** 電磁結合は交差項 ½sin²θ にのみ触れる。黒体核の内部（T⁴）は直接見えない。E₀ は観測量ではなく推論量（#31 の「線積分が観測量」と同方向）。「量子揺らぎ」は、この交差項の周期統計を、位相 θ₀ を知らずに標本化したもの。相対揺らぎ std(KE)/⟨KE⟩ = **1/√2**（⟨KE⟩ = E₀/4、Var = E₀²/32）。#10 の手置き 1/√2 との機構的関係は未確定（K10）。

**T1.4 亜光速がすべてを決める（三層 β 階層）** β = v_ZB/c = 0.0405 として、エネルギーは β の冪で三層に分かれる。

| 層 | 式 | 値 | 何か |
|---|---|---|---|
| β⁰ | mc² | 511 keV | 動かない質量（床） |
| β¹ | β mc² = h v/λ_C | 20.7 keV | photon sphere の量子（#46 の ħω） |
| β² | ½β² mc² = (γ−1)mc² | 419 eV | 核の反跳の運動エネルギー＝橋渡しの a_e/√2 |

β¹ と β² は独立でない：20.7 keV の光子に質量 m が反跳する運動エネルギー E_γ²/(2mc²) = 418.5 eV は (γ−1)mc² = 419.0 eV と 0.1% で一致。異常磁気モーメントは β² 層に住み、**a = γ − 1 ≈ β²/2 → 0（β → 0）**：v ≪ c なら AMM は生じない（著者の見立て、確認済み）。「mc² の 96% は何か」は問いとして成立せず、答えは**動かない質量**。恒等式が mc² の尺度で適用されないこと（KE_max = mc²/2 なら v = 0.7c で Dirac 領域）が、亜光速の意味そのもの。

**T1.5 質量双極子の保存則が ZB を導く** 熱の双極子＝質量の双極子（著者）。孤立系の質量双極子 D = ΣE_i x_i/c² は dD/dt = P（全運動量）で保存則に縛られ、静止系では定数——**質量双極子は振動できない**（重力波が四重極から始まる理由そのもの）。0SM に持ち込むと拘束式 E_A x_A + E_B x_B + E_γ x_γ = 一定。熱が A→B に移るとき核の位置が固定ならエネルギー中心が動いて運動量保存を破るので、**核（質量側）が反跳しなければならない**。この反跳が ZB（Dirac の「位置演算子がエネルギー中心の周りで振動する」と同じ意味）。反跳速度 v/c = E_γ/(E₀ − E_γ) から E_γ = 19.9 keV（厳密）≈ 20.7 keV（非相対論）。独立の仮定（遷移率 f = v/λ_C → hf = 20.68 keV）と一致。

**T1.6 双極子的幾何——何の双極子か** 電荷の双極子ではない：e·λ_C ≈ 2.4×10⁻¹⁰ e·cm に対し電子 EDM 上限 4.1×10⁻³⁰ e·cm（JILA 2023）で 20 桁排除。**エネルギー（熱）の双極子**である：#1 の勾配 ∇(T_B − T_A) ∝ E₀ sin θ が向きを持つ双極子モーメント。ただし半周期ごとに反転する振動双極子で、**平均は零、二乗平均は非零**——EDM 零・磁気モーメント非零と整合。役割分担：極性ベクトル（A→B 軸 n̂、平均で消える）／軸性ベクトル（循環の向き、スピン・磁気モーメント）。**直線往復（#10「最短直線経路」、#19「共線」）だけでは軸性ベクトルが出ない**（古典的に a ∥ v、共線ブースト列の Thomas 回転は零）。#62 §2 Fig. 1 は既に弧 L₀ = 2πr と循環の向きを描いており、幾何は変わっている（K6）。双極子が平均で消えたあと残る最低次のエネルギー多重極は**四重極**（rank-2）で、振動するのはエネルギー層（2π 周期）であって振幅層（4π 周期）ではない。重力波出力 ≈ 4×10⁻⁴⁴ W（宇宙年齢で 10⁻⁷ eV）、安定性は無傷。輻射核・吸収核の対は遠方場を持たない閉じた放射交換（自己吸収する二素子アンテナ）。

**補（2026-09-14、幹 T2 の T2.13 より）** ── 「電荷の双極子ではない」に構造的な理由が付いた。電荷は核に局在する量ではなく、振幅平面 (a, b) の軌道が原点のまわりを回る**保護された巻き数**（系全体に一つ付く整数）である。核に電荷が無い以上、核対が作る双極子は電荷双極子になりようがなく、EDM 零は上限との整合ではなく構造からの帰結になる。**二つの ℤ₂ を混ぜないこと** ── 本項の軸性ベクトル（実空間の循環の向き＝スピン）と、電荷共役（内部平面の反射 b → −b）は別の ℤ₂ である。両者の独立性の証明は幹 T2 の K16。

**T1.7 スピノールの発生機構** 観測量（Ω は (v,a) に双線形、KE は v に二次、TPE は温度振幅に四次）がすべて振幅の偶数次であるため、**振幅の全体符号は原理的に観測できず、振幅は観測量の平方根として Z₂ の曖昧さを持つ**——二重被覆の発生機構（SU(2)→SO(3) と同じ論理）。#10 の変数で言えば：Ω の周期 π/ω の一周で v, a は符号反転 v(t+π/ω) = −v(t)、元に戻るのに Ω の二周期を要する（720°）。#10 の 1/2 は sin²θ = ½(1−cos 2θ) の 1/2 と同一物。実二成分振幅 (T_A, T_B) の円 (θ/2) → エネルギー円 (θ) は z ↦ z² の U(1) 二重被覆（#3 の Riemann 面）＝SU(2)→SO(3) の実断面。**完全な SU(2) には回転軸が要る**（#10 の Ω が e_z を欠く問題、#19 が補う）→ K6 と同じ分岐。光子との差：光子の偏光は場（観測層）そのもので、平方根の振幅層を持たない。「内部が見えないこと」と「スピン 1/2 であること」は同じ事実の二面。

**T1.8 二つの ½** **エネルギーの ½**（#46 の床。β² 層に置けば床 = (γ−1)mc² = (a_e/√2)mc² = 419 eV → 「内部振動子の零点エネルギー＝異常磁気モーメントのエネルギー」）と、**作用の ½**（スピン ħ/2、ΔxΔp ≥ ħ/2、Bohr–Sommerfeld (n+½)h、Nelson の拡散係数 ħ/2m）は別物。弧（λ_C、0.0405c）が作用の ½ を供給できる割合は、どの量で測っても **2πβ = 0.254 = 1/3.93**：

|---|---|---|
| Nelson の拡散係数 D = ℓv/2 | ħ/2m（厳密に一致） | 0.254 × ħ/2m |

三つが同じ比で足りないのは「弧の長さ × 運動量」という同じ積だから。**スピン ħ/2 の約 3/4 は熱（核）側に蓄えられている**：J_total = ħ/2 = J_TPE(θ) + J_KE(θ)、J_KE は 0〜0.13ħ を振動、J_TPE がその補分（「熱エネルギーが角運動量を持ったまま KE に転化し、系として保存する」の定量形）。同じ計算で循環の軌道磁気モーメントは 0.127μ_B（μ_B でも a_eμ_B でもない）。

**T1.9 自由電子の ½＝自己閉じ込め** 従来 QM に自由粒子の ½ はない（E = p²/2m、床なし）。ħω/2 は井戸の壁が Δx を強いた結果。0SM は電子が**自分自身の壁**（A–B の弧）を持つがゆえに外部の井戸なしに ½ を持つ——#33「幾何学的閉じ込め＝静止質量」の ½ による言い直し。**S⁰ は唯一弧状連結でない球面**（二点）。0SM とは「S⁰ を一本の弧で弧状連結にしたもの」であり、弧の有限な長さ λ_C が井戸の壁の代わりに Δx を与える。弧状連結をブラウン運動の由来と採るのは Nelson（1966）・Feynman checkerboard（±c のジグザグ → Dirac）の系譜で、0SM は「決定論的」「亜光速」の二点で踏み込む。連続性（跳びがない）は弧状連結が、乱雑さの量（ħ/2m）は弧と核の両方が担う（T1.8）。

**T1.10 零点の取り出し不能性** π/4（#46 記法）で KE = E₀/2 を全部取り出すと TPE = E₀/2 で T_A = T_B、勾配零、振動子は凍結——取り出した先は「より低い電子」ではなく「電子でないもの」。標準理論の「下の状態がない」と同じ言明。さらに 0SM 固有の一文：**電子の内部エネルギーを取り出す唯一の過程は対消滅（#8）であり、½ ではなく全部を、負エネルギーの相方（#7）と一緒でなければ取り出せない**。n + ½ の階段では n が井戸（外側、創発的波動関数の節）、½ が振動子の床——井戸に入れても内部の床は変わらない。井戸の ħω_well/2 は井戸の振動数で決まり ZB の床とは数値が違う（同じ構造的理由で各階層に ½ が付く、が正確な言い方）。井戸の中の電子は折り返し点 ±a を二核とする外側の二核構造をもう一つ持つ（入れ子）。

**T1.11 「なぜ亜光速か」は「なぜ α か」** 一次で v_ZB/c ≈ √(√2 a_e) ≈ **√(α/(√2π)) = 0.04053**（高次込み 0.04047 と 0.15%）。恒等式は形（1/√2 の比）、α は尺度。質量非依存 → **レプトン普遍性**：μ は 0.04058c（電子と 0.27% 差、質量比 207）。ハドロンは |a| で 0.9c 台（p 0.898、n 0.905）——点状／複合の区別が内部速度の二つの島として現れる。「電子に内部構造がある」の内実は**エネルギー分配の構造であって電荷分布の構造ではない**（形状因子上限 < 10⁻¹⁸ m と λ_C = 2.4×10⁻¹² m の両立）。Dirac の v = c を覆すのではなく**振幅と振動数の割り当て**を覆す（Dirac：振動数 2mc²/ħ を固定し振幅 λ̄_C/2；0SM：振幅 λ_C を固定し振動数を 0.04 倍）。内部線は 10–20 keV。

**T1.12 一つの恒等式** (γ−1)_peak mc² = a_e mc² = (α/2π)mc² = **αħc/λ_C = 593.5 eV**：橋渡しの余剰エネルギーは、電荷 e 二つを λ_C 離した静電エネルギーに一次で厳密に一致（λ_C = 2πħ/mc、Schwinger の 2π と Compton の 2π が同じ 2π）。二核間距離 λ_C（#1/#10）と合わせ「γ−1 は二核間の Coulomb 的結合エネルギー」という読みが浮上。機構は後（#28 の作法）。**補（2026-09-14）** ── 幹 T2 の T2.13 により電荷は核に局在しない巻き数なので、「電荷 e 二つを λ_C 離した」という読みは**採らない**。数値の一致 αħc/λ_C = (γ−1)_peak mc² は無傷で、読みは「**α × 搬送体のエネルギー尺度 ħc/λ_C**」── 結合定数 α が構成関係 ⋆ の側から入る唯一の場所（幹 T2 の K12）。K8 と一緒に扱う。

**T1.12 補 — 橋渡し方程式の機構（2026-09-07）** 現状の T1.12 は γ_v = 1 + |a|/√2 という**関係式**である。ここに機構を付ける。

**思考実験** ── 搬送体（光子球）の共動系で電子を観測すれば、異常磁気モーメントは現れず **g = 2 が厳密に成り立つ**のではないか。数値では β_ZB = 0.040472 → γ − 1 = 8.19999×10⁻⁴ → **√2(γ−1) = 1.15965355×10⁻³**、a_e（実測） = 1.15965218×10⁻³ で**一致 1.2×10⁻⁶**。すなわち **a = √2(γ_ZB − 1)** であり、**γ_ZB = 1 のとき a = 0、g = 2**。**思考実験と橋渡し方程式は同じ命題の表と裏である。** √2 は周期にわたる γ の変動を RMS で拾うことに対応し、T1.3 の相対揺らぎ 1/√2 と同じ因子である（→ K9）。

**述べ方の制約（必ず守ること）** ── a は共変な Pauli 項 (a·e/4m)ψ̄σ^{μν}ψF_μν の係数であり **Lorentz スカラーである。慣性系を取り替えて消えるものではない。** したがって「ブーストで a を消す」とは書けない。**書ける形は一つ ── 共動系は搬送体が振動しているので非慣性であり、a はその非慣性共動系から実験室系へ移ることの運動学的残差である。** 前例がある ── **Thomas 歳差（1926）** は電子の共動系が回転していることだけから磁気的相互作用に因子を与え、微細構造の因子 2 の食い違いを解決した。**磁気モーメントの因子が力ではなく系の取り方から出た実例**であり、本命題はその型に属する。

**現状の限界** ── (1) **予言ではなく整合性である**。β_ZB は a_e から 6 桁決められているので循環であり、予言に変えるには β_ZB の独立決定が要る（→ K8）。(2) **QED は a を 10 桁与える**。Schwinger 項 α/2π だけでは実測から 0.152% ずれ、高次項が計算されて一致している。(3) **三世代の予言にはなっている**（§3 の β_ZB 表）。ただし β_μ/β_e − 1 = 2.70×10⁻³ を μ の寿命に使うと 11 桁外れる（幹 T2 の T2.5）ので、同じ差が二つの現象を同時に説明できるかは未解決。

**T1.13 K13 の決着 — 境界項は閉じ込め力のビリアルである** テンソルビリアル恒等式 d²M^{jk}/dt² = 2c²∫T^{jk}dV + S^{jk} を局所保存則から導き、0SM の内部配置に適用した。境界項の周期平均は

⟨S⟩ = −(E₀/2)[1 + (405π²/256)β²] = −0.51278774 E₀ （d = λ_C）

形状因子は厳密有理数 **405/4096**。補正項は O(β²) で 2.56%、先頭項 −E₀/2 は核間距離の規約にも搬送体の閉包の取り方にも依らない（四通りの閉包で 0.5% 以内）。**この値は偶然ではない** ── 恒等式から床 E₀/2 を除いた残りは変位 D の単位調和振動子であり（幹 T2 の T2.2）、調和振動子のビリアル定理 2⟨T⟩ = E_osc が要求する値と厳密に一致する。**境界項は領域の境界が供給する閉じ込め力のビリアルそのものである。**

S(θ) は核の位置 θ = 0, π で厳密に消え、θ = π/2, 3π/2 で最大 |S| = 1.0768 E₀ となる。**これは #58 が位相安定対の放出事象を置いた二点と一致する。** 全周期を通じて符号を変えない。核の空間トレースを輻射（トレースレス）と採ると ⟨S⟩ = −2E₀ となり **4 倍変わる**（→ K12）。

**T1.14 T1.5 の定理化 — 核固定は不可能である** 核を固定したまま質量双極子の拘束 Σ E_i x_i = 一定 を満たすには、搬送体が u(θ)/d = cos θ/sin²θ の位置にいなければならず、これは θ = 0, π（核の位置）で**極を持つ**。大きな値ではなく発散であり、搬送体は領域の外に出る。**核固定は排除される。** T1.5 は解釈の一つではなく保存則からの帰結である。

反跳を許すと閉包は一意に決まる ── X(θ)/d = ½cos θ[1 + ½sin²θ]、双極子残差 D(θ) ≡ 0（記号的に厳密）。幾何学的な意味は **エネルギーを持っている側の核が常に重心の位置に座る**ことで、核対は ±d/2 だけ振れる。**Zitterbewegung の振幅は核間距離そのものであり、自由に選べるパラメータではない。** 主要項は ½D（幹 T2 の T2.3 の質量双極子）。

**T1.15 四重極の高調波構造** 同じ配置の二階モーメントは閉じた形を持つ。

Ĵ(θ) = sin⁴θ(1 + sin²θ)/16 = [22 − 31cos 2θ + 10cos 4θ − cos 6θ]/512

その三階微分の自乗平均は厳密に **4045/4096**。重力波出力は P = 1.00×10⁻⁴³ W（宇宙年齢で 2.7×10⁻⁷ eV、安定性は無傷）で、単一高調波の見積もり 3.8×10⁻⁴⁴ W の 2.6 倍。**内訳が要点である** ── 出力の 11.88% が 2ω、**79.11% が 4ω（2.00×10¹⁹ Hz、82.7 keV）**、9.01% が 6ω に乗り、**奇数次は恒等的に消える**。奇数次が消えるのは四重極が核入れ替えに対して偶パリティだからである（幹 T2 の T2.4）。ただし高調波の振幅は搬送体の閉包に敏感で、閉包を変えると P は最大 8 倍動く ── **四重極出力を数字として主張するには、点質量の戯画ではなく #57 の a_ℓm による実分布から T_μν を組む必要がある**（N1 への直接の指示）。

**T1.16 核における三階平坦性 — A → B → A′ は滑らかに繋がる** 反跳閉包の軌道 X(θ) = ¼(sin²θ + 2)cos θ を核で展開すると

X′(0) = X″(0) = X‴(0) = 0、　最初に消えないのは X⁗(0) = −9/2（θ = π では +9/2）

**速度だけでなく加速度も躍度も消える。** X − X(0) ≈ −(3/16)θ⁴ で、**核において軌道は三階まで平坦**である。これは自明ではない ── 単振動なら折り返し点で加速度は最大である。**反跳閉包という条件がこの平坦性を作っている。**

**帰結** ── 自由電子が並進するとき A → B → A′ で A ≠ A′ となってよく（保存則は非閉性を禁じない）、その軌跡は核で折れ曲がっても **C³ で繋がる**。一般論としては「速度が消える点では像に角があってもパラメータ付き曲線は C¹ になれる」（r = (t³,|t|³) で片側速度は両方零、C¹ だが C² ではない）だけだが、0SM の軌道はそれより二階良い。

**論拠の指定** ── 「KE = 0 だから搬送体が止まる」は搬送体が質量を持つ場合の推論である。搬送体が光子ならエネルギー零は「静止」ではなく「不在」を意味する。**論拠はエネルギー重心 X(θ) の三階平坦性に置くこと。**

**歩幅について（誤りを一つ記帳しておく）** ── 「一周期あたりの前進 β_ZB c T_ZB が λ_C に一致する」という読みは**採らない**。ν_ZB ≡ v_ZB/λ_C は定義（#67 Eq. nuZB）なので同語反復であり、さらに **v_ZB は螺旋の横断速度であって並進ドリフトではない**（§0）。正しく残るのは ── 静止系では X(θ) は周期的で **A = A′**、歩くのはブーストした系だけで、実験室系の歩幅は **(βγ/β_ZB)·λ_C**（β は並進速度）。β = 0.999999 で 1.7×10⁴ λ_C。Dirac の自由電子の位置演算子が「一様なドリフト＋ Zitterbewegung」に分かれるのと同じ形である。

**T1.17 内部固有加速度 — 等価原理により内部重力場である** 同じ軌道の二階微分は閉じた形を持つ。

**X″(θ) = −(9/4)sin²θ cos θ** 　（最大値は厳密に **√3/2**、θ ≈ 234.7°、**核では零** ── T1.16 と整合）

固有加速度の最大値は **a = ω²λ_C·(√3/2) = 2.07×10²⁷ m/s²**。**電子の内部には、核で零・赤道近くで最大となる 10²⁷ m/s² の加速度場がある。** 等価原理を通せばこれは電子の内部重力場であり、**T1.12 補の「共動系は非慣性である」と同一の扉**である。

**重力時間遅れとの接続** ── 内部時計を ν_ZB と同定すると、高度による時計の進みの差が内部振動数のずれとして書ける（§3 の高度表）。機構としては E₀ → E₀(1 + Φ/c²)、すなわちアインシュタイン 1911 年の論法の再導出であって**新しい機構ではない**。文献上の住所は Müller–Peters–Chu（*Nature* 2010）と Wolf らの論争である。

**検査の在処は #67 が既に確定している** ── a は無次元で ν_ZB と測定時計が同じ因子で偏移するので**一次の試験は無く**、これは #67 が「Penning トラップの比 ν_a/ν_c では装置の共通赤方偏移が厳密に相殺する」と述べているのと同じ言明である。β_ZB が Φ に応答する読み（#67 の Reading B）は k_a ≡ (c²/a)(da/dΦ) = 2 を要求し、Lange ら（2021）の k_α = 14(11)×10⁻⁹ に対して**八桁で排除済み**（Ferrell ら 2007 でも既に五桁）。**β_ZB は局所不変量である。** 残る識別実験は年周変調 Δ(g/2) = 7.65×10⁻¹³（ΔΦ/c² = 3.299×10⁻¹⁰、Fan ら 2023 の不確かさ 1.3×10⁻¹³ に対し比 5.9）ただ一つで、#67 がそれを記帳している。**幹はこれを未確認事項として持たない。**

これにより **幹 T2 の K6 は「なぜ内部位相が一様に進むのか」から「何が位相の進む速さを決めるのか」へ変わる**（400 km で ν_ZB は毎秒 2.06×10⁸ 回多い）。
