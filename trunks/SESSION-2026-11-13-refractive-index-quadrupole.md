2. **群速度の根拠**（#66 付録 B）: 恒等式はエネルギーを一度に移さない。輻射勾配 F = sin θ は二核のエネルギーの微分の差として厳密に出る（#1 の勾配）。**一定振幅の輻射の描像は恒等式が排除する**。核のエネルギーは 3/8 + ½cos θ + ⅛cos 2θ ── **位相では連続、振動数では離散**。恒等式は振動数ごとに三つの釣り合いに分かれる。線の本数はエネルギーの冪（二乗）で決まる。二本の線の群屈折率は n_g = 2n(2ω) − n(ω)。ガウシアン波束と違い、包絡線は毎周期同じ形に戻り、広がらない。
3. **「輻射」の二義**（#66 付録 A.6）: 本系列の輻射は核間の内部の受け渡し。電磁波の放出ではない。外部の光子との結合は O6 として別に置いた。
4. **内部振動の起源は扱わない**。恒等式が記述するのは持続（#66 の Scope 段落）。
5. **#67（仮版）**: 恒等式の三つの通り道 ── 定数（単極子）／ω（A ↔ B、反対称）／2ω（核 ↔ 光子球、対称）。反跳閉包で双極子が恒等的に零 → ω は重力的に沈黙。四重極 J = E₀d² sin⁴θ(1 + sin²θ)/16 は偶数次（2ω・4ω・6ω）のみ、出力の 79.11 % が 4ω（82.7 keV）。**一般相対論の多重極階層（単極子保存・双極子放射なし・四重極から）と一致**。重力荷は定義しない。
