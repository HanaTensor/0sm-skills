- **P4 ＝ 恒等式をもう一度まるごと二乗したもの** ── E₀[cos⁸ + 4cos⁶sin² + 6cos⁴sin⁴ + 4cos²sin⁶ + sin⁸](θ/2) ＝ E₀(TPE + KE)²。スピン 2 のコヒーレント状態の完全性そのもの（電子の三項はスピン 1）。

## §1 恒等式の全数列挙（H1）

占有層で書く（T1.1）── c = 𝒯_A = cos²(θ/2)、s = 𝒯_B = sin²(θ/2)、c + s = 1、D = c − s = cos θ。恒等式 Σ a·c^i s^j = 1（a は正の整数）を全数で数える。c = 1/2 で評価すると各係数は a ≤ 2^(i+j) に押さえられるので、探索は有限で漏れがない。

| 次数の上限 | 2 項 | 3 項 | 4 項 | 5 項 |
|---|---|---|---|---|
| cos⁸（i + j ≤ 4） | 1 | 4 | 16 | 79 |

三項は四つだけである ── 電子の c² + 2cs + s²（cos⁴ + 2sin²cos² + sin⁴）、c + cs + s²、c² + cs + s、そして **c³ + 3cs + s³（cos⁶ + 3sin²cos² + sin⁶ = 1、電子の式の「立方」版）**。五項のうち cos ↔ sin で対称なものは 7 個。

**主項と渡り項の見分け方** ── 電子では主項（TPE）が c², s²（自乗）で、渡り項（KE）が cs（交差）であった。これを一般化して、単項式 c^i s^j を **i, j がともに偶数なら主項（N）、ともに奇数なら渡り項（L）、それ以外を混合（x）**と呼ぶ。全次数 i + j が奇数の単項式（cos²・cos⁶ の層）は**必ず混合**になる（H1）。著者の挙げた「cos⁴ と cos⁶ の組み合わせ」は、cos⁶ の層の項（cos⁴sin² など）を含む限り、主項とも渡り項とも言えない。

### S1 分類（cos¹² まで全数で確認。H1）

> 五項で、(a) cos ↔ sin（核 A ↔ B）で対称、(b) 主項と渡り項だけからなり、(c) cos の取り分の順に**主–渡り–主–渡り–主**と厳密に交互に並ぶ恒等式は、cos¹²（i + j ≤ 6）まで探して**次の二つだけ**である。
>
> **C5**: cos⁴ + 2cos⁶sin² + 4cos⁴sin⁴ + 2cos²sin⁶ + sin⁴ = 1
>
> **P4**: cos⁸ + 4cos⁶sin² + 6cos⁴sin⁴ + 4cos²sin⁶ + sin⁸ = 1 （引数はどちらも θ/2）

手で見ても同じである。中央の主項は c²s² しかない（(m, m) で m が偶数）。対称な和を x = cs で書くと c² + s² = 1 − 2x、c⁴ + s⁴ = 1 − 4x + 2x²、c⁶ + s⁶ = 1 − 6x + 9x² − 2x³、c³s + cs³ = x(1 − 2x)、c⁵s + cs⁵ = x(1 − 4x + 2x²)。端の係数は c = 1 で 1 に決まる。x の各次の係数が消えるのは（端 c²、渡り c³s）で渡りの係数 2・中央 4（C5）と、（端 c⁴、渡り c³s）で 4・6（P4）の二組だけで、残りは x³ が消え残る。

## §2 二つの五項モデル（S2–S10）

### S2 P4 ＝ 恒等式をもう一度二乗したもの ＝ スピン 2（H2、H4）

E₀[cos⁸ + 4cos⁶sin² + 6cos⁴sin⁴ + 4cos²sin⁶ + sin⁸](θ/2) = E₀(TPE + KE)²。五項は **Wigner の小 d 行列の一行 |d²_{m,2}(θ)|²（m = 2, 1, 0, −1, −2）**に一致し、恒等式はスピン 2 のコヒーレント状態の完全性である。電子の三項は |d¹_{m,1}(θ)|²（スピン 1）であり、T1 §4 の「三チャネル (a², √2ab, b²) は対称二乗 Sym²χ = spin-1 の三成分」の次の段が Sym⁴χ = spin-2 になる。**主項は m が偶数（±2, 0）、渡り項は m が奇数（±1）。** cos⁶ 系 cos⁶ + 3cos⁴sin² + 3cos²sin⁴ + sin⁶ は |d^{3/2}|²（スピン 3/2）である。

**注意（二義）** ── ここの「スピン j」「m」は二核の振幅 χ の対称積の添字であって、核子の物理的スピン（1/2）でも軌道の ℓ でもない。N1（ℓ = 1 → ℓ = 2）との類似は数え方の一致であって同定ではない。

### S3 C5 ＝ 搬送体だけを一段開いたもの（H4）

E₀[TPE_A + TPE_A·KE + KE² + TPE_B·KE + TPE_B]、すなわち **KE → KE·(TPE + KE)**（恒等式を光子球の項にだけ一度掛ける）。

| 項 | 式（引数 θ/2） | 読み |
|---|---|---|
| 主項 A | cos⁴ = TPE_A | 電子の核 A そのまま |
| 渡り項 A | 2cos⁶sin² = TPE_A·KE | 核 A × 光子球 |
| 主項（中央） | 4cos⁴sin⁴ = KE² | 光子球の自乗 ── 光子球が第三の座を持つ |
| 渡り項 B | 2cos²sin⁶ = TPE_B·KE | 核 B × 光子球 |
| 主項 B | sin⁴ = TPE_B | 電子の核 B そのまま |

中央 ＋ 渡り項 ＝ KE なので、**粗く見れば C5 は電子と同じ帳簿**（TPE と KE）であり、光子球の内訳だけが増えている。

### S4 なぜ「三 ＋ 三」でなく「三 ＋ 二」か ── 両端の干渉は中央に吸収される（H3）

任意の三つの置き場 n₊ + n₀ + n₋ = 1 を二乗すると六項（自乗三つ、交差三つ）になるが、添字の和 M = m₁ + m₂ で束ねると五つになる。

P(2) = n₊²、P(1) = 2n₊n₀、**P(0) = n₀² + 2n₊n₋**、P(−1) = 2n₀n₋、P(−2) = n₋²

**両端どうしの干渉 2n₊n₋ は M = 0 を持ち、中央の主項に入る。** 電子の置き場（n₊ = c²、n₀ = 2cs、n₋ = s²。n₀² = 4n₊n₋ ── 集団遺伝学の Hardy–Weinberg 曲線と同じ式）に乗せると、五つの束はちょうど P4 の五項になり、中央 6c²s² ＝ KE²（4c²s²）＋ 2·TPE_A·TPE_B（2c²s²）で**比 2:1**。群の言葉では、スピン 1 のコヒーレント状態を二乗したものにはスピン 0 の成分 (2x₊x₋ − x₀²)/√3 が恒等的に無い（H3 で 0）── だから「六」でなく「五」になる。

**QCD の側の像** ── 静的な三クォークのポテンシャルは、格子 QCD で Y 型（Coulomb 和 ＋ 最小の弦の長さに比例する線形項）と測られている（Takahashi・Matsufuru・Nemoto・菅沼 2001、2002）。三角形の一つの角が 120° 以上になると Y の分岐点はその頂点のクォークに乗り、弦は二本になる。**「三 ＋ 二」はこの配置の代数的な姿**であり、両端の干渉が中央に吸収されることが、分岐点が真ん中のクォークに乗ることに対応する。**類比であって導出ではない。** 一般の配置（分岐点が三点の内側）は二核の二項式では表せない ── 三つの独立な占有、すなわち三核が要る（K-b）。

### S5 奇数次は使えない ── 旧 K7 の異議の正しい範囲（H2、H13）

主項／渡り項のパリティ (−1)^(j−m) は A ↔ B（m → −m）で、**2j が偶数のときだけ不変**である。j = 3/2（cos⁶ 系）では主項と渡り項が入れ替わる ── cos⁶ の端は、A ↔ B で渡り項の位置に移る。したがって **cos⁶（奇数次）の層の恒等式は、A ↔ B 対称な「三 ＋ 二」を担えない。**

旧 K7 の「(n_A + n_B)³ の中央二項は A↔B で互いに移り合う非対称な対であって、対称な二つの搬送体ではない」は、**まさにこの半整数の入れ替わりであり、p = 3 に対しては正しい。** ただし偶数次では、渡り項が鏡像の対になるのは鎖としてむしろ当然である ── 一本目は端 A と中央を、二本目は中央と端 B を結ぶので、A ↔ B で互いに移る。**異議は p = 3 で生き、p = 4 と C5 では解ける（変形）。**

### S6 主項と渡り項の閉じた形と平均（H4、H5）

| 模型 | 主項 N | 渡り項 L | N − L | 位相平均（五項・三項） | ⟨N⟩ : ⟨L⟩ |
|---|---|---|---|---|---|
| 電子 E2 | (1 + D²)/2 | (1 − D²)/2 | D² | 3/8, 1/4, 3/8 | 3/4 : 1/4 |
| **P4** | (1 + D⁴)/2 | (1 − D⁴)/2 | D⁴ | 35/128, 5/32, 9/64, 5/32, 35/128 | 11/16 : 5/16 |

- C5 の渡り項は P4 のちょうど半分である。
- **平均がちょうど 1/4 になる項の組は、P4 には無く、C5 では「中央 ＋ 渡り項」だけ**（＝ 電子の KE）。偶数次の二項 (c + s)^(2m) で ⟨N⟩ = 3/4 になるのは m = 1（電子）だけで、m が増えると 11/16, 21/32, 163/256, … → 1/2。

### S7 0SM 自身の規準で選ぶ ── C5（H6）

- **調和性（T1.9 の第二規準）**: C5 の核の差は TPE_A − TPE_B = D = cos θ で**厳密に純粋**（T1.10 の力 −sin θ もそのまま）。P4 の端の差は (7/8)cos θ + (1/8)cos 3θ で、**a₃/a₁ = 1/7**（p = 4 の非調和）。
- **置き場の勘定（T1.9 の第一規準）の読み**: 電子で二度目の二乗が要った理由は「二核が離れているので、輸送中のエネルギーに席が要る」であった。光子球が局在して座を持つなら、核と光子球の間にも輸送の席が要る ── 増えるのは中央の座一つと渡りの席二つで、**C5 はちょうどそれだけを足す。** P4 は核の座まで割り直す。**（この段落は読み）**
- **平均配分**: C5 は電子の 3:1（核：光子球由来）を保つ。P4 は崩す。

**見立て: 主案は C5、群論の側の案として P4 を並べて残す。** 判断は著者に属する（§6 の 1）。

### S8 力学の読み ── 位置に依る慣性と四次のポテンシャル（H7）

x = D = cos t（θ̇ = 1、ẋ² = 1 − x²）と置くと、渡り項は運動エネルギー、主項の床を除いた部分はポテンシャルとして読める。

| 模型 | 運動エネルギー T（＝ 渡り項） | ポテンシャル V | T + V | ⟨T⟩ : ⟨V⟩ |
|---|---|---|---|---|
| 電子 | ½ẋ² | ½x² | 1/2 | 1 : 1（T1.3 の調和振動子） |
| P4 | ½(1 + x²)ẋ² | ½x⁴ | 1/2 | 5 : 3 |
| C5 | ¼(1 + x²)ẋ² | ¼x⁴ | 1/4 | 5 : 3 |

一次元なので、エネルギー保存だけで x = cos t が厳密解になる。**第三の座の代価は、慣性が位置に依ること（核の側で重い）と、ポテンシャルが四次になることである。** 比 5:3 は定数の慣性での四次の値 2:1 とは違うが、位置に依る慣性の項を入れた一般化ビリアル ⟨mẋ²⟩ + ⟨½ x m′ ẋ²⟩ = ⟨xV′⟩ は厳密に成り立つ（P4 で 3/4 = 3/4、C5 で 3/8 = 3/8）。

### S9 赤道で三つが揃い、一周で「一体 ↔ 三体」を呼吸する（H8、図）

赤道 θ = π/2（D = 0、KE 最大、#58 の放出位相）で:

- **C5: 主項 1/4, 1/4, 1/4、渡り項 1/8, 1/8**（三つの主項が等しく、二本の渡りも等しい）
- P4: 1/16, 1/4, 3/8, 1/4, 1/16

ただし θ = 0, π では全エネルギーが一方の端に集まる（図）。**一角の模型は、一周のあいだに「一体」と「三体」の間を呼吸する。** したがって主項は**エネルギーの置き場**であって、常にそこにいる構成子ではない。QCD の三つの価クォークは常にそこにいる（バリオン数）── **主項 ＝ 価クォーク、とは読めない。**

### S10 二つの系列（H4）

- **P 系列**: P₂ₘ = (TPE + KE)^m = (c + s)^(2m)。スピン m のコヒーレント状態。主項 m + 1 個、渡り項 m 個。核は m ≥ 2 で非調和。
- **C 系列**: C_k = TPE·(1 + KE + … + KE^k) + KE^(k+1)（光子球を k 回開く。幾何級数の打ち切り）。主項 k + 2 個、渡り項 k + 1 個、**核はいつも p = 2 で調和**。k = 0…3 で和 1・交互を確認した。

著者の「三 ＋ 二」は P₄（m = 2）と C₁ ＝ C5（k = 1）にあたる。
