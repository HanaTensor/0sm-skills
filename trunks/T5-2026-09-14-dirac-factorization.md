## §1 命題

### T5.1 因数分解と Clifford 代数

$E^2 = p^2c^2 + m^2c^4$ を一次の積に分解する条件は

$$\beta^2 = 1,\quad \alpha_i^2 = 1,\quad \{\alpha_i,\beta\}=0,\quad \{\alpha_i,\alpha_j\}=2\delta_{ij}$$

である。「平方完成」ではなく「因数分解」と呼ぶ理由は、$x^2 - y^2 = (x-y)(x+y)$ の形に落とすために係数の**反交換**が必須であり、その反交換が以下の全命題の源だからである。因数分解は、二つの互いに直交する軸（$\beta$ と $\alpha$）を生む。

### T5.2 一次の cos, sin の正体

静止系（$\mathbf p = 0$）で $H = \beta mc^2$。$\beta$ はエルミートで固有値 ±1 が異なるので、固有ベクトル $|+\rangle, |-\rangle$ は直交する（第一の直交性）。実係数の重ね合わせ

$$|\psi\rangle = \cos\theta\,|+\rangle + \sin\theta\,|-\rangle$$

の cos θ, sin θ が、恒等式の一次の cos, sin である。**正エネルギー成分の振幅が cos θ、負エネルギー成分の振幅が sin θ。**

### T5.3 三層（T2.0 の継承）

| 層 | 量 | 名 |
|---|---|---|
| 一次 | cos θ, sin θ | 振幅 |
| 二次 | cos²θ, sin²θ | 占有確率（T2.0 の「温度」層） |
| 四次 | cos⁴θ, sin⁴θ | エネルギー |

### T5.4 二軸の期待値と単位円

$\alpha$（一成分 $\alpha_x$）は $\beta$ と反交換するので、$\beta$ の固有基底では $|+\rangle \leftrightarrow |-\rangle$ を入れ替える。T5.2 の状態で

$$\langle\beta\rangle = \cos^2\theta-\sin^2\theta = \cos 2\theta,\qquad \langle\alpha_x\rangle = 2\cos\theta\sin\theta = \sin 2\theta$$

したがって

$$\langle\beta\rangle^2 + \langle\alpha_x\rangle^2 = 1 .$$

これは反交換する二軸が Bloch 球上で直交すること（第二の直交性）の帰結であり、等号は状態が純粋であることを意味する。

### T5.5 恒等式の三項の一次表現（本幹の主命題）

| 恒等式の項 | 一次の量 | 名 |
|---|---|---|
| $\cos^4\theta+\sin^4\theta$ | $\dfrac{1+\langle\beta\rangle^2}{2}$ | フェルミオン項（質量軸の偏りの二乗） |
| $\tfrac12\sin^2 2\theta$ | $\dfrac12\langle\alpha_x\rangle^2 = \dfrac12\left(\dfrac{v}{c}\right)^2$ | ボソン項（**速度の二乗の半分**） |
| $=1$ | $\langle\beta\rangle^2+\langle\alpha_x\rangle^2=1$ | 純粋性（単位円） |

$\alpha$ は速度演算子（$\mathbf v = c\boldsymbol\alpha$）であるから、ボソン項は $c = m = 1$ の単位で運動エネルギー $\tfrac12 v^2$ の形をしている。TPE と KE が交換するという 0SM の骨格は、**質量軸と速度軸を直交座標とする単位円**として一次で書ける。フェルミオンとボソンの同居とは、質量と速度が同じ単位円の直交座標であることである。

### T5.6 交差項はコヒーレンスである

密度行列 $\rho = |\psi\rangle\langle\psi|$ の純粋度 $\mathrm{Tr}\rho^2$ は

- 純粋状態: $(\cos^2\theta+\sin^2\theta)^2 = 1$（恒等式そのもの）
- エネルギー基底で完全にデコヒーレンスした状態: $\cos^4\theta+\sin^4\theta$（**四次項だけが残る**）
- 差: $2\cos^2\theta\sin^2\theta = \tfrac12\sin^2 2\theta$（**正負成分の間のコヒーレンス**）

したがって恒等式 = 1 は「内部振動子は閉じた純粋な系であり、正負成分の位相関係が失われない」という物理的主張を含む。デコヒーレンスはボソン項だけを消す。

### T5.7 逆位相と配分比

$$\cos^4\theta+\sin^4\theta = \frac{3+\cos 4\theta}{4},\qquad \tfrac12\sin^2 2\theta = \frac{1-\cos 4\theta}{4}$$

四次項は 3/4 を中心に、交差項は 1/4 を中心に、正確に逆位相で振れる。平均配分はフェルミオン 3 : ボソン 1。

### T5.8 二種の直交性（整理）

1. $\beta$ の固有ベクトルが直交する（$\beta$ のエルミート性）── cos, sin を基底の座標として使える理由。
2. $\beta$ と $\alpha$ が軸として直交する（反交換）── $\langle\beta\rangle^2+\langle\alpha\rangle^2 \le 1$ が成り立つ理由。

因数分解が生んだのは 2. であり、1. はその一方の軸を選んだときに自動的に付く。

### T5.9 実射線空間 $\mathbb{RP}^1$ と二重被覆（T2.10 との接続）

θ と θ+π は同じ状態（全体の符号）を指す。実係数の状態空間は θ の円 $S^1$ ではなく、それを 2 対 1 に潰した射影直線 $\mathbb{RP}^1$。観測可能量が cos 2θ, sin 2θ でしか書けない（歯車比 2、偶数次）のは、θ の円が状態空間を二重に被覆しているからである。$\mathbb{RP}^1$ 上に符号込みの振幅を乗せた束は、正確にメビウスの帯（同語反復束）である。

**注意**: これは実振幅の符号による二重被覆であり、スピン 1/2 の 720° 周期（空間回転の SU(2) 二重被覆、#65 の Hopf）とは**別の**二重被覆である。両者の一致は静止系のこの 2 次元部分空間の中では決まらない → K1。

### T5.10 v_ZB の一次表現（T1 との接点）

本幹の読みでは

$$\frac{v_{ZB}}{c} = \sin 2\theta_0,\qquad \beta^2 = \sin^2 2\theta_0$$

で、θ₀ は負エネルギー成分の混合角。正準値 $v_{ZB} = 0.04047c$（#10、β² = 0.00163798087）を入れると

$$\sin 2\theta_0 = 0.04047,\qquad \theta_0 = 1.160^\circ,\qquad \sin^2\theta_0 = 4.10\times 10^{-4}$$

**「0SM の β² は、ディラック静止状態における正負エネルギー成分の交差項 sin²2θ₀ である」** は #10 の Eq. III.9 と照合可能な具体的言明である → K2。

### T5.11 混合の代価は β² 層（三層 β 階層との照合）

θ₀ の混合状態のエネルギー期待値は

$$\langle H\rangle = mc^2\cos 2\theta_0 = mc^2\left(1 - 2\sin^2\theta_0\right) \approx mc^2\left(1-\frac{\beta^2}{2}\right)$$

すなわち混合のためにエネルギーが $\tfrac12\beta^2 mc^2$ だけ下がる。数値で $\tfrac12 \times 0.00163798 \times 511.0\,\mathrm{keV} = 418.5\,\mathrm{eV}$。これは T1 の三層 β 階層の第三層（419 eV）と一致する。**第三層は、正負成分の混合による静止エネルギーの欠損として一次から出る。**

### T5.12 場の理論との対応

四次のフェルミオン項とボソン交換は同じ物理の二つの書き方である（W ボソンを積分して落とすとフェルミの四点相互作用、逆に Hubbard–Stratonovich 変換でフェルミオン四次項を補助ボソン場とフェルミオン双線形の結合に書き直せる。BCS のクーパー対も同型）。恒等式の中の同居は、この既知の双対性を単一振動子の水準で見ている。

### T5.13 Zitterbewegung は交差項に住む

ZB の振幅は $\alpha^*\beta$（正負成分の積）に比例し、その重みは $\cos^2\theta\sin^2\theta$ ＝交差項。速度 $c\alpha$ の期待値が sin 2θ であることの言い換え。したがって **v_ZB の観測は「ボソン項（コヒーレンス）が生きている」ことの判定**と同義である。

### T5.14 Kerr 読み（#51 との接点、点検待ち）

T2.0 の読み替え（四次は振幅について）を #51 の n(T) に及ぼすと、n は熱力学的温度ではなく振幅の二乗（強度）の関数になる。強度依存の屈折率は Kerr 媒質（n = n₀ + n₂ I）であり、熱 Fermat 計量は Kerr 媒質の Fermat 原理になる。交差項 $2\cos^2\theta\sin^2\theta = a_A^2 a_B^2$ は相互位相変調の項。ただし §7.9 により 4 次元共形の n は光を曲げないので、効くのは 3 次元 Fermat 計量＝物質の経路の側 → K3。

## §3 従来のディラック方程式の解釈との相違（大前提）

標準的な解釈では、自由電子の静止状態は正エネルギーの固有状態であり、負エネルギー成分の混合はゼロである。ZB は正負成分の重ね合わせにのみ現れる干渉項であり、純粋な正エネルギー状態では消える。負エネルギー解は反粒子（あるいは海）として処理される。

本幹の読みはここで分かれる。

1. **物理的な電子は、正負エネルギー成分の固定された混合状態**であり、混合角 θ₀ は内部固有の定数で、$\sin^2\theta_0 \approx 4.1\times10^{-4}$。
2. その帰結として ZB は消えず、速度 $v_{ZB} = c\sin 2\theta_0 = 0.04047c$ を持つ（光速ではない）。
3. 混合の代価は静止エネルギーの欠損 $\tfrac12\beta^2 mc^2 = 419$ eV（T5.11）。
4. 負エネルギー成分は反粒子ではなく、**同じ一個の振動子の第二の核**（T2 の核 B）であり、恒等式の中で核 A と TPE／KE を交換する。

この相違は、0SM が v_ZB を「パラメータフリーの未測定の第一義的予言」とする理由の一次での言い換えである。枝はこれを前提とし、再審理しない。

## §4 記帳（検算）

- $\cos^4\theta+\sin^4\theta+\tfrac12\sin^2 2\theta = (\cos^2\theta+\sin^2\theta)^2 = 1$ ── 記号計算で恒等的に成立。
- $\cos^4\theta+\sin^4\theta = (3+\cos4\theta)/4$、$\tfrac12\sin^22\theta = (1-\cos4\theta)/4$ ── 記号計算で成立。
- 2×2 表現 $\beta = \sigma_z$, $\alpha_x = \sigma_x$ で $\langle\beta\rangle = \cos2\theta$, $\langle\alpha_x\rangle = \sin2\theta$、$\langle\beta\rangle^2+\langle\alpha_x\rangle^2 = 1$ ── 数値・記号とも成立。
- 純粋度分解: $\mathrm{Tr}\rho^2 = 1$、対角のみ $= \cos^4+\sin^4$、差 $= 2\cos^2\sin^2$ ── 成立。
- 数値: β² = 0.00163798087 → sin2θ₀ = 0.040472、θ₀ = 1.1598°、sin²θ₀ = 4.0966×10⁻⁴、厳密な欠損 $mc^2(1-\cos2\theta_0)$ = 418.67 eV、近似 $\tfrac12\beta^2 mc^2$ = 418.50 eV（差は $O(\beta^4)$、m c² = 510.999 keV）。スクリプト実行済み（2026-09-14、全項目 OK）。
- **注意（T5.10 の性格）**: β² = (v/c)² = ⟨α⟩² は定義上の同語反復であり、非自明なのは「その ⟨α⟩ が固定混合角 θ₀ の交差項である」という同定の側である。
