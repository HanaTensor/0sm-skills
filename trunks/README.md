### 0.1 著者宣言 — 恒等式の角は回る

**恒等式の角 θ は回る。θ は内部時間そのものである** ── TPE が 100% から 0% まで複写し尽くす進み具合であり、「**輻射が停止すれば時間が停止する**」。2026-09-14 の著者判断（旧 T2 §0、旧 T5 の K2 への判断）。

**θ の進みは内部時間の定義であって、a_e が位相の速さを決めるのではない。** β は換算率である。

この宣言に乗っているもの ── 新 T2.5（電荷はロンスキアン。静的な混合角の読みではロンスキアンが β を運んで電荷にならない）、新 T5.1（相互作用項は恒等式の角の生成子。読み (a) は自由電子、読み (b) は相互作用中の電子）。

### 0.2 立場の宣言 — 隠れた変数

- **0SM は隠れた変数の理論である。** 変数は θ₀（固定の混合角、粒子の種類を決める）と φ（内部振動子の位相）。
- **「神はサイコロを振らない」の立場。** 流体力学の区別で言えば場（オイラー）ではなく**ラグランジュ記述**（Madelung–Bohm の系譜であって Nelson ではない）。
- **「隠れた」は場の側の語である**（2026-09-15c 追記。上のラグランジュ宣言の帰結）。粒子法（SPH）で粒子が密度や内部エネルギーを担うのは当たり前であり、場の記述はそれを**平滑化して再構成**したものにすぎない。**平滑化で消える量を、場の側が「隠れた」と呼んでいる。** したがって「隠れた変数」には二つの意味がある ── **A ＝ 形式に無い自由度**（0SM が言っているのはこちら）と **B ＝ Bell の意味の局所隠れた変数**。**A と B は独立であり、無限定に書くと読者は B で読む。毎回どちらかを明示すること**（幹 T3 の T3.12）。下の「一粒では安全／二粒子では非局所」という分割は、**この A/B の分割と同一の切り口である。**
- **一粒の範囲では安全である。** 二準位系に隠れた変数を禁じる定理はなく、**Bell 1966 の単一スピン 1/2 の構成が足場になる。**
- **隠れた変数の理論として 0SM が持つ、量子力学にない予言が v_ZB = 0.04047c である。**
- **測定は変数を編入する**（2026-09-15c 追記）。v_ZB が実測されれば、それは「隠れた変数が実在する」ことの間接証明ではなく、**変数が自由度として形式に編入される**ことである ── 測定の後、v_ZB はもはや隠れた変数ではない。これは立場の後退ではなく、**隠れた変数が歴史上唯一勝ってきた形**である（原子、原子核の大きさ、クォーク）。EPR が求めたのは**完備性**であって、隠れていることではない。**幹 T3 の T3.12。**
- **二粒子系では非局所でなければならない**（新 T7.1 で数値的に確認）。**これは選択ではなく帰結**であり、理論が払うと決めた代価として明記する。

### 0.3 層の規約

振幅（cos, sin）／占有（cos², sin²）／エネルギー（cos⁴, sin⁴）の**三層を厳密に区別する**。

**𝒯 ＝ 温度（占有数の層）、T ＝ エネルギー（その二乗の層）**として書き分ける。**四乗は振幅についてであって温度についてではない** ── 温度についてはエネルギーは二乗である。**新 T1.1 を先に読むこと。**

温度を振幅の層に置く読み（𝒯 = cos(θ/2)）は**採らない**（θ > π で負温度を与え、観測にかからない χ → −χ で符号が反転する）。呼称は**振幅読み／占有数読み**とする（#67 の Reading A／Reading B と衝突するため）。

### 0.4 バイアス境界 B1–B5（因数分解。枝はこれを再審理しない）

- **B1（因数分解が二軸を生む）**: ディラック方程式は E² = p²c² + m²c⁴ の因数分解であり、その代償として反交換する二軸（α, β）が現れる。
- **B2（一次の cos, sin は振幅）**: 恒等式に現れる cos θ, sin θ は、質量軸 β の直交固有ベクトル（正／負エネルギー）への実射影である。
- **B3（三層）**: §0.3 のとおり。
- **B4（同居）**: 恒等式 = 1 の中にフェルミオン項（四次）とボソン項（½ sin² 2θ）が同居する。
- **B5（従来解釈との相違は明文化し、枝はそれを前提とする）**: 電子は固定混合角 θ₀ の正負混合状態であり、**負エネルギー成分は反粒子でなく核 B である**（新 T1 の K11 が維持する）。

### 0.6 議論方針

- **標準理論からの反論に対する反論の構築には時間を割かない。** v_ZB ≈ 0.0405c が観測された後の世界に立って議論する。
- **数式は検算する。** 内部整合の検査だけでは足りない ── **外部の実測限界と突き合わせること。** 実験上限・施設仕様・物性値は数年で変わるので、**幹に書かれた外部知識は古い可能性を前提に扱い、古ければ推論の誤りとは別の節に訂正として記す。**
- **検算規則二つ**: 非整数冪は**非負が保証される層（占有層 𝒯 = cos²(θ/2)）で計算する**（振幅層でやると底が負になり複素数が出る）。**臨界点は格子上の符号走査ではなく閉じた式で数える**（零点が格子点や周期の端に乗ると見落とす）。
- **誤りは消さずに記帳する。** 閉じた提案は**閉じ方の型**（運動学／統計／密度／比の不変性／定義域外）まで書く。
