# trunks/ — 壁練の「太い幹」

壁練（`0sm-wall-practice`）の成果のうち、**派生議論の起点として繰り返し使う**ものを、一つのセル（自己完結の md）として保存する場所。

## 規約

- 一幹＝一ファイル。ファイル名 `T<n>-<YYYY-MM-DD>-<slug>.md`。
- 幹は**自己完結**であること：前提（一次資料の骨組み）、バイアス境界、確立した命題（T<n>.m）、検算済み数値表、撤回・修正、枝（K.m）、派生候補、再開手順を含む。要約で代替しない。
- 派生セッションは幹を丸ごと読んでから始め、結論は「どの枝を閉じた／開いた／変形したか」で締める。幹本体を書き換える場合は**新しい日付の版**として保存し、旧版は残す。
- `wall-practice-index.md` には幹への一行の指示のみを置く（幹の内容を index に複製しない）。
- **幹どうしは主題の軸で分ける。K 番号は幹ごとに独立で、参照は「T1 の K3」の形で行う。** 枝は履歴を残さず、改訂のたびに詰め直して番号を打ち直してよい。
