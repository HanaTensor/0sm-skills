## 概要 — この幹は何を問うているのか

この幹が扱うのは、0SM の中心恒等式 **E₀ = E₀[cos⁴(θ/2) + sin⁴(θ/2) + ½sin²θ]** が何を言っているか、である。式そのものは **1 = (cos²(θ/2) + sin²(θ/2))² の展開**にすぎず、数学としては無内容である。物理はすべて、三つの項を TPE_A（核 A の熱）・TPE_B（核 B の熱）・KE（搬送体の運動エネルギー）に**割り当てる側**にある。したがって本幹の仕事は、恒等式を解くことではなく、**その割り当てが何を強制し、何を許すかを読むこと**である。最初の道具は三つの層の区別で、同じ一つの振動に**振幅**（cos, sin）・**占有数 ＝ 温度**（cos², sin²）・**エネルギー**（cos⁴, sin⁴）という三つの名前が付く。観測にかかるのは占有層より上で、振幅層は χ → −χ で符号が変わるので直接は見えない。差 **D ＝ cos θ** は補助的な組み合わせではなく、Bloch ベクトルの z 成分から温度差まで**六つの顔**を持つ、モデルが最初から使っていた量である。

本幹の最大の成果は二つある。第一に、**ボソンとフェルミオンの区別は「どちらの恒等式に従うか」ではなく、「エネルギーは占有数の何次の関数か」という一つの問いに還元される**（T1.2）。次数を選ぶ規準は二つあり、**置き場の勘定**と**調和性**が独立に同じ答えに着く ── しかも調和性は C(p,3) = 0 の実数解として、**整数性を仮定せずに実数全体から p = 1, 2 の二点だけを選ぶ**。第二に、**ディラック方程式の因数分解によって恒等式の三項に一次の量の名が付いた**（T1.14）── 四次項 ＝ (1 + ⟨β⟩²)/2、交差項 ＝ ½⟨α⟩² ＝ ½(v/c)²、恒等式そのもの ＝ 単位円 ⟨β⟩² + ⟨α⟩² = 1。交差項は正負エネルギー成分の**コヒーレンス**であり（デコヒーレンスはボソン項だけを消す）、Zitterbewegung はそこに住む。可視度の下限 **⟨V⟩ = √2 − 1 = 0.4142** も、この層の指紋として出ている。

**本幹は β_ZB の値を一度も使わない。** 数値に関わる問いは幹 T3 の領分であり、位相幾何の論拠（メビウス、二重被覆、Morse）は幹 T2 が供給する ── 本幹はその結論を使うが再導出しない。最大の未解決点は **K4** で、**恒等式の E₀ がどの層のエネルギーか（m_ec² か 2m_ec² か）と、核の空間トレースを輻射と読むか物質と読むか**は同一の問いであり、**⟨S⟩ が 4 倍変わる。** これは旧 T1 と旧 T2 に分かれていたために着手されていなかった枝で、**corpus 全体の最優先である N1（幹 T4 の K1）より先に決められる。** 次いで **K1**（エネルギー分割が二項展開であることの独立な正当化。T1.9 の唯一の残存仮定）と **K12**（交差項の ½ の由来。位相平均という候補が出ており、幹 T5 の K5 と同一かは検算で決まる）である。

**2026-09-24 の追加（T1.23–T1.25）** ── ジューコフスキー変換 ζ = z + a²/z が、恒等式の構造を一枚の絵に畳むことが分かった。円 |z| = a の像は線分（板）[−2a, 2a] で、**板の座標は差 D そのもの**（ξ = 2aD）である。変換は D の正則な延長であり、臨界点は二核だけ、KE は写像の伸び率の二乗になる。二核を焦点とする座標では変換は「振幅比を温度比に送る二乗」になり、**板の表裏は電荷共役（反射 b → −b）、メビウスはその一段下に住む**（T1.23）。逆変換は平方完成そのもので、**恒等式の円と E² = p²c² + m²c⁴ の双曲線は、同じ式 ζ² − ζ̃² = (2a)² の二つの枝であり、二核はその継ぎ目（重根）**である。1+1 次元のディラック方程式ではジューコフスキーの z がスピノル比になり、因数分解（T1.11）と平方完成は同じ平方根を取る二つの道として一致する（T1.24）。著者の問いから、**0-Sphere は点粒子の平方根の分岐点集合である**という読みが立った ── 質量という結合が交差点を二つの頂点に割る（T1.25、読み）。**この絵は K3 と K4 を一本に繋ぐ** ── 核を静止した β の固有状態と読めば、E₀ = m_ec² と「核の空間トレース＝物質」が同時に出る。ただし同日の検証（§5 の K4）で、(i) は二択ではなく四択であり、mc² 尺度は幹 T3 §4 の著者撤回と衝突することが分かった ── 判断の要は「交差項 KE が何を測っているか」の一点に絞られた。

## 現在地 — 何が閉じ、何がまだ開いているか

## 2. 確立した命題（T1.1–T1.25）

### T1.1 三つの層 ── 観測される温度は占有数の層である（旧 T2.0）

恒等式には三つの層がある。同じ一つの振動に三つの名前が付くので、どの層で語っているかを毎回明示する。

| 層 | 記号 | 定義 | 層の中で保存する量 | 観測可能性 |
|---|---|---|---|---|
| 振幅（スピノル） | a, b | a = cos(θ/2)、b = sin(θ/2) | a² + b² = 1 | **不可**。χ → −χ で符号が変わる |
| 占有数 ＝ **温度** | 𝒯_A, 𝒯_B | 𝒯 = a² | **𝒯_A + 𝒯_B = 1** | 可（観測できる最下層） |
| エネルギー | T_A, T_B | T = 𝒯² | E₀ = T_A + T_B + 2√(T_A T_B) | 可（交差項が現れる層） |

**温度が占有数の層にある論拠は符号である。** 振幅を温度と読むと（**振幅読み**）、𝒯_A = cos(θ/2) は θ > π で**負になり**、周期の半分が負温度になる。さらに χ → −χ という観測にかからない操作で温度の符号が反転する。占有数を温度と読むと（**占有数読み**）、𝒯 = a² ≥ 0 が常に成り立ち、χ → −χ で不変である。**Dirac 方程式の解はすでにスピノルの次元まで平方根を取っており、観測される温度の次元は二乗したあとの層にある。** 保存則の形も占有数読みのほうが言明として立つ ── 振幅読みの 𝒯_A² + 𝒯_B² = 1 は「温度の自乗和」という述べにくい量だが、占有数読みは **温度の総和が保存する**と一行で言える。

**呼称について** ── 初稿は「読み A／読み B」と呼んだが、**#67 が v_ZB の局所性について Reading A／Reading B を使っており衝突する。** 本幹では**振幅読み／占有数読み**と呼ぶ。

**代償は四乗の帰属である。** E ∝ 𝒯² であって E ∝ 𝒯⁴ ではない。**四乗は振幅についてであって温度についてではない。** 「四次は Stefan–Boltzmann の T⁴ だから」という #1 以来の動機付けは、構造ではなく**帰属の誤り**である（§4 に訂正を置く）。なお E ∝ 𝒯² を空間次元 d = 1 の Stefan–Boltzmann 則 E ∝ T^(d+1) と結びつける読みは**取らない**（§4）── 状態空間が S¹ であることと空間軌道の次元は別で、#67 は内部軌道を螺旋（横断・縦断の二速度）としている。**次数の根拠は置き場の勘定と調和性だけで足りる**（T2.8）。

二度の二乗の意味もここで言い直せる ── **一段目（振幅 → 温度）は「観測可能になる」二乗であり、二重被覆はこの層に住む。二段目（温度 → エネルギー）は「相互作用が生じる」二乗であり、交差項はこの層に住む。**

**既存の記号との対応**: 以下の命題では従来の記号もそのまま使う。**n = 𝒯**（占有数＝温度）、**TPE = T**（核の熱ポテンシャルエネルギー）である。#38 の I（強度）もエネルギーの層に属する。

**本幹の命題はすべてこの読み替えの下で不変である。** T2.2、T2.6、T2.9 を新しい層で書き直した残差はいずれも厳密に零で、変わるのは名前だけである。構造を動かさずに語義だけを直せることが、この同定を採る三つ目の理由になっている。

### T1.2 二つの恒等式は二つではない（旧 T2.1）

占有数で書けば n_A + n_B = 1 と (n_A + n_B)² = 1。**後者は前者の帰結であって独立な恒等式ではない。** 同じ規格化を二つの次数で読んだものである。したがってボソン／フェルミオンの区別は「どちらの恒等式に従うか」ではなく、**エネルギーは占有数の何次の関数か**という一つの問いに還元される。次数 1 なら交差項は現れず、次数 2 なら現れる。


**（旧 T1.1 を併合）**

**T1.1 恒等式の素顔** 保存恒等式 E₀ = E₀[cos⁴(θ/2) + sin⁴(θ/2) + ½sin²θ] は **1 = (cos²(θ/2) + sin²(θ/2))² の展開**で、数学的には無内容。物理はすべて三項を TPE_A, TPE_B, KE に割り当てる側にある。E = mc²（p^μp_μ = m²c² は定義、物理は慣性質量との同一視）と同型。共通の型は「**変換で作られた無次元因子を、測定可能な二量の比と等置する**」。橋渡し方程式の裸の形は **g/2 = γ_L**（g = 2γ_L）。π の話を経由する必要はない。

### T1.3 差 D と床 — ビリアル定理は破れていない（旧 T2.2）

差を取ると恒等式そのものが因数分解される。

D ≡ TPE_A − TPE_B = cos⁴(θ/2) − sin⁴(θ/2) = [cos²+sin²][cos²−sin²] = **cos θ**

**差を取った瞬間に四次が二次に落ちる。** ⟨D⟩ = 0、⟨D²⟩ = 1/2。恒等式は D だけで書き直せる。

TPE = 1/2 + ½D² 　／　 KE = ½(1 − D²)

熱ポテンシャル側は**定数の床 1/2** と**振動部 ½D²** に分かれ、⟨½D²⟩ = 1/4 = ⟨KE⟩ で **1:1**。床を引いた残りは**変位 D の単位調和振動子そのもの**（x = D、V = ½x²、T = ½(dx/dθ)²、V+T = 1/2 一定）で、ビリアル定理 ⟨T⟩ = ⟨V⟩ が厳密に成立する。⟨TPE⟩:⟨KE⟩ = 3/4 : 1/4 = 3:1 は、床をポテンシャルに含めていたための**見かけの比**であった。恒等式全体は

**E₀ = E₀/2（床、振動しない） + E₀/2（変位 D の調和振動子）**

**なぜ調和振動子になるのかの理由は T2.9 にある** ── 四次の勾配差が純粋な正弦に潰れるからである。潰れなければ非調和になっていた。

### T1.4 差 D の六つの顔（旧 T2.3）

D は補助的な組み合わせではなく、モデルが最初から使っていた量である。(1) #65 の Bloch ベクトルの z 成分 s_z（¼[(1+s_z)²−(1−s_z)²] = s_z）。s は振幅 χ に bilinear なので、差を取ると四次が二次へ落ちる。#65 Eq.(5.8) の T_e2 − T_e1 = −E₀s_z と同一の言明。(2) 核の占有数差 n_A − n_B = cos θ。**四次のエネルギー差と二次の占有数差が一致する**のは、因数分解が (n_A+n_B) = 1 を掛けているだけだからである。(3) その微分 d/dθ(E_B − E_A) = E₀ sin θ は **#1 の輻射勾配関係そのもの**（機構は T2.9）。(4) 二核の熱双極子 (d/2)(E_B − E_A) = −(d/2)E₀D、すなわち**質量双極子**。(5) エネルギー基底では |c±|² = ½ が一定だから、s_z は分岐の占有数差ではなく **± 分岐のコヒーレンス**であり、標準 Dirac 理論で Zitterbewegung を生むのはまさにこの干渉項である ── **D は Zitterbewegung そのもの**。(6) **温度差そのもの**（T2.0 の層で）── D = T_A − T_B = 𝒯_A² − 𝒯_B² = (𝒯_A + 𝒯_B)(𝒯_A − 𝒯_B) = **𝒯_A − 𝒯_B**。規格化 𝒯_A + 𝒯_B = 1 が掛かっているだけなので、**エネルギー差と温度差は数値として同一物**である。(2) の占有数差と同じ因数分解を温度の言葉で読んだもので、以後 D は「温度差」と呼んでよい。

なお「核 A = ψ⁺、核 B = ψ⁻」と文字どおり読むのは #65 Thm 3.1 と衝突する。核基底とエネルギー基底は U で結ばれた別の基底である。両立する言い方は次 ── **負エネルギー解は「吸収側の核」なのではない。それとの干渉がなければ振動が生じない第二の分岐であり、その干渉が核基底では輻射と吸収の交替として現れる。** この形なら「負エネルギー解は何のためにあるのか」への答えが「振動を可能にするため」になり、Feynman–Stückelberg（負エネルギー＝時間逆行の反粒子）や Wheeler–Feynman 吸収体理論（放射が定義されるには吸収体が要る）の系譜に載る。

### T1.5 二つのモード — 交差項が対称モードを生かす（旧 T2.4）

核の入れ替え A↔B に対するパリティで分解する。

| 恒等式 | 差（反対称） | 和（対称） | 交差項 |
|---|---|---|---|
| ボソン（全角・二次） | cos 2θ（2ω） | **1（恒等的に定数）** | なし |
| フェルミオン（半角・四次） | D = cos θ（**純粋に ω**） | 3/4 + ¼cos 2θ（**2ω**） | 1/4 − ¼cos 2θ（**2ω**） |

和の振動部と交差項の振動部は符号だけが違う同一物。**和を振動させているのは交差項そのものである。** ボソンでは対称モードが恒等的に死んでおり、フェルミオンでは 2ω で生きている。性格の違いは三重 ── 周波数（ω 対 2ω、厳密に 2:1）、パリティ（奇対偶）、担い手（核＝占有数・双極子 対 光子球＝搬送・運動エネルギー）。#65 の周波数台帳では観測層とエネルギー／スピン層、多重極では ℓ=1 と ℓ=2 に対応する。**四重極が偶数次高調波しか持たないのはこのパリティによる。**

役割分担：**比 2 を作るのは「二乗」、絶対周波数を ω に据えるのは「半角」。** 全角のまま二乗すると 2ω/4ω となり、比 2:1 は保たれ絶対周波数だけが一段上がる。半角は二重被覆（720°）を、二乗は 2:1 の周波数階層を、それぞれ独立に供給している。

**系（自由度の空きが無い ＝ 励起状態を持たない）** 対称モードが反対称モードに従属している以上、**独立に励起できる第二の振動が恒等式の中に存在しない**。光子球に別の光子を重ねる席が代数の側に無い、ということである。**電子が励起状態を持たないように見えることが、モデルの側から出る。** 加速で内部にエネルギーを貯めることもできない（T2.5 の系を見よ）。

**ただし独立な自由度ではない。** 和 = 1/2 + ½（差）² なので対称モードは反対称モードに従属する。「二つの振動子」は**性格についての言明**であって自由度の数え上げではない。#65 の台帳の脚注（三周波数は二重被覆関係と振幅二次関係で結ばれる）が既にこれを述べている。この従属性こそが**周波数比を代数的に 2 に固定**し、閉じた軌道を保証する（一般の結合振動子は比が自由パラメータで、無理数比なら Lissajous・準周期で閉じない）。

### T1.6 規格化は周波数一致と同値である（旧 T2.5）

二核の周波数を別々に ω_A、ω_B とすると

n_A + n_B = 1 + ½(cos ω_A t − cos ω_B t) = 1 − sin[(ω_A+ω_B)t/2]·sin[(ω_A−ω_B)t/2]

したがって **規格化 n_A + n_B = 1 は ω_A = ω_B と同値**である。恒等式はエネルギー保存の言明であると同時に、**二核の周波数が等しいことの言明**でもある（O15「等しい内部周波数 ↔ 安定粒子」への恒等式側からの根拠）。離調させると欠損は**うなり**になり、包絡線の周期は 2π/|ω_A − ω_B|。O11（二周波数 Lissajous 拡張）が扱うべき対象がここで具体形を得る。ただし μ の寿命を包絡線周期と同定するには離調 4.4×10⁻¹⁶ が必要で、素朴な候補 β_μ/β_e − 1 = 2.70×10⁻³ では 11 桁外れる ── **うなり＝寿命の同定はこの形では支持されない**（→ K4）。

**系（内部への蓄積は加速ではない）** 片側の核にエネルギーを足せば ω_A ≠ ω_B となり、うなりが立ち、有限寿命になる。**内部に貯めて作れるのは「速い電子」ではなく μ・τ の側である。** 加速はブーストであって励起ではなく、加速された電子の静止質量は変わらない。運動学の側からも同じ ── 自由電子は実光子を吸収できない（静止系で s = m² + 2mω > m² となり終状態が単一電子になれない）。**ただし実験室系では光子球は非対称に強まって見える** ── 往路の Doppler 因子は √((1+β)/(1−β)) で、β = 0.999999 なら前方 1414 倍、後方 7.07×10⁻⁴ 倍。**観察は正しく、因果の向きが逆である**（強まったから速いのではなく、速いから強まって見える）。**内部に本当に貯まる領域は別にある** ── 強レーザー場中の実効質量 m\* = m√(1 + a₀²)（→ K9）。

### T1.7 恒等式は二光束干渉の代数である（旧 T2.6）

交差項を核エネルギーで書き直すと

C = 2cos²θsin²θ = **2√(T_A T_B)** 　（交差項は二つの核エネルギーの相乗平均の 2 倍）

したがって恒等式は **E₀ = T_A + T_B + 2√(T_A T_B) = (√T_A + √T_B)²**。一方、量子力学の二光束干渉は I = I₁ + I₂ + 2√(I₁I₂)·cos Δφ。**0SM の四次恒等式は、二光束干渉の強度式を Δφ = 0 に固定したものと同型であり、(√I₁+√I₂)² は Born 則 |ψ₁+ψ₂|² の代数そのものである。** 「二乗によって干渉項が出る」という読みは比喩ではなく、振幅の和を二乗するという操作が両者で同一だということであった。

**注意**：同型であることと Born 則であることは違う。T_A + T_B ≠ 1 なので二段目の像は確率単体ではなく、「確率の確率」ではない。二段目 T = n² は物理的な構成関係であって確率規則ではない。**「同型」以上に言い換えないこと。**

### T1.8 可視度と #4 の回収（旧 T2.7）

可視度は

**V = 2√(T_A T_B)/(T_A + T_B) = (1 − D²)/(1 + D²)**

左は強度の等しくない二光束干渉の可視度の**標準式そのもの**（二つの「光束」は二つの核エネルギー）。右は差 D で書いた形で、**可視度は差 D だけで決まる**（D = 0 で V = 1、D = ±1 で V = 0、D = 1/2 で 3/5）。sin²u/(1+cos²u) に還元でき ∫₀^π = π(√2−1) より **⟨V⟩ = √2 − 1 = 0.414213562373095**（厳密）。

**#4（2019）の「左右のスリットを通る波の振幅が等しくない」という仮説は、D ≠ 0 のことである。** #4 が仮説したものを #38 が内部恒等式から導き、両者をこの式が繋ぐ。

量子力学との唯一の違いは振幅の性質である ── QM の ψ₁, ψ₂ は複素で交差項 2Re(ψ₁*ψ₂) は符号を変え、完全な暗縞（V = 1）が可能。0SM の n_A, n_B は実で非負なので交差項は正定値、**消えない → V < 1**。#38 の可視度下限はここから来ている。#65 が複素構造を観測層（ω）で内部生成されるものとした以上、**可視度下限は「まだ複素になっていない層」の指紋**である可能性がある（→ K2）。

### T1.9 一本杉 — ボソンとフェルミオンの区別を一つの根から（提案、著者判断待ち）（旧 T2.8）

T2.1 で問いは「エネルギーは占有数の何次か」に還元された。次数を選ぶ規準が**二つ**ある。

**第一の規準：エネルギーの置き場の数。** (n_A + n_B)^p の展開の項数は p + 1 であり、項の一つ一つが置き場に対応する。

| p | 項数 | 置き場の解釈 |
|---|---|---|
| 1 | 2 | 核A、核B（**搬送体の席がない**） |
| **2** | **3** | 核A、**搬送体**、核B ← 0SM の構成 |
| 3 | 4 | 搬送体が二つ？ |

**二核と搬送体一つ、すなわち置き場が三つ。三項になるのは p = 2 のときだけ。** 四次は Stefan–Boltzmann の類推からではなく置き場の数から出る。そして置き場が三つある理由は

**S⁰ が弧状連結でない → 二核は離れている → 輸送中のエネルギーに席が要る → 置き場が三つ → p = 2 → 四次 → 交差項 → フェルミオン**

**第二の規準：調和性（T2.9 より）。** D_p ≡ a^(2p) − b^(2p) が純粋な cos θ になるのは **p ≤ 2 のときだけ**である。代数的理由は a^(2p) − b^(2p) = (a²−b²)·Σ_k a^(2k) b^(2(p−1−k)) の第二因子が 1 になるのが p=1（因子 1）と p=2（因子 a²+b² = 1）だけだからで、p ≥ 3 では a²b² が残る。**内部運動が調和振動になるのは p ≤ 2 のときだけ。**

**この規準は整数性を仮定していない（2026-09-09 に確定）。** 全角変数 u = cos θ で書くと D_p = [(1+u)^p − (1−u)^p]/2^p = 2·Σ_{k 奇} C(p,k) u^k / 2^p なので、D_p ∝ u となる条件は三次以上の奇数次係数がすべて消えることである。第一の条件だけで決まる ── **C(p,3) = p(p−1)(p−2)/6 = 0 の実数解は {0, 1, 2}**（C(p,5) = 0 の解 {0,1,2,3,4} はこれを含むので追加の解は出ない）。p = 0 は D ≡ 0 で振動が存在せず退化するので、**実数直線全体から p = 1 と p = 2 の二点だけが残る。** したがって「p は整数である」と置く必要はない ── **離散性は整数性の約束事から来ているのではない。** なお途中の非調和は浅く、\|a₃/a₁\| の最大は p\* = 1.4365 で **1.61%** にとどまる（§3）。壁としての深さは別の言明から来る（T2.12）。

**二つの規準は独立かつ相補的である。調和性が実数全体から p ∈ {1, 2} の二点を切り出し、置き場の数がそのどちらかを選ぶ。** 片方だけでは決まらない。**二つの規準の性格は違う** ── 調和性は代数（二項係数の消失）であり、置き場の数は解析（級数が有限項で終わり大域的に存在すること）である。後者が整数性を供給する（T2.12 の ③）。そして絞られた二つが、ちょうど二種類の粒子に対応する ── **p = 1 がボソン（搬送体なし）、p = 2 がフェルミオン（搬送体あり）。**

光子は核を持たず**それ自身が搬送体**なので中継の席が要らない。置き場は二つ、p = 1、交差項なし、V = 1 が可能（#38 §4.3 と一致）。**モデルの名前が、ボソンとフェルミオンの区別を含んでいた。**

一文にすると ── **ボソンは二乗を一度行う。フェルミオンは二度行う。一度目が二重被覆を生み、二度目が交差項を生む。二度目が必要になる理由は、二核が空間的に離れていることである。**

一段目の二乗（振幅 χ → 占有数 n = |χ|²、Born）は二重被覆・720°・スピノルを生み、二段目の二乗（占有数 n → エネルギー T = n²）は交差項・干渉・可視度下限・対称モードを生む。2019 年以来の SU(2) と被覆の考察は一段目にそのまま収まる。

残る前提は**エネルギー分割が規格化の冪の二項展開である**こと（→ K1）。

**補（2026-09-14d）── p が分けるのは統計ではなく時計の有無である。** T2.14 により、p = 2 の系は二核の回転子＝内部時計を持ち電荷を担える。W±（有質量・荷電・ボソン）は p = 2 に入らねばならず、「p = 2 ⇒ フェルミオン」は採れない。T2.12 が既に「0SM の溝はスピン統計の溝と同じものだとは主張できない」と述べていたので衝突ではなく精密化である ── **p = 1 ＝ 核なし・時計なし・中性・質量零（光子）／p = 2 ＝ 二核・時計あり・荷電しうる・有質量（e, μ, τ, W±）。** スピン統計の札は p からではなく別の場所から来る。中性は三種に分かれる ── **時計なし**（光子）／**打ち消し**（W = B ≠ 0、Z⁰・中性子、T2.13 (h)）／**保護なし**（離調、ニュートリノ、T2.13 P3）。クォークはこの表に入れない（分数電荷は未導出、T2.13 (c)）。

### T1.10 力と勾配 ── 二項の差が力の源泉である（常に念頭に置く命題）（旧 T2.9）

四次のチャネルを**個別に**微分すると三次項になる。

d/dθ cos⁴(θ/2) = −2cos³(θ/2)sin(θ/2) 　／　 d/dθ sin⁴(θ/2) = +2sin³(θ/2)cos(θ/2)

個々には正弦ではない。ところが**差を取ると**

dTPE_A/dθ − dTPE_B/dθ = −2cos(θ/2)sin(θ/2)·[cos²(θ/2) + sin²(θ/2)] = **−sin θ**

**三次項を潰しているのは第一の恒等式そのものである。** #1 の輻射勾配関係 ∂_θ(E_B − E_A) = E₀ sin θ は、この一行で出る。

同じ潰れ方が**二度**起きていることに注意する ── D 自身が a⁴ − b⁴ = (a²+b²)(a²−b²) = a²−b² で潰れ、その微分が a³b + ab³ = ab(a²+b²) = ab で潰れる。**第一の恒等式は「潰す道具」として二度働いている。**

和のほうは dTPE_A/dθ + dTPE_B/dθ = −½sin 2θ = −dKE/dθ。**差は ω・奇パリティ、和は 2ω・偶パリティ**で、T2.4 の二モードが微分の層にもそのまま現れる。和は保存則が押さえており、A から出たものは B と搬送体に分かれる（三体の帳簿）。

**構造的な意味がここにある。** 標準力学の F = −dV/dx は**一つの**ポテンシャルの勾配である。0SM は**二つのポテンシャルを別々に微分して差を取る**。したがって出てくるのは坂を下る力ではなく、**二つの貯蔵庫の不均衡**であり、力学的というより熱力学的である。作用反作用を別途課す必要がなく、和は保存則が押さえる。**一つのポテンシャルの勾配ではこの構造は出ない。差を取るという操作が、二核であることそのものの表現になっている。**

そしてこの潰れが T2.2 の調和振動子の根拠であり、T2.8 の第二の選抜規準（調和性は p ≤ 2 でしか成り立たない）の出所でもある。

**熱輸送としての読み（T2.0 の層で）** ── D が温度差そのものである（T2.3 の第六の顔）なら、この命題は一行で読み替わる ── **温度差の勾配が熱流を駆動する。** そして三次項を潰している因子 𝒯_A + 𝒯_B = 1 は**温度の総和の保存**であるから、**潰す道具は保存則そのもの**である。この読みでは −sin θ は坂を下る力ではなく Fourier の法則の類似物であり、T2.9 が「力学的というより熱力学的である」と述べた性格が、層の同定によって比喩ではなく字義どおりになる。二核＝二つの熱浴、搬送体＝その間の熱流という #1 以来の描像に、恒等式の代数がそのまま重なる。ただし下の未決の一歩（エネルギー毎ラジアン → 力）は読み替えても残る。

**未決の一歩を明記しておく** ── ∂_θ(E_B − E_A) はエネルギー毎ラジアンであって力ではない。長さで割る操作（λ_C かその一部）がどこかに要り、そこは恒等式だけでは終わらない。この一歩を書かずに済ませると「勾配＝力」で読み飛ばされる。

**この一歩の正体（2026-09-07 追記）** ── これは**導出の欠落ではなく、構成関係の指定**である。外微分 d は計量を要さず、余微分 δ = ⋆d⋆ は要する。**恒等式も T2.9 も d だけの層にあり、欠けている一歩は ⋆ である。** 前計量電磁気学（Kottler 1922、van Dantzig、Cartan、体系化は Hehl–Obukhov）ではマクスウェルは dF = 0 ／ dH = J ／ H = ⋆F と書かれ、**計量は四本の方程式のどこにも入らず、構成関係一本にだけ入る**。さらに真空で複屈折が起きないことを課すと構成テンソルは計量から来るものに限られるが、**共形因子＝尺度だけは決まらない**（Lämmerzahl–Hehl、Obukhov–Rubilar）。**恒等式が長さを与えないことと、前計量電磁気学が尺度を残すことは同じ欠落である。** 恒等式は穴を空けているのではなく、境界を正しく引き当てている。

### T1.11 因数分解と Clifford 代数（旧 T5.1）

$E^2 = p^2c^2 + m^2c^4$ を一次の積に分解する条件は

$$\beta^2 = 1,\quad \alpha_i^2 = 1,\quad \{\alpha_i,\beta\}=0,\quad \{\alpha_i,\alpha_j\}=2\delta_{ij}$$

である。「平方完成」ではなく「因数分解」と呼ぶ理由は、$x^2 - y^2 = (x-y)(x+y)$ の形に落とすために係数の**反交換**が必須であり、その反交換が以下の全命題の源だからである。因数分解は、二つの互いに直交する軸（$\beta$ と $\alpha$）を生む。

**補（2026-09-24）** ── 「平方完成ではなく因数分解」という呼び分けは、**同じ平方根を取る二つの道**として両立する。因数分解は反交換する二軸を足して一次にし、平方完成は二枚目の葉を足して一価にする。1+1 次元では両者が一致する（T1.24）。本項の本文は無改変。

### T1.12 一次の cos, sin の正体（旧 T5.2）

静止系（$\mathbf p = 0$）で $H = \beta mc^2$。$\beta$ はエルミートで固有値 ±1 が異なるので、固有ベクトル $|+\rangle, |-\rangle$ は直交する（第一の直交性）。実係数の重ね合わせ

$$|\psi\rangle = \cos\theta\,|+\rangle + \sin\theta\,|-\rangle$$

の cos θ, sin θ が、恒等式の一次の cos, sin である。**正エネルギー成分の振幅が cos θ、負エネルギー成分の振幅が sin θ。**

### T1.13 二軸の期待値と単位円（旧 T5.4）

$\alpha$（一成分 $\alpha_x$）は $\beta$ と反交換するので、$\beta$ の固有基底では $|+\rangle \leftrightarrow |-\rangle$ を入れ替える。T5.2 の状態で

$$\langle\beta\rangle = \cos^2\theta-\sin^2\theta = \cos 2\theta,\qquad \langle\alpha_x\rangle = 2\cos\theta\sin\theta = \sin 2\theta$$

したがって

$$\langle\beta\rangle^2 + \langle\alpha_x\rangle^2 = 1 .$$

これは反交換する二軸が Bloch 球上で直交すること（第二の直交性）の帰結であり、等号は状態が純粋であることを意味する。

### T1.14 恒等式の三項の一次表現（本幹の主命題）（旧 T5.5）

| 恒等式の項 | 一次の量 | 名 |
|---|---|---|
| $\cos^4\theta+\sin^4\theta$ | $\dfrac{1+\langle\beta\rangle^2}{2}$ | フェルミオン項（質量軸の偏りの二乗） |
| $\tfrac12\sin^2 2\theta$ | $\dfrac12\langle\alpha_x\rangle^2 = \dfrac12\left(\dfrac{v}{c}\right)^2$ | ボソン項（**速度の二乗の半分**） |
| $=1$ | $\langle\beta\rangle^2+\langle\alpha_x\rangle^2=1$ | 純粋性（単位円） |

$\alpha$ は速度演算子（$\mathbf v = c\boldsymbol\alpha$）であるから、ボソン項は $c = m = 1$ の単位で運動エネルギー $\tfrac12 v^2$ の形をしている。TPE と KE が交換するという 0SM の骨格は、**質量軸と速度軸を直交座標とする単位円**として一次で書ける。フェルミオンとボソンの同居とは、質量と速度が同じ単位円の直交座標であることである。

### T1.15 交差項はコヒーレンスである（旧 T5.6）

密度行列 $\rho = |\psi\rangle\langle\psi|$ の純粋度 $\mathrm{Tr}\rho^2$ は

- 純粋状態: $(\cos^2\theta+\sin^2\theta)^2 = 1$（恒等式そのもの）
- エネルギー基底で完全にデコヒーレンスした状態: $\cos^4\theta+\sin^4\theta$（**四次項だけが残る**）
- 差: $2\cos^2\theta\sin^2\theta = \tfrac12\sin^2 2\theta$（**正負成分の間のコヒーレンス**）

したがって恒等式 = 1 は「内部振動子は閉じた純粋な系であり、正負成分の位相関係が失われない」という物理的主張を含む。デコヒーレンスはボソン項だけを消す。

### T1.16 逆位相と配分比（旧 T5.7）

$$\cos^4\theta+\sin^4\theta = \frac{3+\cos 4\theta}{4},\qquad \tfrac12\sin^2 2\theta = \frac{1-\cos 4\theta}{4}$$

四次項は 3/4 を中心に、交差項は 1/4 を中心に、正確に逆位相で振れる。平均配分はフェルミオン 3 : ボソン 1。

### T1.17 二種の直交性（整理）（旧 T5.8）

1. $\beta$ の固有ベクトルが直交する（$\beta$ のエルミート性）── cos, sin を基底の座標として使える理由。
2. $\beta$ と $\alpha$ が軸として直交する（反交換）── $\langle\beta\rangle^2+\langle\alpha\rangle^2 \le 1$ が成り立つ理由。

因数分解が生んだのは 2. であり、1. はその一方の軸を選んだときに自動的に付く。

**接合（2026-09-14c）** ── 第二の直交性 ⟨β⟩² + ⟨α⟩² = 1 は幹 T2 の T2.13 の単位円 \|z\|² = a² + b² = 1 と同じ式であり、電荷の議論で効いた条件（規格化 ⟺ ロック、床＝ギャップ、二解 δ ∈ {0, π}、巻き数の保護）はすべてこの一本から出る。**電荷が整数として保護されるのは反交換の帰結**であり、第一の直交性は数えるための座標を与えるにすぎない。さらに純粋状態で等号・混合状態で ⟨β⟩² + ⟨α⟩² < 1 という不等式は、幹 T3 の T3.4 が K.E. ≥ 0 から出した a² + b² ≤ 1 と同じ不等式である ── 一方は演算子の反交換から、一方はエネルギーの非負性から。離調したニュートリノは「ブロッホ球の内側に落ちた状態」であり、#50 の「χ が局所的にしか定義されない」、T3.7 の「定常状態でない」、T2.13 の「保護された巻き数が無い」は、いずれも球面から離れたことの別名である。T5.6「デコヒーレンスはボソン項だけを消す」とも整合する（交差項 ½⟨α⟩² は第二の軸の座標の自乗、電荷の符号は ⟨α⟩ の奇数次に住む）。

**接合（2026-09-24）** ── ジューコフスキーの絵では、第一の直交は二核 z = ±a が互いに対蹠であること、第二の直交は二核（β の固有状態）と写像の極 z = 0, ∞（純粋な右向き・左向き成分＝α の固有状態、速度 ±c）がリーマン球面上で 90° 離れていることとして現れる（T1.24、§3）。**点粒子と 0-Sphere を隔てているのは第二の直交である**（T1.25）。

### T1.18 場の理論との対応（旧 T5.12）

四次のフェルミオン項とボソン交換は同じ物理の二つの書き方である（W ボソンを積分して落とすとフェルミの四点相互作用、逆に Hubbard–Stratonovich 変換でフェルミオン四次項を補助ボソン場とフェルミオン双線形の結合に書き直せる。BCS のクーパー対も同型）。恒等式の中の同居は、この既知の双対性を単一振動子の水準で見ている。

### T1.19 Zitterbewegung は交差項に住む（旧 T5.13）

ZB の振幅は $\alpha^*\beta$（正負成分の積）に比例し、その重みは $\cos^2\theta\sin^2\theta$ ＝交差項。速度 $c\alpha$ の期待値が sin 2θ であることの言い換え。したがって **v_ZB の観測は「ボソン項（コヒーレンス）が生きている」ことの判定**と同義である。

### T1.20 時間発展とブロッホ球（K4・K10 から、2026-09-14b）（旧 T5.15）

静止系で正負エネルギー成分は逆向きに回る:

$$|\psi(t)\rangle=\cos\theta_0\,e^{-i\omega t}|+\rangle+\sin\theta_0\,e^{+i\omega t}|-\rangle,\qquad \hbar\omega=mc^2$$

期待値は

$$\langle\beta\rangle=\cos2\theta_0\ (\text{一定}),\qquad \langle\alpha_x\rangle=\sin2\theta_0\cos2\omega t,\qquad \langle\alpha_y\rangle=\sin2\theta_0\sin2\omega t$$

ZB は速度平面 (α_x, α_y) 内を周波数 2ω で回る円運動である。交差項 ½ sin²2θ₀ には二通りの読みがあり、それがラグランジュ／オイラーの区別に一致する。

| 読み | 式 | 意味 |
|---|---|---|
| **ラグランジュ（一粒・瞬間）** | $\tfrac12(\langle\alpha_x\rangle^2+\langle\alpha_y\rangle^2)=\tfrac12\sin^22\theta_0$ | 二成分の和は時間によらず一定。恒等式は各瞬間に厳密 |
| **オイラー（位相平均）** | $\overline{\langle\alpha_x\rangle^2}=\sin^22\theta_0\,\overline{\cos^2}=\tfrac12\sin^22\theta_0$ | 一成分を分解不能な位相について平均。**½ は cos² の位相平均** |

一粒の恒等式は**ブロッホ球**の条件 $\langle\beta\rangle^2+\langle\alpha_x\rangle^2+\langle\alpha_y\rangle^2=1$ であり、T5.4 の単位円は時間を入れると単位球になる。測定側の恒等式（0SM の E₀ = 1 の形）は、その一射影の位相平均である。同じ数 ½ sin²2θ₀ が実在側では「二成分の瞬間の和の半分」、測定側では「一成分の位相平均」として出る。

**補（2026-09-24）** ── 二核を焦点とする座標 s = e^{iφ}·tan(θ/2)（T1.24。本項の記号では tan θ₀）で見ると、本項の歳差は |s| を固定して φ を回す運動（一つの核を囲むアポロニウスの円）であり、著者宣言（README §0.1）の回る角は φ を固定して |s| を動かす運動（二核を結ぶ弧）である。

### T1.21 何が単振動しているか（2026-09-07 に語義訂正）（旧 T1.2）

二核は**温度** 𝒯_A = cos²(θ/2), 𝒯_B = sin²(θ/2) を持ち、**𝒯_A + 𝒯_B = 1**（これが規格化そのもの）。エネルギーはその **2 乗** T = 𝒯² である。恒等式は (𝒯_A + 𝒯_B)² = 𝒯_A² + 𝒯_B² + 2𝒯_A𝒯_B であり、**KE = 2𝒯_A𝒯_B = ½sin²θ は二核の温度の交差項**。質量項は一周期を通じて E₀/2 を下回らない。

**訂正の内容** ── 旧版は「温度振幅 T_A = cos(θ/2) のエネルギーは 4 乗（Stefan–Boltzmann）」と書いていた。**四乗は振幅についてであって温度についてではない。** 振幅 a = cos(θ/2) と温度 𝒯 = a² の間にもう一段の二乗があり、四乗はその合成である。温度を振幅の層に置けない理由は符号にある ── 振幅を温度と読むと θ > π で**負温度**になり、観測にかからない χ → −χ で温度の符号が反転する。占有数の層なら 𝒯 = a² ≥ 0 が常に成り立ち符号も不変で、**温度の総和が保存する**という言明が立つ。**これは語義のみの訂正であって構造の変更ではない**（恒等式・数値・全命題は一切動かない）。四次の根拠は Stefan–Boltzmann の類推ではなく置き場の勘定と調和性である。導出と論拠は**幹 T2 の T2.0 と T2.8**、位相幾何の本体は **T2.10**（観測可能量は偶数次でなければならない）。

**⟨TPE⟩:⟨KE⟩ = 3:1 の扱い** ── 旧版の「ビリアル定理（1:1）は成り立たない」は**撤回**（§4）。床 E₀/2 をポテンシャルに含めていたための見かけの比であり、床を除けば 1:1 で厳密に成立する（幹 T2 の T2.2）。

### T1.22 観測可能性＝交差項結合（旧 T1.3）

電磁結合は交差項 ½sin²θ にのみ触れる。黒体核の内部（T⁴）は直接見えない。E₀ は観測量ではなく推論量（#31 の「線積分が観測量」と同方向）。「量子揺らぎ」は、この交差項の周期統計を、位相 θ₀ を知らずに標本化したもの。相対揺らぎ std(KE)/⟨KE⟩ = **1/√2**（⟨KE⟩ = E₀/4、Var = E₀²/32）。#10 の手置き 1/√2 との機構的関係は未確定（K10）。
### T1.23 ジューコフスキー変換 ── 差 D の正則な延長、二核は折り目（2026-09-24 新設）

**(2) 変換は D の正則な延長であり、臨界点は増えない。** ζ/2a = ½(z/a + a/z) は円の上で cos θ = D に一致するので、ジューコフスキー変換は D を円から（原点を除く）複素平面全体へ正則に延長した唯一のものである。dζ/dz = 1 − a²/z² の零点は z = ±a の二つだけ ── **幹 T2 の T2.2 の臨界集合 S⁰ は、正則に延長しても増えも減りもしない。** 円の上では

**KE = ½ sin²θ = ⅛ |dζ/dz|²**

**(3) 二核を焦点とする座標では、変換は二乗である。**

**(ζ − 2a)/(ζ + 2a) = [(z − a)/(z + a)]²**

|---|---|---|---|---|
| 振幅平面（幹 T2） | cos(θ/2) + i sin(θ/2) | 4π | 二乗（#3 の z ↦ z²） | メビウス χ → −χ（スピン） |

**(6) 実空間への移植（幹 T4 への接合）。** ξ 軸を実空間の軸へ運ぶと、ジューコフスキーの段だけなら核以外は 2 対 1 である。ここに幹 T4 の T4.4 の反跳閉包を重ねると

**X/(d/2) = D(3 − D²)/2** 　（T4.4 の ½cos θ[1 + ½sin²θ] と同一式）

で、**単調なので 1 対 1、二核は二核に移る**（ξ = ±2a ↦ X = ±d/2）。ただし縮尺は dX/dξ = (3d/4a)·KE で、**核の上で零**になる（D = 0, 0.5, 0.9, 1 → X/(d/2) = 0, 0.6875, 0.9855, 1。ξ の最後の 10% が X の最後の 1.45% に押し込まれる）。**「幾何学的な対応」（等角・等長）が壊れるのは二核の上だけ**で、それは欠陥ではなく S⁰ そのものである。さらに **T4.6 の三階平坦性は二段の積に分解される** ── ジューコフスキーの臨界点で 1 − D ≈ θ²/2（二次）、反跳閉包で X − d/2 ≈ −(3d/4)(1 − D)²（二次）、合わせて −(3/16)dθ⁴（T4.6 と一致）。**幹 T4 の次の版に還流すること。** なお #51 は A–B 軸を内部配位空間と明言しているので、X を空間の一方向と取るかは別に決める（写像の形はどちらでも変わらない）。

**性格**: (1)–(5) は代数として閉じている。(6) は T4.4 の閉包を前提とする。

### T1.24 平方完成と因数分解 ── 円と双曲線は同じ式の二つの枝（2026-09-24 新設）

**逆変換は平方完成そのものである。** z² − ζz + a² = 0 から (z − ζ/2)² = (ζ/2)² − a²、z = [ζ ± √(ζ² − 4a²)]/2。**二核は判別式が零の点（重根）**である。解と係数の関係で、二根 z と a²/z の和は ζ、積は a²。そして

**ζ² − ζ̃² = (2a)²**

これを E² − (pc)² = (mc²)² と並べると、**ζ ↔ E、ζ̃ ↔ pc、2a ↔ mc²、z ↔ (E + pc)/2、a²/z ↔ (E − pc)/2** が対応する（1+1 次元）。E ≥ mc² は (E ± pc)/2 の相加相乗平均の不等式で、**静止質量は相加平均と相乗平均が一致する点**である。

| ξ の範囲 | z の逆像 | E, p | 形 |
|---|---|---|---|
| ξ > 2a | 実軸 z = a e^ψ | E = mc² cosh ψ、p は実 | 双曲線（ローレンツ側） |
| ξ = ±2a | z = ±a（重根） | p = 0 | **二核** |
| \|ξ\| < 2a | 円 z = a e^{iθ} | E = mc² cos θ、pc = i mc² sin θ（虚） | 円（**本幹の恒等式**、ギャップ内、ユークリッド側） |
| ξ < −2a | 負の実軸 | E ≤ −mc² | 負エネルギー側 |

**恒等式の円と E² = p²c² + m²c⁴ の双曲線は、同じ一本の式の二つの枝であり、二核はその継ぎ目である。** 核間の距離 4a は 2mc²（標準ディラックの ZB 角周波数 2mc²/ħ に当たるエネルギー。0SM の ν_ZB は #67 で別に定義）であって、長さではない。2026-09-03 の壁練で出た対比（フーコーの 2π(1 − cos) と双曲面積の 2π(cosh − 1)、曲率の符号だけが違う）は、この表の円の枝と実軸の枝である。

**1+1 次元のディラック方程式で、ジューコフスキーの z はスピノル比になる。** カイラル表示（α = σ_z、β = σ_x）で (E − pc)R = mc²L なので **R/L = (E + pc)/mc² = z/a**。ζ はスピノル比の関数としてのエネルギーである。平面波（実の z = a e^ψ）では ⟨β⟩ = 1/γ = sech ψ、⟨α⟩ = v/c = tanh ψ なので、**T1.13 の単位円 ⟨β⟩² + ⟨α⟩² = 1 は z の実軸であり**、ジューコフスキーはそれを双曲線へ写す。ブロッホ角はラピディティのグーデルマン関数 gd ψ である。

**T1.11 との関係** ── T1.11 は反交換が要るという理由で「平方完成ではなく因数分解」と呼び分けた。ジューコフスキーを通すと二つは対立しない ── **同じ平方根を取る二つの道**である。**因数分解（ディラック）は反交換する二軸を足して一次にし、平方完成（ジューコフスキー）は二枚目の葉を足して一価にする。** 1+1 次元では R/L = z/a で両者が一致する。反交換の役（質量が R と L を結ぶこと）は、ジューコフスキーでは「二根の積が一定」（z × a²/z = a²）が担う。

**T1.17 の二種の直交が絵に乗る** ── 第一の直交（|+⟩ ⊥ |−⟩）は二核 z = ±a が互いに対蹠であること、第二の直交（β ⊥ α）は二核（β の固有状態）と写像の極 z = 0, ∞（純粋な右向き・左向き成分＝α の固有状態、速度 ±c）がリーマン球面上で 90° 離れていることとして現れる（§3）。

**相対位相で枝が決まる。** 状態 cos(θ/2)|+⟩ + e^{iφ} sin(θ/2)|−⟩ に対して s = e^{iφ} tan(θ/2)。**ξ 軸（実数の ζ）に乗るのは φ = 0, π（板の外）か φ = ±π/2（板の上）のときだけ**である。

- 幹 T2 の畳み方 z = a + ib をそのままスピノル a|+⟩ + i b|−⟩ と読むと、φ = ±π/2 で**板の上に乗る**。幹 T2 の T2.5 の「B は A より必ず四分の一周遅れる（か進む）」が、ちょうど板に乗る条件であり、遅れか進みかが表裏＝電荷の符号である。
- 同位相（幹 T2 の T2.4 で δ = π/2、D ≡ 0、W = 0）は z/a = ±i で**板の中央 ξ = 0 に止まる** ── T2.5 の「時間が止まった系」と同じ点。
- T1.12 の実係数の形（φ = 0）は**板の外**、双曲線の枝に出る。静的な混合角 θ₀ は ξ₀/2a = 1/cos 2θ₀ = γ の一点（数値は幹 T3 の領分）。README §0.2 の二つの変数が、同じ ξ 軸の二つの枝に住み分ける ── **回る位相は板の上、固定の混合角は板の外**。付録 (16) の「二角構造は正しく、割り当てだけが逆だった」の幾何学的な姿である。
- 動きの違いも同じ座標で読める ── 著者宣言（README §0.1）の回る角は φ を固定して |s| を動かす（二核を結ぶ弧）。標準ディラックの静止系 ZB（T1.20）は |s| を固定して φ を回す（一つの核を囲むアポロニウスの円）。

**留保**: 本項のエネルギーの読み（ξ ↔ E）は B2（一次の cos, sin ＝ β の固有ベクトルへの射影）の上に立つ。T1.4 が指摘するとおり、字義どおりの「核 A = ψ⁺」は #65 Thm 3.1 と衝突し（→ K3）、その読みでは核は ±a から 90° ずれて板の端に来ない。**本項は 1+1 次元の言明である**（3+1 次元は K16）。

### T1.25 0-Sphere は点粒子の平方根の分岐点である（2026-09-24 新設、著者の問いから。読み）

**著者の問い（2026-09-24）**: 通常の x 軸・y 軸の原点にある点は、これまでのボソンとしての「点粒子」を表し、ディラック方程式で平方完成をしたら正負エネルギーが出てきた。0SM では正負エネルギーを TPE の輻射と吸収に、Δm を TPE の増減に割り当てた。ここから、点粒子を平方完成すると 0-Sphere としての二点間距離がジューコフスキー変換によって出てくる、と解釈できるか。

**答え: できる。** 一行にすると **「0-Sphere は、点粒子の平方根が持つ二つの分岐点である」**。ただし二箇所の言い換えが要る ── 開くのは「点」そのものではなく「**交差（縮退）**」であること、出てくる距離はまず**エネルギー（2mc²）**で、空間の距離へは h を通して移ること。

**(1) 原点が板に開く。** a = 0 でジューコフスキー変換は恒等写像 ζ = z となり、板は原点一点に潰れる。a を 0 から持ち上げた瞬間に原点のまわりに半径 a の円が引かれ、その円が折り畳まれて長さ 4a の板になり、縁に二点 ±2a が現れる（原点そのものは無限遠へ送られる）。

| | a = 0（点粒子） | a > 0（0SM） |
|---|---|---|
| 変換 | ζ = z（恒等） | ζ = z + a²/z |
| エネルギーと運動量 | E = ±pc の二直線が原点で交わる | 双曲線、頂点は ±mc² |
| √(E² − m²c⁴) の分岐点 | 原点に重なる | ±mc² に分かれる（**二点 ＝ S⁰**） |
| 円 \|z\| = a | 原点に潰れる | 原点から距離 a を保つ |
| 巻き数・内部時計 | 定義できない（中性、固有時間なし） | 定義できる（幹 T2 の T2.4 のギャップ、T2.5 の時計） |

**なぜ交差が開くか** ── 1+1 次元のカイラル表示で H = [[pc, mc²], [mc², −pc]]。質量は R と L を結ぶ非対角の結合で、p = 0 で交わる二本 E = ±pc をこの結合が ±mc² に押し分ける（**回避交差**、準位反発）。ギャップ 2mc² は結合の 2 倍である。「点を平方完成すると二点が出る」を正確に言えば、**「質量という結合が、交差点を二つの頂点に割る」**。

**(2) 既存の命題との噛み合い。**
- **名前が字義どおりになる**: 二点 {±2a} は線分 [−2a, 2a] の境界 ∂D¹ = S⁰ であり、円 S¹ を線分に折り畳んだときの折り目＝T2.2 の臨界集合である。エネルギー軸の上の「半径 mc² の 0 次元球面」と読める。
- **幹 T2 の T2.5「質量零の粒子は中性」がそのまま出る**: a = 0 だけが円を原点に潰し、巻き数を定義できなくする。**質量とは、円を原点から離しておく半径である。** 付録 (13) の「振幅が原点を避ける」がこれにあたり、a = 0 の側は T1.9 補の p = 1（核なし・時計なし・中性・質量零）である。
- **点粒子と 0-Sphere は 90° 離れている**: 原点 z = 0 と無限遠 z = ∞ は純粋な L と R（速度 ±c で走る質量のない点粒子、α の固有状態）、二核 z = ±a は ±mc²（β の固有状態）。**点粒子と 0-Sphere を隔てているのは T1.17 の第二の直交（因数分解が生む α ⊥ β）そのもの**である。

**(3) ボソンの層からフェルミオンの層へ降りる一段。** 平方完成の前の E² = p²c² + m²c⁴（クライン・ゴルドン方程式）はスピン 0 のボソンの方程式で、内部の自由度を持たない ── 著者の言う「ボソンとしての点粒子」はこの層にあたる。ζ 面はこの層にある（E は ζ² − ζ̃² = (2a)² の形で二乗としてしか現れない）。平方完成で z 面に降りると R/L = z/a のスピノル比の層に入り、± の二値が二枚の葉として一価に並ぶ。**二枚が一つに合わさる重根の点がちょうど二つあり**、それが二核である。T1.9 の「ボソンは二乗を一度、フェルミオンは二度」と向きが揃う。

**(4) 著者の割り当てを板の上に置く。**
- **正負エネルギー → 輻射と吸収**（B5）: 縁の +2a = +mc² が核 A、−2a = −mc² が核 B。板の上を A から B へ動くことが TPE の A → B の移送、すなわち A の輻射と B の吸収である。T1.4 の両立する言い方（負エネルギー分岐との干渉が、核の基底では輻射と吸収の交替として現れる）にとって、板の往復がその交替そのものになる。
- **Δm → TPE の増減**: Δm を二核の TPE の差（一方が増えた分だけ他方が減る）と読むと、板の座標は **ξ = mc²·D = (mc²/E₀)(TPE_A − TPE_B)**。

| ξ | D | TPE_A | TPE_B | KE | 意味 |
|---|---|---|---|---|---|
| +2a（+mc²） | +1 | 1 | 0 | 0 | 核 A（折り返し） |
| +a | +1/2 | 9/16 | 1/16 | 6/16 | |
| 0 | 0 | 1/4 | 1/4 | 1/2 | 赤道（KE 最大、#58 の放出位相） |
| −a | −1/2 | 1/16 | 9/16 | 6/16 | |
| −2a（−mc²） | −1 | 0 | 1 | 0 | 核 B |

  **板の座標がそのまま TPE の差（Δm c²）になるのは E₀ = mc² のときだけ**である。E₀ = 2mc² なら ξ はその半分になる。**K4 はこの絵では「E₀ は板の半長 2a か全長 4a か」と言い換わる**（§5）。ただし第三の答えがある ── 恒等式の板は Dirac の板とは別の、尺度 E₀ の小さな板でありうる（E₀ = βmc² など。§5 の K4 の検証）。

**(5) 距離の単位 ── エネルギーの二点と空間の二点。** ジューコフスキー変換が直接与えるのは 4a = 2mc² = 1.022 MeV。空間の二核間距離を幹 T4 の T4.3 の規約 d = λ_C で取ると **d × 4a = 2hc**（2.4797×10⁻¹² MeV·m）。式は λ_C = h/mc の書き換えにすぎないが、**h の置き場所**として意味がある ── エネルギー軸の 0-Sphere と空間軸の 0-Sphere を結ぶ換算率の位置に h が来る。2026-09-15 の「プランク定数を場でなく核に求める」と置き場所が合う。T1.23 (6) と合わせて、移植の**形**は反跳閉包、**尺度**は h である。

**(6) 0SM が付け加えるもの。** 二つの分岐点は、質量を持つディラック粒子なら誰の数学にもある ── 点電子の理論もこの 0-Sphere を内に持っており、板の内側（ギャップ）は運動量が虚になる領域として自由粒子の記述から外されている。**0SM が付け加えるのは、その二点を実在（核）とし、二点の間（ギャップ）を内部振動子が走る場所、すなわち内部時間の場所とすること**である。README §0.2 の「A ＝ 形式に無い自由度」は、この板の内側 ── 自由粒子の形式が減衰解として捨てている領域 ── と読める。

**性格**: (1)(2)(3) の代数と (5) の数値は検算済み。**0-Sphere を分岐点と「読む」こと、(4) の割り当て、(6) の位置づけは読みであり、著者判断に属する。**

## 付録A — これまで気づかれなかったこと

本幹の内容は、その大半が既存論文の中に**素材としては存在していた**。連結が起きなかった理由を記録しておく。同じ型の見落としは繰り返されるからである。

**(1) 差 D はどの論文にも記号を持たなかった。** #1 の輻射勾配関係は差の微分であり、#65 の s_z は差そのものであり、#4 の「振幅の不等性」は差 ≠ 0 である。**三本の論文が同じ量を三つの別の名前で扱っていた。** 名前のない量は、読み手の頭の中で論文を跨げない。差に D という記号が付いた瞬間に、可視度 V = (1−D²)/(1+D²) は二行の計算になり、#4 と #38 が繋がった。**素材の不足ではなく、記号の不足であった。**

**(2) 床 E₀/2 は「定数オフセット」として読まれたことがなかった。** #46 は「幾何学的束縛エネルギーの床」、#49 は「放出の閾値」として、いずれも**物理的に意味のある量**として扱ってきた。だからこそ、ビリアル定理を当てるときにポテンシャルから引くべき定数だとは気づかれなかった。**床が物理的に意味を持っているときほど、この落とし穴は踏みやすい。**

**(3) 交差項は #1 以来ずっとあったが、「対称モードを生かすもの」としては読まれていなかった。** #38 は交差項を干渉項として読み、#65 は振動子の運動エネルギーとして読んだ。パリティ分解（核の入れ替え A↔B に対する奇偶）を通すと、両者が同じ一つの構造 ── 対称モードの生死 ── の別名であることが見える。
