## 1. 前提 — 読み込んだ一次資料の骨組み

**#9（2023, Beyond the Standard Model: Neutrino Oscillations）** 電子モデルの二振動子を、**振動数を等しく置かない**形に拡張したもの。中心の式は

E_ν = E_ν [ cos⁴(ω_ν1 t/2) + sin⁴(ω_ν2 t/2) + K.E. ]

で、K.E. は「二つの引数が違うので ½E_ν sin²(ωt) に簡約できない」と明記される。主張は四つ ──（a）二核は直交・独立で互いの放射を吸収しない、（b）リサジュー曲線が閉じるまで相互作用が起きない、（c）だから相互作用が稀である、（d）閉じるのに時間がかかるから質量が極端に軽い。§5 に「この仮定を裏づける数学的根拠の構築は将来の課題」と記されている。包む boson の候補として W±, Z⁰ を挙げる。seesaw 機構の重い右巻きニュートリノを要求しない点を利点として述べる。

**#50（2026）** 同じ構造を自由度の数え上げから整理する。閉包時間は **2π/|ω_ν1 − ω_ν2|**、比が無理数なら永久に閉じない。**ω_A/ω_B は量子数ではなく軌道の形を決める連続パラメータ**で、スピノルの次元は 4 のまま。位相的分岐として ── ω_A = ω_B は閉測地線・安定粒子・χ が大域的に定義される・自由度 4、ω_A ≠ ω_B は開（リサジュー）測地線・振動する粒子・χ は局所的にのみ・自由度 4 ＋ 形のパラメータ。**PMNS 行列を借りることは方法論的に許されない**（置き換えようとしている枠組みから結論を借りることになる）と明記し、逆に**混合角は ω_ν1/ω_ν2 から導出されるべき**だとして将来課題に置く。

**#51** 付録 (iii) で、螺旋構成は電子（ω_A = ω_B）にのみ適用され、**リサジュー螺旋とその固定端点線積分は未解決**と記帳する。

**#68** O11「二振動数（リサジュー）拡張 ── 安定性起源テーマ（O15）の幾何学的入口」、O15「ω₁ = ω₂ が安定粒子、不等なら不安定または振動する粒子。#9 の二振動数足場を数学的基礎とする」。三つの困難を挙げる ── 異なる振動数の二振動子の束縛の起源、振動数比と異常磁気モーメントの橋、初期足場と現行枠組みの整合。

**#4（2019）** 電子の二重スリットで左右の振幅が等しくないという仮説。重み係数は A_spinor1 = A cos²θ、A_spinor2 = A sin²θ で、**同じ A に相補的な重みが付く形**であり、核固有の振幅非対称ではない。T2.7 が D ≠ 0 として回収済み。

## 2. 確立した命題（T3.1–T3.14）

**T3.1 corpus が提起しているのは振動数差である** #9・#50・#68（O11, O15）はすべて ω_A ≠ ω_B で書かれている。振幅については一語も変えていない。**振幅の不等性を言っているのは #4 で、それは電子の側の話であり、T2.7 の D ≠ 0 として既に回収されている。** corpus の配置は「振幅差は電子の側、振動数差はニュートリノの側」である。記憶がこの二つを融合しやすいので、幹として明記しておく。

**T3.2 リサジュー曲線の閉包は振動数比のみで決まる** x = A cos(ω₁t), y = B sin(ω₂t) の閉包条件は ω₁/ω₂ が有理数であること。**A, B は外接矩形の縦横比を決めるだけで、閉包の条件式に入らない。** 数値確認済み ── 振幅を 7 倍にしても閉包は不変（比 1:1 と 2:3 の両方で検証）。したがって「振幅差がリサジューを閉じなくさせる」という形の主張は成立しない。

**T3.3 振幅差がすること — 規格化を ω で変調する** 振動数を共通にして振幅だけ変えると

𝒯_A + 𝒯_B = A cos²(θ/2) + B sin²(θ/2) = **(A+B)/2 + ((A−B)/2)·cos θ**　（残差 厳密に零）

**これはうなり（包絡線）ではなく、振動数 ω そのものでの変調である。周期は変わらない。** 変調の大きさは **(A−B)/2 · D**（D = cos θ）なので、**振幅差は差 D に直結する**。T2.3 の「D の六つの顔」に七つ目を足す形になる。

**T3.4 #9 の式は振幅 1 のままでは運動エネルギーが負になる（要訂正）** #9 の式は K.E. = 1 − cos⁴(ω₁t/2) − sin⁴(ω₂t/2) を意味するので、**K.E. ≥ 0 は sup(T_A + T_B) ≤ 1 を要求する**。ところが離調させると、二つの位相がトーラス上で稠密になるため**いつか必ず両核が同時に最大になり**、sup → 2 となる。振幅 1 のままなら **K.E. = −1**。

**したがって a² + b² ≤ 1、等振幅なら a ≤ 1/√2。** 比ごとの上限（a = b として、許される等振幅 a_max = 1/√sup）──

| ω₁:ω₂ | sup(T_A+T_B) | a_max |
|---|---|---|
| **1:1（逆位相）** | **1.000** | **1.000** |
| 1:2 | 1.286 | 0.882 |
| 1:3 / 3:1 | 1.586 | 0.794 |
| 3:2 | 1.654 | 0.777 |
| 1:4 | 1.740 | 0.758 |
| 5:4 | 1.883 | 0.729 |
| 2:1 / 2:3 / 4:3 | 2.000 | 0.707 |
| **無理数比**（黄金比・√2−1・π/4） | **2.000**（漸近） | **0.7071 = 1/√2** |

> **1:1 の逆位相ロックだけが、核を「満身」のまま保てる唯一の配置である。離調した粒子は必ず軽い。**

これは #9 §4.3 の軽さの論証（「閉じるまで時間がかかるので運動エネルギーのまま長く留まる」）の定量的な置き換えになる。**ただし方向は正しいが桁が足りない** ── 上限は最大でも 30% の減少であって、ニュートリノに要る 10⁷ 倍ではない。また上限を課すだけで値を決めないので、答えているのは「なぜ軽いか」ではなく「なぜ同じ重さにはなれないか」である。

**1/√2 はこれで四度目**である ── #10 の RMS 置換（a → a/√2）、T1.3 の相対揺らぎ std(KE)/⟨KE⟩、T1.12 補の √2、そして本項の「位相ロックを外す代価」。機構の候補として記帳する（→ K3）。

**T3.5 床 E₀/2 は 1:1 逆位相ロックの帰結であり、離調で消える** 電子では inf(cos⁴(θ/2) + sin⁴(θ/2)) = **1/2**（θ = π/2、T1.2／T2.2 の床）。離調させると inf → 0 ── 数値で黄金比 1.4×10⁻¹⁴、√2−1 で 1.1×10⁻¹⁴、π/4 で 1.3×10⁻¹⁷。

> **床 E₀/2 は恒等式の性質ではなく、位相ロックの性質である。**

**#9 が「T_ν1 = T_ν2 = 0 となり全エネルギーが運動エネルギーに変わったときに相互作用が起きる」と仮定した瞬間は、床の消失として定理になる。** #9 はこれを仮定として置いていた。

**T3.6 #9 の希少性の論証は成り立たない（要訂正）** #9 §4.1／§5 は「リサジューの閉包に一回の相互作用を割り当てれば、閉包時間が長いことが相互作用の稀少さを説明する」とする。これは成立しない。

二重零点の近傍（T_A + T_B < ε²）の滞在率 ──

| 比 | ε = 0.3 | ε = 0.2 | ε = 0.1 |
|---|---|---|---|
| 黄金比 | 1.246×10⁻¹ | 8.014×10⁻² | 3.876×10⁻² |
| √2 − 1 | 1.246×10⁻¹ | 8.014×10⁻² | 3.876×10⁻² |
| π/4 | 1.246×10⁻¹ | 8.016×10⁻² | 3.873×10⁻² |

**三つの比で三桁まで一致する。** 滞在率は ε に比例し（四乗のため）、**比に依らない** ── Weyl の一様分布定理の要求である。**曲線が閉じないことは、二重零点を稀にしか訪れないことを意味しない。**

比に依るのは**最大待ち時間**のみ（閾値 0.04、同一区間での比較）──

| 比 | 平均間隔 | 最大間隔 |
|---|---|---|
| 黄金比 | 0.06 | **18.3** |
| √2 − 1 | 0.06 | **29.6** |
| π/4 | 0.06 | 23.4 |

**黄金比が最小**である（最も近似しにくい無理数は最も規則的に訪れる）。直感の逆。#9 が「将来の課題」とした数学的根拠はディオファントス近似（三距離定理・連分数）の問題として定式化できるが、**平均率が普遍なので希少性の説明にはならない**。希少性は結合の小ささから来るしかない。

**T3.7 うなりの帰属訂正 — 寿命ではなく風味振動** T2.5 は離調によるうなりの包絡線周期を**粒子の寿命**と同定しようとして 11 桁外れ、支持されないと記帳された（幹 T2 §4）。帰属先を変えると三点が揃う。

1. **うなりは本来コヒーレントな周期現象**である。寿命は非コヒーレントな減衰なので器が違っていた。風味振動はまさに周期的な拍で、うなりが説明すべき対象の形をしている。
2. **T2.5 は「規格化 𝒯_A + 𝒯_B = 1 ⟺ ω_A = ω_B」を証明済み**である。離調した二核系は規格化を周期的に破る、すなわち**定常状態ではない**。そして**風味固有状態はハミルトニアンの固有状態ではない**。同じ形の言明である。
3. **#9 はニュートリノを非対称な振動数（閉じないリサジュー）として置いている。** 非対称＝離調、非閉性＝拍。

これにより **幹 T2 の K4**（2:1 ロックを破る機構、必要な離調 4.4×10⁻¹⁶ の正体）の形が変わる ── 問いは「4.4×10⁻¹⁶ の正体は何か」ではなく「**Δm/m̄ が離調そのものか**」になる。正常順序の m₃ と m₂ なら Δm/m̄ = 0.83 で **order 1 の離調**、準縮退なら小さい離調。突き合わせは未了（→ K1）。

**T3.8 静止系のうなりは 2–12 THz である（0SM に依らない）** 質量固有状態どうしの静止系うなり Δmc²/h は、振動実験の測定値だけで決まる。**β も 0SM も使っていない。**

|---|---|---|---|
| m₃ − m₂（正常順序） | 41.6 meV | **10.1 THz** | 29.8 µm |
| m₃ − m₁（正常順序） | 50.3 meV | **12.2 THz** | 24.7 µm |
| m₂ − m₁（正常順序） | 8.68 meV | **2.10 THz** | 143 µm |

**これが本幹で最も堅い錨である。** 0SM が加えられるのは機構（離調した二核）だけで、振動数そのものは標準量子力学の帰結である。

**T3.9 0SM の内部振動子は遠赤外に落ちる（ただし β_ν は外挿）** ν_ZB = β mc²/h。

| 順序 | 状態 | mc² | ν_ZB | λ |
|---|---|---|---|---|

**線の本数と配置が質量順序を区別する** ── 正常順序なら「一本なし・85 GHz・492 GHz」の三本ばらけ、逆順序なら「485 と 492 GHz のほぼ縮退した二本＋一本なし」。

**述べ方の制約（必ず守ること）** ── **β_ν = 0.0405 は仮定である。** T1.11 が確立したレプトン普遍性は**荷電レプトンの |a| から出ており**、ニュートリノには測定された異常磁気モーメントがないので同じ手順は使えない。これは無パラメータの予言ではなく、**m_ν と線の振動数を結ぶ一本の関係式**である。裏から読めば「線を測れば m_ν が出る」。

**T3.10 宇宙背景ニュートリノは非相対論的である** T_ν = 1.945 K → kT = 0.168 meV、典型運動量 3.15kT = 0.528 meV。m₃ = 50.3 meV に対して **p/mc = 0.0105**（m₂ でも 0.061）。数密度 336 /cm³（3 世代＋反粒子の合計）。**静止系の線がドップラーで崩れない 336 /cm³ の浴が存在する。**

**T3.11 結合が無い（本幹の唯一の借金）** 離調系の内部構造は言えるが、外界と繋ぐ結合が 0SM の中に無い。理由は三つとも既に確立している ── **T1.6**（電子の双極子はエネルギー（熱）双極子であり、電荷双極子は EDM 上限で 20 桁排除）、**T1.5／T1.15**（質量双極子は運動量保存で振動できず、輻射は四重極から。電子の重力波出力 1.0×10⁻⁴³ W）、**Q = W − B**（2026-09-02、ニュートリノは巻き数 W = 0・環 B = 0 で電荷を持たない）。

> **帯域が一致していることは、結合があることを意味しない。**

**補（2026-09-14、幹 T2 の T2.13 より）** ── 「W = 0」の内実が定まった。電荷は振幅平面 z = a + ib の原点まわりの**保護された巻き数**であり、保護されるのは |z| = 1（規格化 ⟺ ロック、T2.5）のときだけ。離調系は原点を訪れる（T3.5 の床の消失と同じ事実）ので、巻き数は「0 である」のではなく「**保存する整数が存在しない**」。一方が偶数の有理比は W = 0、奇:奇の有理比は W = ±1 だが保護なし（位相差で符号が反転）、無理数比は定義不能。Q = W − B の W はこれで割り当てから帰結になった。B（閉じた環の層）の置き場は著者判断待ち。

返済先の候補は一つある ── **磁気モーメントの七桁の窓**。標準理論は m = 0.05 eV で μ_ν ≈ 1.6×10⁻²⁰ μ_B、実験上限は原子炉（GEMMA）2.9×10⁻¹¹ μ_B、球状星団の星の冷却 1.5×10⁻¹² μ_B。**計算の型は既にある**（T1.8 が電子で循環の軌道磁気モーメント 0.127 μ_B を出している）。足りないのは「電荷を持たない核で循環が何を作るか」（→ K2）。なお上限値は 2026年5月時点の知識なので、論文化の際は引き直すこと。

**T3.12 遠赤外で結合するなら、標的は金属ではあり得ない** 外部入力（物性）。Hagen–Rubens 関係から λ = 10 µm での吸収率は銅 1.5%、アルミ 1.9%、鉄 3.7%、ステンレス 304 9.8%。一方**皮膚（含水組織）は放射率 0.98**。

> **磨いた金属は遠赤外線の鏡であり、含水・有機の側が吸収体である。** したがって 0SM のニュートリノ内部振動子が共鳴として外に結合するなら、結合先は金属ではあり得ない。

さらに**タンパク質の集団振動モードは 0.1–3 THz**、水の水和殻の緩和は 0.1–1 THz で、**T3.9 の 492 GHz を含む**。帯域は重なる（結合の有無とは別問題、T3.11）。

付記（よくある誤解の訂正）: 遠赤外線は体の奥に届かない。水中の侵入深さは 10 µm で **12.5 µm**、3 µm で 0.9 µm。奥に届くのは近赤外（1 µm で 29 mm）。

**T3.13 単一量子検出は E/kT ≈ 100 でしか成り立たない** 外部入力。単一量子増幅器（光電子増倍管・ロドプシン）が成立する条件は、信号が熱よりはるかに大きいことである。

| | E | E/kT（300 K） |
|---|---|---|
| 可視光子（500 nm） | 2.48 eV | **96** |
| 光電面の仕事関数（バイアルカリ） | 1.80 eV | 70 |
| ロドプシンの熱障壁（21.9 kcal/mol） | 0.95 eV | 37 |
| **遠赤外 0.49 THz の量子** | **2.02 meV** | **0.078** |

0.49 THz の量子に対する Bose 占有数は 300 K で **12.3**、77 K で 2.80、24 K で 0.60。**占有数が 1 を切るのは 33.9 K 以下。**

> **信号が kT より小さいものを単一量子として拾う増幅器は設計できない。** 不可逆な第一歩を起こすのに 2 meV しか使えないなら、その障壁は 2 meV 以下でなければならず、熱が毎秒 10¹³ 回叩いている。

ロドプシンの巧妙さは「光学的な敷居 2.5 eV と熱障壁 0.95 eV を別の経路に分けた」ことだが、**この技は信号が kT より大きい場合にしか使えない。移植できない。** 残る道は二つ ── **冷やす（33.9 K 以下）か、単一量子を諦めてコヒーレントな力を積算する（Stodolsky 型）か。**

参考（暗計数を同じ尺度に直した比較）: 光電面（20 インチ管、300 K）は表面原子あたり 2.5×10⁻¹⁵ /s、面積あたり 2.5 /s/cm²。ロドプシン（310 K）は分子あたり 7.5×10⁻¹¹ /s（1 回/420 年）、面積あたり 2.5×10⁵ /s/cm²。**どちらの尺度でも光電面が 10⁵ 倍静か**で、桿体は立体的に詰めているため面積効率で負け、**神経回路の同時計数で補っている**（粒子検出器と同じ手法）。一次過程はロドプシンが勝つ（量子収率 0.65 対 0.2–0.3、異性化 200 fs）。

**T3.14 検出器の骨子 — 柔らかさはカロリメトリで自滅し、ラッチ方式で噛み合う**（**本項は初稿であり、`trunks/T4-2026-09-09-recoil-reporter.md`（幹 T4）が全面的に改訂した。設計を扱うときは T4 を見ること。** 特に温度想定は 20 mK → **共有結合ラッチなら室温**に緩み、(h) の「時間情報の喪失」も読み出しの頻度と連続磁気・発光読み出しで大きく緩和された） 外部入力。以下は標準的な弱い相互作用（CEvNS）に対する設計であり、**0SM の共鳴を試す装置ではない**（要求が正反対、§4 参照）。

**(a) 仕分け。** 背景ニュートリノ（0.5 meV）が原子核に渡せるエネルギーは **5.0×10⁻¹⁷ eV**（炭素）。標的をどう選んでも桁が動かないので、熱にはならず**力の測定しかない**。柔らかい標的が効くのは太陽・原子炉（MeV）側である。

**(b) 軽さの利得。** T_max = 2E²/(M+2E)。太陽 pp 端点に対して H-1 378 eV、**C-12 31.6 eV**、O-16 23.7 eV、Si-28 13.5 eV、Ge-73 5.19 eV、Cs-133 2.85 eV。炭素は Cs の 11 倍。

**(c) 軽さの損失。** 断面積は Q_W² ∝ N² に比例し、**水素は N = 0 なので標的にならない**（Q_W = −0.08）。質量あたりの Q_W²/A は C 2.57、O 3.42、Ar 10.7、Ge 20.4、Cs 41.0。

**(d) 率の表（太陽ニュートリノ、回/kg/年、概算）。**

| 標的 | 閾値 1 eV | 4 eV | 10 eV | **30 eV** |
|---|---|---|---|---|
| C-12 | 1.76 | 1.66 | 1.46 | **0.78** |
| O-16 | 2.33 | 2.15 | 1.79 | 0.91 |
| Si-28 | 4.00 | 3.45 | 2.35 | 1.17 |
| Ar-40 | 6.98 | 5.58 | 2.99 | 1.34 |
| Ge-73 | 12.63 | 7.74 | 4.42 | 0.91 |
| Cs-133 | **22.71** | 10.46 | 4.14 | 1.17 |

> **軽い標的の利点は率ではなく、「高い閾値でも反跳が届く」ことである。** 閾値 30 eV では全標的が約 1 回/kg/年に揃う。

**(e) 柔らかさの自滅。** カロリメータの分解能は ΔE ≈ √(kT²C)、熱容量 C ∝ (T/Θ_D)³。Ge（Θ_D = 374 K）を基準にすると、有機分子結晶（90 K）で熱容量 71.8 倍・分解能 8.5 倍悪化、**タンパク質結晶（60 K）で 242 倍・15.6 倍悪化**、凍結生体試料（50 K）で 419 倍・20.5 倍悪化。取り戻すには 20 mK → 3.2 mK が必要。さらに**非熱的フォノン検出も使えない**（柔らかく乱れた分子固体ではフォノンの平均自由行程が短い）。**低振動数モードが密であることは、低い閾値を作る理由でもあり熱容量を上げる理由でもある ── 同じ一つの性質である。**

**(f) 回り道＝ラッチ（不可逆）方式。** 熱ではなく**壊れた結合を数える**。20 mK での熱切断率は厳密に零（指数が −10⁶ の桁）── C–H 4.30 eV、C–O 3.70 eV、C–C 3.60 eV、C–N 3.20 eV、S–S 2.20 eV。**信号が永久的な構造変化なので、熱容量も占有数も無関係になる。** 読み出しは事後（配列決定・分光・色中心の計数）。一事象で切れる C–C 結合は、太陽 pp 端点 / C-12 で **8.8 本分**、Be-7 で 36.9 本分、原子炉 3 MeV で 447 本分。

これが**ロドプシンから移植できる唯一の部品**である（T3.13 の四部品のうち②「戻れない第一歩」だけ。増幅ではない）。

**(g) 自己整合。** ラッチの閾値は結合一本 4 eV ではなく、確実な多重結合の痕跡として **10–30 eV** 程度になる。(d) の表より、**閾値 30 eV では軽い標的が損をしなくなる**。「軽い」「柔らかい」「ラッチ」の三つが同じところに落ちる。

**(h) 本当の代価 — 時間情報の喪失。** 永久的な痕跡を事後に読むので、いつ起きたか分からない。したがって**同時計数が使えない**（T3.13 が示したとおり、網膜も粒子検出器も暗計数を同時計数で殺している）。原子炉のオン・オフ比較、年周変調、宇宙線 veto もすべて使えず、**露光期間中の背景が全部積算される**。1 回/kg/年に対して自然放射能と宇宙線は桁違いに多い。**逃げ道は方向感度ただ一つ。**

**文献上の住所**: 生体分子を粒子検出器に使う筋は既に開かれている ── DNA を並べた方向感度つき暗黒物質検出器の提案（Drukier, Freese, Spergel ら、2012年頃）、芳香族有機分子の三重項励起を使う方向感度つき検出（Blanco, Collar, Kahn, Lillard ら）。いずれも狙いは**断面積ではなく空間分解能と方向情報**であり、本項の向きと一致する。なお太陽ニュートリノの CEvNS は**まだ観測されていない**（暗黒物質探索でいう「ニュートリノの霧」）。外部情報はいずれも 2026年5月時点の知識なので、論文化の際は現状を確認すること。

## 付録A — セッション検証規則（本セッションで増えたもの）

- **非整数冪を扱うときは底が負にならないか確認する。** `cos(θ/2)**(2p)` は θ > π で底が負になり、非整数 p では複素数を返す。占有数の層（𝒯 = cos²(θ/2) ≥ 0）で定義し直すこと。実際に一度この誤りを出した。
- **零点を符号変化の走査で数えるとき、格子点上の零点を取り落とす。** dD/dθ の零点（θ = 0, π）を二度取り落とした。周期境界の零点と、格子点にちょうど乗る零点の両方に注意する。閉形式が得られるなら解析的に数えること。
- **離散性の観察が出たら、それが位相幾何なのか代数なのか解析なのかを分ける。** 本セッションでは三つが同じ顔をしていた（調和性＝代数、臨界点とメビウス＝位相幾何、分解の大域性＝解析）。2026-09-07 の規則（符号や大小の観察が出たら背後の位相幾何か代数を探す）の逆向きの型である。
- **「閉じない」と「稀に訪れる」を混同しない。** 非閉軌道でも一様分布定理により訪問率は普遍である。#9 の希少性論証がこの混同だった。
- **柔らかさのような性質は、利点と欠点を同時に供給していないか確かめる。** 低振動数モードの密度は、低い閾値の理由でもあり熱容量の理由でもあった。

## 付録B — #9 の素材は揃っていたのに、なぜ繋がらなかったか

- **(1) K.E. の非負性が検査されていなかった。** #9 は「K.E. はもう簡約できない」と書いて先に進んだ。簡約できない項は**中身を問われなくなる**。記号が消えた量は検査されない ── 幹 T2 付録A の (1)（差 D に記号がなかった）と同じ型である。
