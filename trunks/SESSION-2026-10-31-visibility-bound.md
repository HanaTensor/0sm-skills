### 0.2 三つの読み

#38 の文言は三通りに読める。**数を持つのは C だけ**なので、検定の対象は C とする。

| 読み | 内容 | 何が反例になるか |
|---|---|---|
| **S 厳密値** | 観測される可視度は常に 0.414（環境・配置に依らない、§4.2 の字面） | 0.414 と異なる値すべて。可視度が温度・バイアス・照明で動くこと自体 |
| **C 天井** | 固有の因子が 0.414 で、観測値 ＝ 0.414 ×（外部の因子 ≤ 1）≤ 0.414 | **0.414 を上回る値**。下回る値は検定にならない |
| **W 弱い** | V = 1 は原理的に達成できない（§7） | 誤差の中で V = 1 の測定のみ。有限の精度では反証できず、それだけでは数を持たない |

**検定の向きは非対称である** ── 外部の不完全さ（空間的コヒーレンス・エネルギー幅・振動・検出器）は可視度を**下げることしかできない**ので、C の下では低い値は何も言わず、**高い値が一つあれば足りる**。同日の Q4 が「電子線ホログラフィーの 10–40% は確証にも反証にもならない」と書いたのはこの向きのことである。

## §1 内部の検算（U1–U6、U12、U13）

**U1** ── V = 2√(I_A I_B)/(I_A + I_B) = (1 − D²)/(1 + D²)（T1.8）は #38 式 (4.3) の右辺と θ₃₈ = θ/2 で一致し、∫₀^π sin²u/(1 + cos²u) du = π(√2 − 1) から **⟨V⟩ = √2 − 1 は厳密**（30 桁の求積でも一致）。一粒ごとの V は 0（D = ±1、片方の核に全エネルギー）から 1（D = 0、赤道）まで動く。**代数に誤りは無い。**

**U2 字義どおりの式は使えない** ── #38 式 (4.1)・(4.3) を字面どおり（交差項の係数 2𝒞、𝒞 = 2cs）に読むと I_min = (3cos²θ − 1)/2 で、**位相の 39.2%（sin²θ > 2/3）で強度が負**になり、V の最大は 2 になる。この読みの平均 2(√2 − 1) = 0.828 は 0.62 と 0.92 の間に落ちるが、**物理的に許されない式の値なので救済には使えない**（T1 §4 の「係数の重複」の帰結として記帳）。

**U3 数え方** ── 同じ式から、平均の取り方で二つの値が出る。

| 数え方 | 値 | 使った論文 |
|---|---|---|
| **一個一打**（各電子が一点。確率密度を一粒ごとに規格化して足す） | **√2 − 1 = 0.4142** | #38 §6 の MC |
| **強度の和**（Σ I をそのまま足す） | ⟨2cs⟩/⟨c² + s²⟩ = (1/4)/(3/4) = **1/3** | **#4 の式 (e3_J0_W_int)** |
| **通過中に θ が回る**（README §0.1。通過時間は内部周期の 10⁴–10¹⁴ 倍、U10） | 一粒の像が時間平均され **1/3** | ── |

**corpus は同じ式に二つの平均を使ってきた**（#4 は 1/3、#38 は √2 − 1）。どれを採っても天井は √2 − 1 を超えない。なお §0.1 の著者宣言（θ は内部時間そのもので回る）を厳密に当てると、#38 §4.1 の「一粒は定まった θ を持つ」は通過中に成り立たず、値は 1/3 に下がる ── **内部の不整合だが、救済の向きには動かない。**

**U4 層と分布** ── 層と位相の分布を替えた変種の天井。

| | 位相一様（#38。README §0.1 と両立） | 球面一様（Bloch 球上で D が一様。**参考** ── §0.1 と両立しない） |
|---|---|---|
| p = 2（エネルギー層、I = 𝒯²、#38） | **√2 − 1 = 0.4142** | π/2 − 1 = 0.5708 |
| p = 1（占有層、I = 𝒯） | 2/π = 0.6366 | **π/4 = 0.7854** |

**README §0.1 と両立する変種の天井は最大 2/π = 0.637**（p = 1 は一個一打でも強度の和でも 2/π）。§0.1 は θ が回り TPE が 100% から 0% まで移ると言うので、どの瞬間でも D = cos θ は逆正弦分布に従い、球面一様（D が一様）は取れない ── 右の列は §0.1 を捨てた場合の参考値である。Ji ら 2003 の 0.62 だけなら 2/π の下に収まる（層を一段ずらせば逃げられるように見える）が、**真空の電子の 0.67・0.78 が 2/π を超え**、固体中の電子と中性子の 0.90 以上は参考値の π/4 = 0.785 も超える（§2）。p = 3, 4 は 0.301, 0.235 でさらに低い。

**U5 分布に依らない上界** ── x = D² ∈ [0, 1] で (1 − x)/(1 + x) ≤ 1 − x、√(1 − x) ≤ 1 − x/2 なので、**どんな位相分布でも ⟨V⟩ ≤ 1 − ⟨D²⟩（p = 2）、≤ 1 − ⟨D²⟩/2（p = 1）**。位相一様なら ⟨D²⟩ = 1/2 で、上界は 1/2 と 3/4。**0.92 を出すには ⟨D²⟩ ≤ 0.08（p = 2）** ── 分波の瞬間にほぼすべての粒子が赤道（TPE_A ≈ TPE_B、KE 最大、#58 の放出位相）にいなければならない。

**U6 外部の分波器** ── 外部の分波比 T と二核の分配を掛けた模型（I₁ = T·c², I₂ = (1 − T)·s²）でも、⟨V⟩(T) は T = 1/2 で最大 √2 − 1。**外部の分波器では天井は上がらない。** 形も違う ── V(T)/V(1/2) は、標準の 2√(T(1 − T)) が T = 0.05 で 0.44 まで下がるのに対し、積の模型は 0.86 を保つ平らな曲線になる。Ji ら 2003 は V(T₁) を 2η√(T₁(1 − T₁))（η ≈ 0.6）で当てはめている（図 2c）── 分波比依存の**形**でも標準の側に乗る。

**U13 同値な言い換え** ── #38 の V(θ) は、第一分波器の比を T₁ = c²/(c² + s²)（核エネルギーの比）に置き換え T₂ = 1/2 とした Mach–Zehnder 干渉計の理想可視度 2√(T₁R₁T₂R₂)/(T₁T₂ + R₁R₂) に厳密に等しい。**#38 §4 は「A の意味の隠れた変数（形式に無い自由度、README §0.2）である内部位相が、一粒ごとに分波比を決める」と言っている。** 経路に内部状態が相関する（which-path の印が付く）のではない ── その場合の可視度は |⟨χ₁|χ₂⟩| で、核 A・B が直交すれば 0 になる。標準の量子力学では、分波器が内部状態に盲目なら V は内部状態に依らず 1（T₁ = T₂ = 1/2）まで届く。

**U12 #4 の再現** ── 表 1 の 0.655:0.345、0.794:0.206 は θ₃₈ = π/4 − kπ/20 の cos²θ₃₈ : sin²θ₃₈。式 (e3_J0_W_int) の位相平均は (3/8)(a² + b²) + (1/4)ab で、等振幅の二波では **V = 1/3**（強度の和）。

**外村ら 1989 はコントラストの数値を書いていない。** 書かれているのは、電子の到来率を変えてもコントラストが 10% 以内で変わらなかったこと（誤差は主にバイプリズムの細線のドリフト）である。**#38 が支持に引いた実験には、比べるべき数が無い。**

### 2.3 可視度が外部の量で動く

バイプリズム電圧（Schütz 2014: 51% → 36%）、電子の温度とエネルギー（Ji 2003: 抄録で減衰を明記）、QPC の透過率（Ji 2003: 2η√(T₁(1 − T₁))）、干渉計の大きさ（Roulleau 2008）、結晶の熱処理（Heacock 2018: 23% → 90%）、干渉域の幅（Cho・Oshima 2013: 図の読み取り）。**読み S（環境に依らない）はこれだけで排除され**、可視度を決めているのは外部の量である。

### 2.4 地雷 ── 中性子干渉計の H ビームの約 40%

完全結晶の中性子干渉計では O ビームの理想は 100% だが、**H ビームは動力学的回折のため約 40% が上限**である（Huber ら 2024 §II B）。ILL S18 の装置一覧にある 40% の型も装置の性質である。**H ビームの 0.4 と √2 − 1 = 0.414 の近さは偶然**（look-elsewhere。10-31 nucleon の Q1 と同じ型）で、比べるのは O ビームに限る。

## §3 前提の判定

### 3.1 前提 (a) ── すべての実験で成り立つ（逃げ道 (a) は運動学で閉じる）

内部位相の周期（V の周期）は **#38 の書き方で πħ/m_ec² = 4.0×10⁻²¹ s、現行の ν_ZB = βc/λ_C = 5.0×10¹⁸ Hz で 1/(2ν_ZB) = 1.0×10⁻¹⁹ s**（U9）。

- **連続源には時刻の基準そのものが無い** ── 量子ホール干渉計の直流バイアスによる貯水池からの注入、原子炉、電界放出・熱電子放出。位相は定義により一様である。
- **飛行時間のぼけが周期を桁違いに上回る**（U10）── TEM（200 keV、ΔE = 0.3 eV、光路 1 m）で 2×10⁻¹⁵ s ＝ 周期の 2×10⁴ 倍（現行）／5×10⁵ 倍（#38）。中性子（λ = 2 Å、Δλ/λ = 1%、光路 0.1 m）で 5×10⁻⁷ s ＝ 10¹²–10¹⁴ 倍。
- **仮に放出時刻を 1 as に揃えても**周期の 10 倍（現行）／250 倍（#38）で、位相分布の一様からのずれ（第一 Fourier 成分）は ×10⁻⁸⁵⁸。
- **逆算**（U9）── 位相を赤道のまわりに選んで実測に届くには、0.62 で周期の 64%、0.92 で 23%、0.98 で 11% の窓が要る。時刻にして **10⁻²²–10⁻²⁰ s** の精度で、分波の瞬間の位相を揃えねばならない。

**したがって前提 (a) はどの実験でも成り立ち、「その実験では内部位相が揃っている」という逃げ道は無い。** 閉じ方の型は**運動学**（時刻の分解能と飛行時間の分散）で、理論の進展では動かない。#4 が書く「同位相で出れば鮮明な縞」も、同じ理由で実現しない ── 位相はバイプリズムに着くまでに一様になる。

**(1) 反例は 2003 年から公開されていた。** 電子の Mach–Zehnder 干渉計の 0.62 は #38（2026）の 23 年前に Nature に出ている。「普遍」と書いた数を、その粒子が干渉する**すべての分野**の最良の実験に当てる手順が無かった。同日の付録A (4)「『普遍』と書いた数は、最初に別の粒子で試す」の前段にあたる ── **まず同じ粒子の別の分野で試す。** 電子は真空（電子線）と固体（量子ホール端状態）の二つの分野で干渉し、可視度の記録は分野ごとに別の文献にある。
