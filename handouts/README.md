# handouts/ — 読ませるために切り出したもの

幹（`trunks/`）は自己完結した作業記録であり、**他人が読む順序では書かれていない。**
ここには、幹の内容を読ませる順序に組み替えたもの、および議論の前提を外部の知識体系に接続しなおしたものを置く。

## 規約

- 幹の内容をここに複製しない。**組み替えるか、外部知識を足すか、どちらかの仕事をしていること。**
- ファイル名に日付を入れる。改訂は新しい日付の版として保存し、旧版は残す。
- 数値には確度を添える。◎ 検証済み／○ 公表値あり（出典付き）／△ 概数・モデル依存／× 未測定。
