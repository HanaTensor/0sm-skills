# 0-Sphere Model Wall Practice（壁練）

0SM コーパス（#1–#68、#16 永久欠番）を土台とする構想議論セッションの実行 skill。役割分担: **本 skill = 発火と議論**、`0sm-corpus-curate` = 成果の workspace 確定登録、`0sm-zenodo-upload` = 論文化後の寄託準備。

## 1. Trigger conditions

- User が「壁練」「壁打ち」を宣言、またはテーマを提示して 0SM 文脈での議論を求めた
- 「N1 を進めたい」「T1 の K4 を攻めたい」「幹 T4 の K1」「幹 T◯ の続き」「#67／#68 の続き」型の依頼
- 「#XX の未解決問題を攻めたい」「新論文を構想したい」「◯◯は 0SM でどう説明されるか」型の依頼

## 2. 起動手順

1. **インデックス取得**（必須・最初に行う）:
   `https://raw.githubusercontent.com/HanaTensor/0sm-skills/main/wall-practice-index.md`
   （jsDelivr はキャッシュ遅延があるため raw を使う。補助: 同 `/index.md` = DOI 全表）
   **§0「現在地」と §2「地雷」を必ず読むこと。**
2. **幹の判定**: §0 の幹一覧を見て、テーマが幹に該当するなら
   `https://raw.githubusercontent.com/HanaTensor/0sm-skills/main/trunks/T<n>-....md`
   を**丸ごと読む**（要約で代替しない）。幹の §0 に著者設定のバイアス境界と議論方針があり、これに従う。**幹の再開手順（§7 等）に指示された節・資料も読む**
3. **一次資料**: `tex-sources/NN/main.tex`（raw URL）または Zenodo DOI 直接 fetch。個票精度が必要なら baseline の `context/papers/NNN.md` 添付を依頼
4. **外部知識が要るとき**: `handouts/README.md` を見る（§7）
5. fetch 不能時は §5 の地雷だけは守り、必要論文の添付を User に依頼

## 4. 壁練モードの規範

- **両輪検証**: 0SM 内部整合性の検査と、標準理論（QFT/GR）側からの反論の両方を率直に。賛否のバランスを崩さない。ただし**幹が「反論への反論は書かない」等の議論方針を設定している場合はそれに従う**
- **数式は検算する**: 主張に数値・次元が伴う場合は計算で確認（bash 可）。**外部の実測限界と突き合わせること** ── #67 は MICROSCOPE・原子時計比較・原子質量との接触で結論が出た。T1.6 は電子 EDM 上限で 20 桁の排除を確認した。内部整合の検査だけでは足りない
- **検算規則二つ**（2026-09-09、実際に踏んだ落とし穴）: **非整数冪は非負が保証される層（占有層 𝒯 = cos²(θ/2)）で計算する** ── 振幅層でやると底が負になり複素数が出る。**臨界点は格子上の符号走査ではなく閉じた式で数える** ── 零点が格子点や周期の端に乗ると見落とす
- **外部入力は毎回現状を確認する**: 実験上限・施設仕様・物性値は数年で変わる。**幹に書かれた外部知識は古い可能性を前提に扱い、古ければ推論の誤りとは別の節に訂正として記す**（T4 §4.1 がその型）
- **既存論文との照合**: 新規主張は重複・矛盾を先にチェック。**「これは未解決」と書く前に、後続論文が動かしていないか確認する**（#66 が rank-2 を動かしていた例がある）
- **誤りは消さずに記帳する**: 幹の撤回節に理由とともに残す。**閉じた提案は閉じ方の型（運動学／統計／密度／比の不変性）まで書く。** 運動学と統計で閉じたものは理論の進展では動かないが、密度と背景で閉じたものは条件次第で動く
- **未解決問題への接続**: 議論の結論は「どの課題（N.n／T◯ の K.n）を閉じた／開いた／変形したか」で締める
- **採番史は扱わない**: 旧番号・改番経緯には言及しない。現行番号のみ

## 5. 地雷（fetch 不能時もこれだけは守る）

- **0.040374c は corpus-wide 撤回**。原因＝質量を kg のまま入れ幾何学化質量 GM/c² を使わなかった。保有8本 = #14/#15/#17/#20/#22/#23/#27/#37。レプトン臨界半径（3.43e-25 / 5.71e-24 m）と崩壊の説明も同時に撤回。**正準値は #10 の 0.04047c**（β²=0.00163798087）
- **過剰撤回も禁止**: #22 の Δν/ν≈5.29×10⁻¹⁰（時計比で速度が相殺）と #15 の γ=1+a は無傷。#23 の「GR 補正は量子スケールで無視できない」は #28 に反転されており繰り返さない
- **地平面凍結（#63）は観測的シグネチャとして撤回済み**（LPI 限界で 10⁸ 倍排除）。遠方観測者の記述としてのみ残る
- **0.04047c は生きている** ── パラメータフリーの**未測定の第一義的予言**。幹 T1 はこの値を既定値として立つ
- **用語**: corrected／**retracted＝撤回**（corpus-wide もあり）／superseded／set aside by decision。**「rejected/棄却」は使わない**

## 6. 出口（セッション終端の3分岐）

1. **論文化へ**: `0sm-corpus-curate`（curate）→ `latex-paper-drafting`／`revtex-aps-format`（起草）→ `0sm-zenodo-upload`（寄託4成果物）
2. **継続へ**: 状態は**成果物本体**（#68 §1 の再出発宣言／該当する幹）と `wall-practice-index.md` に書き戻す。HANDOFF 文書は作らない ── 成果物の外に状態を置くと乖離するため
3. **幹への還流**: 幹から派生した議論は幹の §5 に追記し、**新しい日付の版**として保存（旧版は残す）。派生議論の起点として繰り返し使える新テーマが立ったら新しい幹 T<n> を起こす（規約は `trunks/README.md`）。index には幹への一行のみを置き、内容を複製しない。**再開手順の節を忘れずに更新する** ── 新しく作った節や資料をそこから指さなければ、次のセッションはその存在を知らない
