## 3d. 第 5 稿：#51・#66 からの変更を I 節に明記（著者決定、2026-11-27）

I 節の「#51 が導入した螺旋が載る面を本稿が定める」を、次の二段に置き換えた。

- **既発表の読み**：#51 は横の回転を ZB の亜光速、縦のピッチを ∼c とした。#50 も亜光速を赤道の回転に置いた。#66 は亜光速を、内部の媒質（屈折率 n）の中の担い手の群速度 c/n と読んだ。
- **本稿の変更**：
  - #51 の割り当てを逆にする。亜光速は核の間の軸方向の運動に属し、軸のまわりの運動はほぼ c で回る。
  - #66 の内部の媒質を、経路の幾何で置き換える。飛行中のエネルギーはどこでも c で動き、軸方向の移送が c より遅いのは、ホースの上の経路が軸より長いからで、屈折率が担い手を遅くするからではない。
  - #51・#66 の ν = v/λ_C は残す。速さは軸方向の移送の速さと読む（VI 節）。#66 の帰結のうち屈折率の値に依るものは、本稿では使わない。
  - #51 は「予言の速さを捨てることになる」として一様な速さ c の螺旋を退けた。ホースではその速さは捨てられず、軸への射影が担う。経路の上の速さは c。
  - 本稿は、その螺旋が載る面を定める。
