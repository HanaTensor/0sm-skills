## 概要

#51 v3 の表 II は、横の回転を v_ZB ≈ 0.04c、縦のピッチを v_pitch ≈ c としていた。著者の提案（07:45）で役割を入れ替えた。**光は常に光速で yz 面を回り（青線）、A から B へは亜光速の v_ZB で移る（赤線）。** 議論の末に、著者が「一番しっくりくる」とした像は次のものである（09:19）。

> 核 A・B を両極に置いた回転楕円体（x の半軸 d/2 = λ_C/4、横の半軸 ƛ_C = λ_C/2π）の上を、代表の粒が**光速で**、極角を内部位相 θ と同じ速さで一様に進む。粒の x 軸への射影は、厳密に #1 の単振動 x = −(d/2) cos θ になり、その速さは #1 の輻射勾配 sin θ に比例する。

![採用した描像](fig_spheroid_hose.png)

## 現在地

- **確定**したもの: 二つの恒等式の役割分担、取り分 ＝ 輻射勾配の積分、射影 ＝ 単振動、半径 ƛ_C の輪の量（赤道で ħ/2・μ_B・g = 2）、光を曲げる力のビリアル ＝ E₀/2、ランベルト則から cos²(a/2)。
- **最優先の未決**: 予言値 ν_ZB をどの層の刻みで読むか（§7 の U1。午後の追記 §14.4 で「平均か二乗平均か」から「放出される光子はエネルギーの層とスピノールの層のどちらの刻みを運ぶか」へ絞られた）。
- **最大の弱点**: 角運動量が一周期で保存しない（§7 の U2）。
- **決め手の候補**: 光が自分自身を輪に閉じ込める理論（自己捕捉）。ホースの形を外から与えずに出す道（§7 の U5）。

## 14. 午後の追記（11:06–11:15）── #50、#10、#29〜#31 との照合と、層の統一

照合した資料：#50（main.tex）、#10（Zenodo 17764997 の PDF）、#29 v1・#30 v2・#31 v1（日本語版 PDF）、#62（tex-sources）。検算は `layers_10_29.py`。

### 14.1 #50（カイラリティ・ヘリシティ）への適用

**光速と亜光速の両立。** Dirac の速度演算子 cα の固有値 ±c（Breit）＝ 青線の粒の速さ（常に c）。Foldy–Wouthuysen の平均位置（震えない、速さ < c）＝ 赤線の影。Zitterbewegung（正と負の枝の干渉）＝ 行き（A→B）と帰り（B→A）の半周期の入れ替わり（#50 の表 4 の 5・6 行、#7）。#66 の「±c は搬送体の速さではない」は改める必要がある。

**三つの二値。**

| 二値 | 絵の上での意味 | #50 での役割 | 自由度か |
|---|---|---|---|
| 進む向き sign(v_x) | 影が A→B か B→A か。半周期ごとに入れ替わる | 正と負のエネルギーの枝 | 位相の範囲（#50 §7.6 の点検どおり） |
| 回る向き w | x 軸のまわりの回転の向き。往復を通じて一定 | スピンの射影 ±½ | 二値 |
| 時計の向き sign(dθ/dt) | 内部の位相が進むか戻るか | カイラリティ χ | 二値 |

2 × 2 ＝ 4 で、#50 の自由度の点検と整合する。

**候補：内部の螺旋の巻き方が定まる閾値。** 巻き方 ＝ sign(v_x) × w。静止した電子では半周期ごとに入れ替わる。並進の速さ V が影の最大の速さを超えると定まる。閾値は運動エネルギーで約 1.04 keV（平均の読み、最大 0.0636c）、または約 0.84 keV（二乗平均の読み、最大 0.0572c）。どの観測量に現れるかは未定（U11）。

**機構の付与：質量ゼロの極限。** #50 の表 6 の 7 行目（評価 △：「m → 0 で v_ZB → 0」）に代えて、m → 0 で輪の半径 ƛ_C = ħ/(mc) が無限大に広がって回転が消え、粒の速さ c がすべて x 方向に回り、追い越せないので h = χ（Weyl の極限）。Dirac 側の「質量のない粒子は光速で進む」と一致する。

**#50 を改める必要がある点（U12）。** (a) §6.4「v_ZB は yz 面の回転の赤道の速さ」は入れ替えにより訂正。(b) 「回転は内部の位相空間にあり実空間の軌道ではない」という但し書きは、回転楕円体（λ_C の大きさの実空間の絵）と食い違う。SPH の立場とは整合。(c) Thomas 歳差の居場所（14.3 で解消の候補）。

### 14.2 #10 との照合

**#10 がしていること。** II 節：v = cos ωt、a = −sin ωt を Thomas の式に入れ −½ sin 2ωt（v ⊥ a が必要。後に #49 が弧の曲がりで補った）。III 節：回転の Lorentz 収縮（自転車の車輪）。a = (g − 2)/2 の「2 で割る」を根拠に、半周 π のうち割合 a が縮むと読む（式 III.1–III.4、L/L₀ = 1/(1 + a)）。式 III.5：交流の実効値にならって a/√2。式 III.9–III.10：0.04047c を「平均の速さ」と呼び ν = 5.007×10¹⁸ Hz。#10 はすでに「仮想光子が正弦の最大の速さで光速に達しても、全体の速さは平均して光速より小さい」と書いている（今日の青線と赤線の萌芽）。

**発見 A：U1 の出どころ。** #10 は二乗平均で作った値を「平均の速さ」と呼び、振動数の計算では平均の速さとして使っている。#62 の 2^(1/4) の食い違いも同じ式 III.5 から来る。

**発見 B：光時計が #10 の「π の割合 a」を出す。** 赤線の最大で γ = 1 + a とすると、⟨γ − 1⟩ = a/2（⟨sin²θ⟩ = ½）、一回転あたりの角の不足 ＝ 2π × a/2 ＝ a·π（数値 3.6416×10⁻³ と 3.6432×10⁻³）。Thomas 歳差を使わずに #10 の主張が出る。

**代償（14.4 で整理）。** この読みでは赤線の最大 0.0481c、平均 0.0306c（3.79×10¹⁸ Hz、15.6 keV）、二乗平均 0.0340c（4.20×10¹⁸ Hz、17.4 keV）で、正準値 0.04047c はどれにも一致しない。

### 14.3 #29〜#31 との照合

**#29 の半円 ＝ 球のホースの子午線（確定）。** 赤線からの距離を r とした (x, r) の半平面は上半平面で、境界 ＝ x 軸 ＝ 熱測地線（#29 の「一様な領域では実空間の直線」）、核 ＝ 境界上の無限遠点。球のホース（半径 d/2）の子午線は境界に直交する半円 ＝ #29 の測地線。子午線が中心のまわりに掃く角 π ＝ #29 の「一方向の伝播で外部は π」。

**光速の粒の回る角 ＝ 双曲的な長さ（確定）。** 双曲計量 (dx² + dr²)/r² で半円に沿った長さは ln tan(θ/2)（数値で一致）。粒の方位角 φ = cot ψ × ln tan(θ/2)（メルカトル図法で航程線がまっすぐになる関係）。両極の近くの無限の巻き ＝ 無限遠点までの無限の双曲的距離。#29 の式 (II.2) の左辺 ∫ω_hyp が、青線の回る角として実在する。
