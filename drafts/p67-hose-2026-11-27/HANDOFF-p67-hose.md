## 3. 著者の見解（草稿に反映されているかを必ず確かめる）

1. **0SM は場の理論から粒子力学（流体力学、SPH 法）をなぞる。** 場の理論の語彙で読まない。草稿の「grain」は SPH の代表粒子にあたる。
2. **d = λ_C/2 の出どころ**：熱ポテンシャルのエネルギーがすべて光子に変わったときの波長が Compton 波長である、という定義に由来する（著者 17:43）。草稿の II 節はこれを「往復一回分の波長」として書いている。輪の半径 ƛ_C も同じ光子から出す。
3. **v_ZB は、電子が加速されてもされなくても、それとは別のスコープで起こっている内部の微小振動である**（著者 18:04）。電子全体の速さ V とは別の量。草稿の III 節 d「Three speeds」と VII 節がこれに従っているかを確かめる。
4. **描像**：A から B へは熱ポテンシャルのエネルギーの測地線（x 軸、赤線）。運動エネルギーの螺旋は、回転楕円体のホースの上を光速で進む（青線）。エネルギーは砂山が崩れるように順に放射され、先に B に着いたものから順に凝固する。一度に光子に移るのではない。
5. **代数が主で、ホースは従。** x への射影が sin になることが要点（#1 の輻射勾配から単振動が出る）。
6. **静水圧平衡は必ずしも守らなくてよい。** 熱勾配が大事。
7. **一般相対性理論**：電子を高高度に持っていくと、その分だけ観測される v_ZB が速くなる。この描像で説明できる（#22）。
8. **0.04047c は生きている正準の予言。** 自分の判断で変えない。0.040374c（撤回済みの別の値）と混同しない。
9. **#65 で撤回した Stefan–Boltzmann の T⁴ の読みを持ち込まない。**
10. **論文の書式**：本文に疑問文を入れない。読者案内（「大学院生向け」など）を入れない。引用は Zenodo で DOI が確定した論文だけ。前方参照をしない。寄託物に GitHub のリポジトリ名・パス・アドレスを書かない。

## 5. 草稿の要点（読む前の見取り図）

- **前提**：E₀ をすべて一個の光子に変えると波長 λ_C。軸に沿って往復一回分 → d = λ_C/2。輪として一周分 → R = ƛ_C。したがって d = πR、縦横比 π/2。
- **ホース**：半軸 λ_C/4 と ƛ_C の回転楕円体。粒は速さ c で、極角 θ が一様に進む。x への射影は v_x = v_p sin θ（#1 の単振動）。v_p < c で、値は決めない。
- **恒等式**：占有の層 ψ_A² = cos²(θ/2)、ψ_B² = sin²(θ/2)。その重心が赤線になる。四次の層は cos⁴(θ/2)、sin⁴(θ/2)、飛行中 ½ sin²θ（#65）。v_x/v_p = 2ψ_Aψ_B。
- **赤道**：L = ħ/(2γ_p)、μ = μ_B/γ_p、g = 2（厳密）。
- **往復**：ν = v̄/λ_C = (2/π) v_p/λ_C。光時計の横の速さは c/γ(v_x)。
- **特殊相対性理論**：静止から加速すると縦横比は π/(2Γ)。Γ = π/2（0.7712c、292 keV）で球に見える。例の表を VII 節に置いた。輪の時計から de Broglie 波長 h/p。
- **一般相対性理論**：各点で不変。遠くから見ると刻みが (1 + Φ/c²) 倍。地表と GPS 軌道で 5.29×10⁻¹⁰（#22）。
- **注記**：子午線は Poincaré の半円（#29）。
- **Scope**：軸方向の速さの値、赤道以外の角運動量、螺旋の巻き方は扱わない。
