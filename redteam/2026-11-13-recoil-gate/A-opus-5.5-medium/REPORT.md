# 検算報告 ── 二核のあいだのエネルギー移送と質量双極子

**要約（三行）**
1. **確かめたこと**：BRIEF の設定どおりに質量双極子 D と二階モーメント J を閉じた形で求めた。核を固定した場合（Q1）、核対の反跳を許した場合（Q2）、運動量の割り当て方（Q3）、光子球の置き方を三通り変えた場合（Q4）、四重極放射（Q5）を、sympy で厳密に、numpy で数値でも確かめた。
2. **わかったこと**：核を固定すると D は ω と 3ω で振れる。反跳を許せば D を一定に保つ x_m(θ) = C + (d/16)(9cosθ − cos3θ) が定数 C を除いて一意に決まる。振幅はちょうど d/2、核の最大速度は 0.095c（d=λ_C/2）と 0.191c（d=λ_C）。J = (E₀d²/16)sin⁴θ(1+sin²θ) で、成分は 2ω・4ω・6ω の偶数倍だけ。出力の取り分は 12% : 79% : 9%、出力は約 1×10⁻⁴³ W（d=λ_C）。
3. **未決のこと**：D が一定になるには、離れた点どうしでエネルギーを受け渡すときの「移送の運動量」が欠かせない。これを光速以下の流れで運ぶと、予算 E₀ の外に最低でも (ωd/2c)E₀（d=λ_C で E₀ の 12.7%）の「移送中のエネルギー」が要る。このため設定のエネルギー収支は O(ωd/c) で閉じていない。また 4ω・6ω の成分では nωd/c ≳ 1 となり、四重極近似が怪しい。

## 0. 選んだ読み（曖昧な点）

| 点 | 採った読み | もう一方の読み（結論が変わる所で並べて計算） |
|---|---|---|
| T_A, T_B, K の中身 | **読み A**：系の全エネルギーはこの三つだけ（核にこれとは別の静止エネルギーは無い）。D・J もこの三つで作る | **読み B**：核それぞれに別に静止エネルギー Mc² がある。Q2・Q5 で並記した |
| エネルギーを測る系 | 実験室系（核対が動いても T_A, T_B はそのまま）。速さ ~0.2c なので、別の読みも Q3 補で見積もった | **読み R**：T は核対の静止系での値で、実験室系では γ 倍になる |
| 光子球の運動量 | (K/c²)·v_γ（不変質量 K/c² の塊） | ±K/c（光としての運動量）。Q3 で検討 |

記号：θ = ωt、c₂ = cos(θ/2)、s₂ = sin(θ/2)。核 A は x_m − d/2、核 B は x_m + d/2。光子球は x_γ = x_m + (d/2)g(θ) に置き、基準案では g = −cosθ。
よく使う恒等式は E_B − E_A = E₀(s₂⁴ − c₂⁴) = −E₀cosθ、K = 2E₀c₂²s₂²。
数値は νλ_C/c = 0.040472、ωλ_C/c = 0.254294。

## Q1. 核を固定した場合

**導出**　x_m = 0 とおく。

c²D = E_A(−d/2) + E_B(d/2) + K·(−(d/2)cosθ) = −(E₀d/2)·cosθ·(1 + ½sin²θ)
  = **−(E₀d/16)(9cosθ − cos3θ)**

sympy でこの式と照合し、差が 0 になることを確かめた（`q1_q2_dipole.py`）。

**何が起きるか**
- D は ω（振幅 9/16）と 3ω（1/16）の二成分で振れる。
- 全運動量は P = dD/dt = **(3/4)(E₀ωd/c²)sin³θ** = (E₀ωd/c²)(9/16·sinθ − 3/16·sin3θ) で、0 にならない。最大値は θ = π/2 で、d=λ_C/2 のとき 0.0954 E₀/c（2.60×10⁻²³ kg·m/s）、d=λ_C のとき 0.1907 E₀/c。
- 核を固定するには、外から力 F_ext = dP/dt = (9/4)(E₀ω²d/c²)sin²θcosθ を加え続けなければならない。この力も ω と 3ω を含む（9/16·cosθ − 9/16·cos3θ）。

**結論**　D は全位相で一定には保てない。保てない分は「系が孤立していない」ことの表れで、運動量 P(θ) が支え（外界）とやりとりされる。支えまで含めた孤立系ではやはり D は一定になる。したがって Q1 の系を「質量双極子が振れる孤立した重力源」とみなすことはできない。一般相対論では源に ∇_μT^{μν} = 0 が課されるので、Q1 の設定はそもそも許される源ではない。

**弱点**　「固定」を外部拘束と読んだ。もし固定を「核が非常に重い」の意味で読むなら、それは読み B の M → ∞ の極限にあたる（Q2）。その場合 D は一定のまま、反跳はほぼ 0 になる。

## Q2. 核対の反跳を許す場合

**導出**　c²D は x_m について一次式で、係数は E_A + E_B + K = E₀ である。

c²D = E₀x_m − (E₀d/2)cosθ(1 + ½sin²θ)

これを一定値 E₀C とおけば、x_m が直ちに求まる。

**(a) 形と一意性**

x_m(θ) = C + (d/2)·cosθ(1 + ½sin²θ) = **C + (d/16)(9cosθ − cos3θ)** = C + (d/2)·(3u − u³)/2　（u = cosθ）

x_m は代数的に一次の条件で決まるので、加える定数 C（重心の位置）を除いて**一意**である。微分方程式の積分定数のような任意性も無い。
このとき光子球の位置は x_γ = C + (d/4)cosθ·sin²θ になる。θ = 0 では核 A が、θ = π では核 B が、ちょうど重心 C に来る。つまり、エネルギーをすべて持つ核が常に重心に座る、という形になる。

**(b) 有界性と振幅**　f(u) = (3u − u³)/2 は [−1, 1] で単調増加し（f′ = 3(1 − u²)/2 ≥ 0）、値域は [−1, 1]。したがって有界で、**振幅は d/2、全幅は d**。d=λ_C/2 で 6.07×10⁻¹³ m、d=λ_C で 1.21×10⁻¹² m。

**(c) 核の最大速度**　dx_m/dt = −(3/4)ωd·sin³θ なので、最大は θ = π/2 で v_max = (3/4)ωd。

| d | v_max | v/c | γ |
|---|---|---|---|
| λ_C/2 | 2.859×10⁷ m/s | **0.0954** | 1.0046 |
| λ_C | 5.718×10⁷ m/s | **0.1907** | 1.0187 |

どちらも光速未満である。光子球の速さの最大は |dx_γ/dθ| = d/4 から 0.0318c と 0.0636c。
読み B では振幅と速度が μ = E₀/(E₀ + 2Mc²) 倍になる。Mc² = E₀ なら d=λ_C で 0.064c、陽子程度の質量なら 5.2×10⁻⁵ c。

**(d) 振動数成分**　x_m は **ω と 3ω だけ**を含み、比は 9 : −1（5ω 以上は厳密に 0）。D はすべての成分が 0 である。x_m の形は Q1 の D の形を符号を変えて写したものになっている（x_m − C = −c²D_Q1/E₀）。

**弱点**　速さが 0.19c なので γ − 1 ≈ 1.9% になり、非相対論的な扱いの限界に近い（Q3 補を参照）。

## Q3. 自明さの点検

Q2 は D を一定と課して運動を決めたので、D が一定なのは作り方から当然である。以下では、運動量を部品ごとに割り当てて自明でない点を調べる（`q3_momentum.py`、`q3b_relativistic.py`）。

**運動量の割り当て**（c²/(ωE₀d) 倍で表示）
- 核対：P_pair = (E_A + E_B)v_m。相対論的にも p = Ev/c² は厳密に成り立つ。
- 光子球：P_γ = K·v_γ（塊としての割り当て）。
- 移送：P_tr = Σ Ė_i(x_i − x_c)。A → 光子球 → B の流れの率を a = −Ė_A、b = Ė_B とすると（a − b = K̇ を確認済み）、P_tr = a(x_γ − x_A) + b(x_B − x_γ)。これは離れた点のあいだのエネルギーの流れが持つ運動量（運動量密度 = エネルギー流束/c²）である。

| 部品 | 成分（sin nθ の係数） | 最大値 |
|---|---|---|
| P_pair | −21/64 (ω), +9/128 (3ω), +3/128 (5ω) | 0.375 |
| P_γ | −3/64 (ω), +7/128 (3ω), −3/128 (5ω) | 0.125 |
| P_pair + P_γ | = −½sin³θ（ω, 3ω） | 0.5 |
| P_tr | = +½sin³θ | 0.5 |
| 和 | **0（恒等的）** | ― |

**結果**
1. 和が 0 になること自体は積の微分の恒等式で、新しい情報ではない。自明でないのは、**移送の運動量 P_tr が塊の運動量の和と同じ大きさで必要だ**という点である。P_tr を落として「塊の運動量の和が 0」を課すと、x_m = (d/12)cosθ(2 + sin²θ) になる。このとき D は −(3/8)cosθ + (1/24)cos3θ で振れ、dD/dt = P が破れる。
2. **ω の成分は部品には残っている**。核対の運動量、光子球の運動量、移送の運動量、核対に働く力 F_pair = (E₀ω²d/c²)(−21/64·cosθ + 27/128·cos3θ + 15/128·cos5θ) のいずれにも基本波 ω がある。打ち消し合うのは総和だけである。双極子放射は総和の D だけで決まるので、これは矛盾ではない（連星でも各星は ω で動く）。ただし、「ω が消える」のは部品の和を取った後だけであり、部品の一つでも割り当てを誤ると ω の双極子が現れる。その意味で結論は割り当てに対して脆い。
3. **移送を光速以下で運ぶと、予算の外にエネルギーが要る**。率 Ė の流れが距離 L を速さ u ≤ c で運ばれるなら、途中にあるエネルギーは ĖL/u ≥ ĖL/c である。基準案での下限は E_tr,min = (ω/c)[a|x_γ − x_A| + b|x_B − x_γ|] で、最大は θ = π/2 の **(ωd/2c)E₀**。
   - d=λ_C/2 のとき **E₀ の 6.4%**、d=λ_C のとき **12.7%**。
   - この値は、光子球を二核のあいだのどこに置いても θ = π/2 では変わらない（a = b = ½ になるため。Q4 の三案すべてで同じ値を得た）。
   - BRIEF の収支 T_A + T_B + K = E₀ にはこの「移送中のエネルギー」が入っていない。したがって**収支は O(ωd/c) で閉じていない**。これがこの検算で見つかった最も大きな内部矛盾である。
4. **光子球の運動量を K/c にすると成り立たない**。K/c（最大 0.5 E₀/c）は K·v_γ/c² の 15.7 倍（d=λ_C）から 31.5 倍（d=λ_C/2）も大きく、それを打ち消す反対向きの運動量がどこにも無い。dD/dt = P と両立させるには、光子球を「不変質量 K/c² を持ち、光速よりずっと遅く動く塊」と考えるしかない。自由な光子ではなく、閉じ込められた定在波のようなものである。
5. **相対論補正（読み R）**。T を核対の静止系の値と読んで γ 倍し、D 一定を固定点反復で解き直した。
   - x_m の変化は d=λ_C/2 で 1.0×10⁻⁴ d、d=λ_C で 4.0×10⁻⁴ d。
   - 5ω・7ω の成分が 10⁻⁴ d の程度で新たに現れる。
   - 全エネルギーの揺れは d=λ_C/2 で 0.25%、d=λ_C で **1.0%**。
   - 結論の形は変わらないが、「E₀ 一定」も「x_m は ω と 3ω だけ」も、厳密には O(β²) で崩れる。

**弱点**　3 の下限は、エネルギーが一次元の経路に沿って局所的に流れる、という仮定による見積もりである。場が三次元に広がっていれば経路はさらに長くなり、下限も大きくなる。

## Q4. 置き方への依存

一般の置き方 x_γ = x_m + (d/2)g(θ)（光子球の内部の広がりを σ² とする）について、D 一定の条件は

x_m = C + (d/2)[cosθ − (K/E₀)g]

となり、x_m について一次なので**どの置き方でも必ず一意に解ける**。θ = 0, π では K = 0 なので、x_m = ±d/2 は置き方によらない（`q4_placement.py`）。

| 案 | x_m の成分 | 核の v_max（λ_C/2 / λ_C） | J の成分 | 出力の取り分 | P_GW（d=λ_C） |
|---|---|---|---|---|---|
| 基準案 g = −cosθ | ω, 3ω（9/16, −1/16）d | 0.095c / 0.191c | 0, 2ω, 4ω, 6ω | 11.9 / 79.1 / 9.0 % | 1.00×10⁻⁴³ W |
| (i) 一様分布 g = 0, σ² = d²/12 | **ω だけ**（d/2） | 0.064c / 0.127c | 0, **2ω だけ** | 2ω が 100% | 2.26×10⁻⁴⁴ W |
| (ii) 等速往復（三角波） | ω, 3ω, 5ω, 7ω, …（奇数倍すべて。0.545, −0.041, −0.0026, …） | 0.084c / 0.168c | 0, 2ω, 4ω, …（偶数倍すべて） | 18.6 / 81.1 / 0.25 % | 6.77×10⁻⁴⁴ W |
| (iii) 移送の運動量が 0 になる置き方 | g = −1/cosθ で発散 | ― | ― | ― | 採れない |

- **(i)** K が [x_A, x_B] に一様に広がるなら、その重心は x_m なので D には効かない。そのため x_m = C + (d/2)cosθ と純粋な ω になり、J = (E₀d²/6)sin²θ と純粋な 2ω になる。
- **(ii) を選んだ理由**　光子は一定の速さで進むのが自然であり、基準案の cosθ は「調和的に動く」という一つの約束にすぎない。等速往復はその約束を外した最も素朴な案で、高調波がどれだけ置き方に依存するかを見るのに適している。速さは 2ωd/π（d=λ_C で 0.081c）で、光速ではない。光速で往復させると片道 d/c の時間が半周期 π/ω の 8%（d=λ_C）にしかならず、K = ½E₀sin²θ という配分と両立しない。
- **(iii)** 「光子球が受け渡しの場所そのものにいる」（P_tr = 0）を課すと g = −1/cosθ になる。|g| ≥ 1 なので光子球は二核の外にあり、θ → π/2 で無限遠へ飛ぶ。つまり、**連続的な受け渡しを局所的に行う置き方は、点の光子球では存在しない**。これは Q3-3 の結論（移送の運動量は避けられない）を裏から確かめたことになる。

**結論**
- 置き方を変えても変わらないこと：D 一定の解が存在し一意であること。x_m が有界で幅 d であること（θ = 0, π で ±d/2）。J に奇数倍が無いこと。移送中のエネルギーの下限 (ωd/2c)E₀。
- 置き方で変わること：x_m に含まれる高調波（ω だけ／ω+3ω／奇数倍すべて）、核の最大速度（基準案に比べ最大 33% 小さい）、J の高調波と出力（4.4 倍の幅）。
- 「x_m は ω と 3ω だけ」「J は 6ω で打ち切り」は**基準案だけの性質**である。

**弱点**　奇数倍が消えるのは、置き方が g(θ + π) = −g(θ)（A↔B の鏡映と半周期のずらしの組で不変）を満たすときに限られる。ここで調べた三案はいずれもこれを満たす。A → B と B → A で振る舞いが違う置き方を採れば、J にも奇数倍が出る。

## Q5. 残る二階のモーメント

**(a) 閉じた形**　基準案で D 一定（Q2）のとき、x_A − C = (d/2)(f − 1)、x_B − C = (d/2)(f + 1)、x_γ − C = (d/4)cosθsin²θ である。u = cosθ とおくと

J/(E₀d²) = (1 − u²)²(2 − u²)/16、すなわち **J = (E₀d²/16)·sin⁴θ·(1 + sin²θ)**

= E₀d²·[11/256 − (31/512)cos2θ + (5/256)cos4θ − (1/512)cos6θ]

チェビシェフ展開（厳密）と FFT（数値）で一致し、差は 10⁻¹⁶ だった（`q5_quadrupole.py`）。θ = 0, π ではエネルギーがすべて重心の一点にあるので J = 0 になる。

**(b) 振動数成分**　0、2ω、4ω、6ω だけ。**奇数倍は無く**（数値でも 10⁻¹⁷ 以下）、**上限は 6ω**（J が cosθ の 6 次多項式だから）。読み B でも 0〜6ω の偶数倍だけである。

**(c) 高調波ごとの取り分**　I⃛ の n 次成分の振幅は (nω)³a_n E₀d²/c² なので、取り分は (n³a_n)² に比例する。n³a_n は 2ω で −31/64、4ω で 5/4、6ω で −27/64。

| 高調波 | (n³a_n)² の比（/4096） | 取り分 |
|---|---|---|
| 2ω | 961 | **11.88%** |
| 4ω | 6400 | **79.11%** |
| 6ω | 729 | **9.01%** |

出力の大半は 4ω が担う。読み B（Mc² = E₀）では 26.4 / 55.9 / 17.7%、陽子程度の M では 20.0 / 80.0 / ~0% になる。

**(d) 出力の大きさ**

P = (2G/15c⁵)⟨I⃛²⟩ = (2/15)·(4045/4096)·G E₀² ω⁶ d⁴ / c⁹

| d | P_GW | 一周期で失う割合 P/(E₀ν) | 減衰時間 E₀/P |
|---|---|---|---|
| λ_C/2 | 6.3×10⁻⁴⁵ W | 1.5×10⁻⁵⁰ | 1.3×10³¹ s |
| **λ_C** | **1.0×10⁻⁴³ W** | 2.5×10⁻⁴⁹ | 8.2×10²⁹ s（2.6×10²² 年） |

d⁴ に比例するので、d が 2 倍になると出力は 16 倍になる。読み B（Mc² = E₀）では 5.7×10⁻⁴⁵ W、陽子程度の M では 6.3×10⁻⁴⁴ W（d=λ_C）。

**弱点（重要）**　四重極公式は、系の大きさ R が放射の換算波長 c/(nω) よりずっと小さいことを前提にしている。ここでは R ≈ d（核 B は重心から最大 d 離れる）なので、展開の目安は nωd/c になる。

| d | 2ω | 4ω | 6ω |
|---|---|---|---|
| λ_C | 0.51 | **1.02** | **1.53** |
| λ_C/2 | 0.25 | 0.51 | 0.76 |

出力の大半を担う 4ω で、すでに 1 程度になっている。したがって d=λ_C の出力の数値と取り分は**桁の見積もり**にとどまり、高次の多極（八重極など）と遅延の補正が同じ桁で効くおそれがある。さらに Q3-3 のとおり、源の局所的な保存 ∇T = 0 自体が O(ωd/c) で満たされていない。

## Q6. 仮定の棚卸し

| # | 仮定 | どこに効いたか | 崩れたら |
|---|---|---|---|
| 1 | エネルギーの配分（cos⁴、sin⁴、½sin²）と θ = ωt の等速。力学から導かず、外から与えた運動 | すべて | 高調波の内容がすべて変わる。D 一定の解が存在することだけは変わらない |

**総合の判断**　「反跳を許せば質量双極子を一定に保てる」は、運動量保存を言い換えただけである。どの置き方でも成り立ち、頑健だが自明でもある。自明でない内容は二つある。一つは、運動量の帳簿を閉じるには移送の運動量が欠かせず、それを運ぶエネルギーが設定の収支から漏れていること（仮定 2）。もう一つは、四重極の出力の数値が置き方と多極近似の妥当性に強く依存すること（仮定 4 と 7）。結論の強さを上げるには、二核と光子球のあいだの場を一次元の連続体（エネルギー密度と流束を持つもの）として書き、∂_tu + ∂_xS = 0 を局所的に満たす模型で同じ計算をやり直すのがよい。
