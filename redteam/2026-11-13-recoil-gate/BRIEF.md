## 1. 設定

一本の軸（x 軸）の上に、次の三つの要素がある。

- **核 A と核 B**：二つの点。核間距離を d とする。
- **光子球**：二つの核のあいだを行き来するエネルギーのかたまり。軸の上の一点 x_γ にあるとみなす（§1.3 で置き方を指定する。置き方そのものも検討の対象である）。

### 1.1 エネルギーの配分

内部の位相を θ = ωt とし、各要素のエネルギーを次で与える（E₀ は全エネルギー）。

- 核 A：T_A = E₀ cos⁴(θ/2)
- 核 B：T_B = E₀ sin⁴(θ/2)
- 光子球：K = ½ E₀ sin² θ

すべての θ で T_A + T_B + K = E₀ が成り立つ。θ = 0 で全エネルギーが A にあり、θ = π で全エネルギーが B にあり、その間は一部が光子球として移動中である。θ が 2π 進むと A → B → A の一往復になる。

### 1.2 数値

- ω = 2πν、ν = 5.0007 × 10¹⁸ Hz
- 核間距離 d は二通りで調べること：**d = λ_C/2** と **d = λ_C**（λ_C = h/(m_e c) = 2.42631 × 10⁻¹² m）
- E₀ = m_e c² = 511 keV（必要なら）

### 1.3 光子球の置き方（基準案）

核対の中点を x_m とする（核 A は x_m − d/2、核 B は x_m + d/2）。基準案では、光子球はエネルギーを多く持つ核の側に寄り、

x_γ = x_m − (d/2) cos θ

に置く（θ = 0 で A の位置、θ = π で B の位置、θ = π/2 で中点）。

### 1.4 使ってよい標準的な事実

孤立系の質量双極子 **D = Σ E_i x_i / c²** は dD/dt = P（全運動量）を満たす。静止した孤立系では P = 0 なので、D は一定である。一般相対論では、このことが「重力の双極子放射が存在しない」理由になっている。

## 2. 問い

**Q1. 核を固定した場合。** x_m を固定し、光子球だけが動けるとき、D を全位相で一定に保てるか。保てないなら、何が起きるかを式で示せ。

**Q2. 核対の反跳を許す場合。** 核間距離 d を保ったまま、核対が一体となって x_m(θ) だけ動くことを許す（光子球の置き方は §1.3 の基準案のまま）。D を全位相で一定に保つ x_m(θ) は存在するか。存在するなら、
- (a) その形を求め、一意かどうかを述べよ
- (b) 有界かどうか、振幅はいくらか
- (c) 核の最大速度を d = λ_C/2 と d = λ_C の両方で求め、光速未満かを確かめよ
- (d) x_m(θ) と D(θ) の振動数成分（ω の何倍の成分を含むか）を求めよ

**Q3. 自明さの点検。** Q2 で「D が一定」を課して運動を決めたのなら、D が一定になるのは作り方から当然である。**自明でない検査**を考えて実行せよ。たとえば、
- 各要素の運動量（核対の運動量、光子球の運動量、エネルギーの移送に伴う運動量）を明示的に割り当て、その和が dD/dt と各位相で一致するか
- 光子球の運動量の割り当て方（E/c² × 速度、あるいは別の形）によって結論が変わるか
- **ω の成分が、運動量や力のどこかに残っていないか**

**Q4. 置き方への依存。** 光子球の置き方を変えると結論は変わるか。少なくとも次の二つで調べよ。
- (i) 光子球のエネルギー K が、二核のあいだに一様に分布している場合
- (ii) 自分で物理的に妥当と考える別の置き方（理由を書くこと）

**Q5. 残る二階のモーメント。** D が一定に保たれた状態で、重心まわりの二階モーメント J = Σ E_i (x_i − x_c)² を求めよ。
- (a) J(θ) を閉じた形で書けるなら書け
- (b) J に現れる振動数成分をすべて挙げよ（ω の何倍か、奇数倍はあるか、上限はあるか）
- (c) 四重極放射の出力は J の三階時間微分の二乗に比例する。高調波ごとの出力の取り分を求めよ
- (d) 出力の大きさを見積もれ（E₀ = m_e c²、d = λ_C の場合。式と数値）

**Q6. 仮定の棚卸し。** 以上の結論を左右した仮定をすべて挙げ、どれが最も弱いか、それが崩れたら何が変わるかを述べよ。
