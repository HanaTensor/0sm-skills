# 検算報告 ── 二核のあいだのエネルギー移送と質量双極子

**要約（三行）**

1. 確かめたこと：BRIEF §1 の配分と置き方のもとで、質量双極子 D を一定に保てるか、保ったときに何が残るかを、手計算と `verify.py`（記号計算＋数値）で調べた。
2. わかったこと：核を固定すると D は ω と 3ω で振動し、保てない。核対の反跳を許せば D を一定にする運動は必ず存在して一意、有界（振幅 d/2）、亜光速（最大 0.19c）である。残る二階モーメントは 2ω・4ω・6ω だけを含み、四重極の出力は 10⁻⁴³ W 程度になる。
3. 未決のこと：D が一定になること自体は作り方からの帰結で、物理の検査になっていない。運動量の収支は「移送に伴う運動量」を入れて初めて閉じ、その項も個々の要素の運動量と力も ω 成分を持ったままである。何が反跳を引き起こすのか（力の法則）と、電荷がどこに乗るのかは設定に無く、ここが決まらないと放射が無いとは言えない。

計算はすべて `python3 verify.py > results.txt` で再現できる（数秒）。以下の数値は `results.txt` からの転記である。

## 選んだ読み

| 箇所 | 選んだ読み | 結論への影響 |
|---|---|---|
| D に入れるエネルギー | §1.1 の T_A・T_B・K だけ。核の静止質量や反跳の運動エネルギーは入れない（E₀ が全エネルギーと書かれているため） | 反跳の運動エネルギーは最大で E₀ の 1% なので、結論は v²/c² の精度でしか成り立たない（Q3・Q6） |
| 核の最大速度 | 重心が静止した系で測った核の速度 | 光子球に対する相対速度も併記した |
| Q4 (i) の一様分布 | K が動いている二核のあいだ（長さ d）に一様に広がる。重心は x_m、分散は d²/12 | ── |
| Q5 (d) の出力 | 軸上に並んだ線状の源として標準の四重極公式を使う。横方向の広がり（「球」の大きさ）は無視 | 広がりが球対称なら四重極に寄与しないので変わらない |
| 定数 | ν と λ_C は BRIEF の値、ほかは CODATA 値 | ── |

記号：c ≡ cos θ、s ≡ sin θ と略す。T_A = E₀(1+c)²/4、T_B = E₀(1−c)²/4、K = E₀s²/2 で、T_A − T_B = E₀c である。

---

## Q1. 核を固定した場合

**結論：保てない。** 基準案では D が ω と 3ω で振動し、置き方を自由にしても光子球が無限遠へ飛ぶ。

**導出。** x_m = 0 として

c²D = −(d/2)(T_A − T_B) + K x_γ = −(E₀d/2) c + (E₀s²/2) x_γ

基準案 x_γ = −(d/2)c を入れると

c²D = −(E₀d/4) c(3 − c²) = −(E₀d/16)(9 cos θ − cos 3θ)

c² dD/dt = +(3E₀dω/4) sin³θ

D の振れ幅は ±E₀d/(2c²)。全質量 E₀/c² が核 A の位置から核 B の位置まで動くのと同じである（θ = 0 と θ = π で全エネルギーが別の場所にあるので、これは置き方によらない）。dD/dt = P ≠ 0 だから、系は孤立していないか、運動量が保存していないかのどちらかになる。孤立系として扱えば、質量双極子が ω と 3ω で振動する、存在しないはずの双極子放射源になる。

**置き方を自由にしても救えない。** D = C/c² に必要な位置は x_γ = (2C + E₀d c)/(E₀s²)。θ = 0 と θ = π で分母が 0 になり、分子はそれぞれ C + E₀d/2 と C − E₀d/2 で、両方を 0 にする C は無い。光子球はエネルギーが 0 に近づく位相で無限遠に行く。

**弱点。** 「光子球を一点とみなす」ことに依っている。ただし広がった分布でも重心について同じ式になるので、結論は変わらない。

## Q2. 核対の反跳を許す場合

**結論：存在し、定数を除いて一意、有界、亜光速。**

**(a) 形と一意性。** 核と光子球を x_m だけずらすと c²D に E₀x_m が加わるので

**x_m(θ) = x₀ + (d/16)(9 cos θ − cos 3θ) = x₀ + (d/4) cos θ (2 + sin²θ)**

dx_m/dθ = −(3d/4) sin³θ

x₀ は重心の位置。D = E₀x₀/c² を課せば x_m は各位相で一意に決まる（D は x_m の一次式で、係数 E₀ が 0 にならないため）。残る自由度は x₀ の選び方と、D = Pt + 定数 を許した場合の等速の並進だけである。

付随して、光子球は x_γ = x₀ + (d/16)(cos θ − cos 3θ) = x₀ + (d/4) sin²θ cos θ。また θ = 0 で核 A が、θ = π で核 B が x₀ に来る。つまり「エネルギーを全部持っている核」がいつも重心にいて、動くのは核の側である。

**(b) 有界性と振幅。** x_m − x₀ は +d/2（θ = 0）から −d/2（θ = π）まで単調に動く。振幅 d/2、全幅 d。

**(c) 最大速度。** |v| = (3ωd/4)|sin³θ|、最大は θ = π/2 で 3ωd/4。

| d | 核の最大速度 | 光子球の最大速度（重心系） | 光子球の核に対する最大速度 |
|---|---|---|---|
| λ_C/2 | 2.859 × 10⁷ m/s = **0.0954c** | 0.0318c | 0.0636c |
| λ_C | 5.718 × 10⁷ m/s = **0.1907c** | 0.0636c | 0.1271c |

どちらも光速未満。なお νλ_C/c = 0.04047 なので、ωd/c は 0.127（λ_C/2）と 0.254（λ_C）である。

**(d) 振動数成分。** x_m は ω（振幅 9d/16）と 3ω（振幅 d/16）。D は直流成分だけ（数値で max|D − 平均| = 2 × 10⁻¹⁶ E₀d）。

**弱点。**
- 存在と一意性は自明である。どんな置き方でも x_m を一つ足せば D は定数にできる。中身があるのは有界性・速度・振動数成分だけ。
- 核は 0.19c で動くのに、その運動エネルギーは E₀ の勘定に入っていない（Q3 で大きさを出す）。
- 「光子球」が光速の 3〜13% でしか動かない。光子と呼ぶなら説明が要る。

## Q3. 自明さの点検

**結論：運動量の収支は閉じるが、閉じるのは「移送の運動量」を入れたときだけで、それも恒等式である。ω 成分は全運動量からは消えるが、各要素の運動量と力には残る。光子球の運動量を E/c にすると破綻する。**

**検査 1：運動量を割り当てて足す。** 各要素に E_i v_i/c² を割り当てる。

- 核対：c²p_pair = (T_A + T_B) v_m = −(3E₀ωd/8)(1 + c²) s³
- 光子球：c²p_γ = K v_γ = +(E₀ωd/8)(2 − 3s²) s³
- 和：**c²p_naive = −(E₀ωd/2) sin³θ ≠ 0**（最大で E₀ωd/2c²）

動いている塊の運動量だけでは 0 にならない。エネルギーが A から光子球へ、光子球から B へと離れた場所に移るので、その流れが運動量を運ぶ。流れの大きさ × 距離で割り当てると

c²p_transfer = (−Ṫ_A)(x_γ − x_A) + Ṫ_B (x_B − x_γ) = +(E₀ωd/2) sin³θ

となり、和は全位相で 0（数値で 3 × 10⁻¹³）。ただしこれは Σ Ė_i x_i の書き換えで、dD/dt = Σ E_i v_i/c² + Σ Ė_i x_i/c² という微分の積の規則そのものである。A から B へ直接流す経路にしても合計は同じになる。**したがってこの検査も、連続の式を仮定すれば自動的に通る。通ったことは、モデルが正しい証拠にはならない。**

わかったのは逆向きのこと：全運動量の 0 は、塊の運動量 −(E₀ωd/2c²) sin³θ と移送の運動量 +(E₀ωd/2c²) sin³θ の打ち消しで成り立っている。移送項を消す置き方を探すと x_γ = x_m − (d/2)/cos θ となり、核の外に出て θ = π/2 で発散する。移送の運動量は避けられない。

**検査 2：光子球の運動量を E/c にする。** 光子球が本物の光なら運動量は K/c で、K v_γ/c² の 8〜30 倍になる。この場合、基準解のままでは最大 0.52〜0.53 E₀/c の運動量が余る。P = 0 に戻すには θ = π/2 で核対に 1.13c（λ_C/2）、1.25c（λ_C）が要り、**光速を超える**。そもそも速さ 0.03c で動く塊に E/c の運動量を持たせると、エネルギーの流れと運動量密度が食い違う。つまり結論は割り当てに強く依存し、Q2 が成り立つのは「光子球は速さ v で動く質量 K/c² の塊」と読んだときに限る。進行する光ではなく、ほぼ定在波のようなものと読まねばならない。

**検査 3：ω 成分はどこに残るか。**

| 量 | 含む成分 |
|---|---|
| 全運動量、D | なし |
| 核対の運動量 | ω, 3ω, 5ω |
| 光子球の運動量 | ω, 3ω, 5ω |
| 塊の運動量の和、移送の運動量 | ω, 3ω |
| 核対に働く力 | ω, 3ω, 5ω |
| 核対の位置 x_m | ω, 3ω |

打ち消しは「すべての要素が同じ結合で場に寄与する」ときにだけ効く。重力は全エネルギーに結合するので D だけが効き、双極子は消える。しかし結合が要素ごとに違えば ω は表に出る。たとえば**電荷が核に乗っていて光子球が中性なら、電気双極子は e(x_m − x₀) で、ω と 3ω で振動する**。ラーモアの式に入れると 2.6 W（λ_C/2）、10.4 W（λ_C）で、E₀ を 10⁻¹⁴ 秒で失う。電荷の置き場所は BRIEF に無いので、これは設定の外の参考値だが、質量双極子が一定でも電磁的な双極子放射が無いことは保証されない、という点は設定に依らない。

**検査 4：エネルギーの自己整合。** 基準解の反跳の運動エネルギー（非相対論）は最大で 0.25% E₀ = 1.3 keV（λ_C/2）、1.0% E₀ = 5.2 keV（λ_C）。これは T_A + T_B + K = E₀ の外にある。全エネルギーの保存か D の一定かのどちらかが、この大きさで破れている。

**弱点。** 検査 1 は恒等式、検査 3 の電荷の話は設定外の読みである。動力学（何が核を押すのか）が与えられていないので、作用反作用を独立に検査する手段が無い。

## Q4. 置き方への依存

**結論：存在・一意性・振幅 d/2・奇数次だけという性質は置き方に依らない。変わるのは高調波の中身と最大速度。**

光子球の重心を x_γ = x_m + (d/2) g(θ) と書くと、一般に

x_m − x₀ = (d/2)[cos θ − (sin²θ/2) g(θ)]

- 端点は g に依らない（s² = 0 なので）。振幅 d/2 は、θ = 0 と π で全エネルギーが一つの核にある、という配分だけで決まる。
- g(θ + π) = −g(θ)（A と B を入れ替える対称性）なら x_m は奇数次だけになる。

| 置き方 | x_m − x₀ | 成分 | 核の最大速度（λ_C/2、λ_C） |
|---|---|---|---|
| 基準 g = −cos θ | (d/16)(9cos θ − cos 3θ) | ω, 3ω | 0.095c, 0.191c |
| (i) 一様分布 g = 0 | (d/2) cos θ | **ω だけ** | 0.064c, 0.127c |
| (ii-a) 等速往復（三角波） | 数値 | 奇数次すべて（3ω で 0.041d、以後急減） | 0.084c, 0.168c |
| (ii-b) 核のエネルギーの重心 g = −2c/(1+c²) | d cos θ/(1 + cos²θ) | 奇数次すべて（等比的に減衰） | 0.127c, 0.254c |

**(ii) の選択理由。** (ii-a) は、光子球を A を出て B に着く自由な塊とみなす読み。力を受けない塊は等速で動くはずで、基準案のように端で止まる理由が無い。核に対する速さは 2dν = 0.040c（λ_C/2）、0.081c（λ_C）。(ii-b) は、光子球が二核の場に束縛されていて、場の源の重心に座るという読み。

どの場合も D は一定に保てる（(ii-a) で max|D − 平均| = 10⁻¹⁶）。一様分布のとき核は単振動になり、最も素直である。

**弱点。** (ii-a) は θ = 0, π で速度が跳ぶ。K がそこで 0 なので x_m は滑らかだが、塊の速さが 0.04c であって c でない理由は無い。置き方を選ぶ物理的な原理が設定に無いので、高調波の中身（3ω があるか）は予言ではなく選択である。

## Q5. 残る二階のモーメント

**(a) 閉じた形。** 基準案で、x₀ まわりに

**J(θ) = (E₀d²/16) sin⁴θ (1 + sin²θ) = (E₀d²/512)(22 − 31 cos 2θ + 10 cos 4θ − cos 6θ)**

θ = 0, π で 0（全エネルギーが重心の一点）、θ = π/2 で最大 E₀d²/8。

**(b) 振動数成分。** 2ω、4ω、6ω の三つだけ。奇数倍は無い。上限は 6ω。奇数倍が無いのは、θ → θ + π が A と B の入れ替え（x₀ に関する鏡映）で、J が鏡映で変わらないためである。これは置き方に依らない。上限の 6ω は基準案に固有（J が sin θ の 6 次式）。

**(c) 高調波ごとの取り分。** 三階微分の振幅は係数 × n³ に比例する。

| 成分 | J の係数（× E₀d²） | J⃛ の振幅（× E₀d²ω³） | 出力の取り分 |
|---|---|---|---|
| 2ω | 31/512 | 0.4844 | **11.88%** |
| 4ω | 10/512 | 1.2500 | **79.11%** |
| 6ω | 1/512 | 0.4219 | **9.01%** |

出力の 8 割は 4ω に出る。

**(d) 大きさ。** 軸上の線状の源では Q_ij Q_ij = (2/3)I²（I = J/c²）なので

P = (2G/15c⁵) ⟨(d³I/dt³)²⟩ = (2G/15c⁹)(E₀d²ω³)² × 1.0114

（1.0114 = ½(0.4844² + 1.25² + 0.4219²)）

| d | P | E₀/P | 一周期あたり |
|---|---|---|---|
| λ_C | **1.00 × 10⁻⁴³ W** = 6.3 × 10⁻²⁵ eV/s | 8.2 × 10²⁹ s = 2.6 × 10²² 年 | 2.5 × 10⁻⁴⁹ E₀ |
| λ_C/2 | 6.3 × 10⁻⁴⁵ W（1/16） | 4.1 × 10²³ 年 | ── |

実質的に 0 だが、厳密には 0 でない。

**置き方への依存（参考）。** 一様分布では J = (E₀d²/6) sin²θ で 2ω だけになり、⟨J⃛²⟩ は基準案の 0.225 倍。高調波の配分 11.9 / 79.1 / 9.0% は基準案に固有の数字である。

**弱点。** 四重極公式は遅い運動の近似で、ここでは β が 0.19 まで行くので 4% 程度の補正がある。応力（T^ij）の寄与と、Q3 で見た移送のエネルギー流は入れていない。高調波の取り分は置き方で変わる。

## Q6. 仮定の棚卸し

| # | 仮定 | 崩れたら |
|---|---|---|
| 1 | 系は孤立していて P = 0 | D は一定でなくてよくなり、Q2 の拘束そのものが消える |
| 2 | 核対が一体で自由に反跳できる（d は固定） | Q1 に戻り、双極子が ω, 3ω で振動する |
| 3 | 光子球の運動量は K v/c²（光速で進む光ではない） | E/c なら核に超光速が要り、破綻する（Q3 検査 2） |
| 4 | エネルギーが離れた要素のあいだを移るとき、その流れが運動量を運ぶ | 塊の運動量だけでは (E₀ωd/2c²) sin³θ が余る |
| 5 | 光子球の置き方（基準案） | 3ω の有無、最大速度、J の高調波の配分が変わる。存在・振幅・偶奇は変わらない |
| 6 | E_i に反跳の運動エネルギーを入れない（遅い運動） | 0.25〜1% の補正。偶奇の規則が保たれるかは未検証 |
| 7 | 配分 cos⁴、sin⁴、½sin² が反跳で変わらない | 反跳が配分に跳ね返れば、全体を自己整合に解き直す必要がある |
| 8 | 重力だけを考える（すべての要素が同じ結合） | 電荷が核だけに乗れば電気双極子が ω で振動する（参考値 10 W） |
| 9 | 一次元。横方向の構造なし | J の値と四重極の係数が変わる |

**最も弱いのは 2（と、その裏にある力の不在）である。** x_m(θ) は「D が一定になるように」逆算した運動で、核をそう動かす力の法則が設定に無い。Q2 が示したのは「D を一定にする運動が運動学的に可能で、亜光速である」ことまでで、「系が実際にそう動く」ことではない。運動方程式が与えられて初めて、x_m(θ) = (d/16)(9cos θ − cos 3θ) がその解かどうかを検査できる。解でなければ Q1 の振動する双極子が残る。

次に弱いのは 3 と 8。3 は「光子球」という名前と、速さ 0.03〜0.13c という結果のあいだの緊張で、8 は質量双極子の打ち消しが電磁的な放射の不在まで保証しないという点である。
