### 結果 R1–R7（付録 B と同じ）
- **R1** 光線の段から波の段への展開で、位相（HJ）と強度（群速度での連続）が分かれる。#51 の表の二つの行は、その最低二次の項に当たる。
- **R2** 群の屈折率 1/β は、エネルギーの原点をどこに取っても変わらない。物質波の位相の屈折率は、静止エネルギーを残すと β、引き去ると 2/β になる。
- **R3** 動力学的位相は往復一回でちょうど 2π 進む（ΔS_dyn = ω_ZB/ν_ZB = 2π）。したがって J = h、担い手は往復路長にちょうど一波長 λ_C を持つ。担い手は電子自身の de Broglie 波ではない（そちらは 0.0405 波長しか入らない）。ω_ZB に掛かる因子 β は、群の屈折率の逆数 ν_ZB/ν_C として読める（#51 v3 で未解決として残した点への答え）。
- **R4** ν_C をくくり出すと、包絡線はシュレディンガー方程式に従う。これは拡散係数が虚数の熱方程式で、ħ/2m = (λ_C/2)(c/2π) = 5.79×10⁻⁵ m²/s。Klein–Gordon の形は、Lorentz 共変性と静止エネルギー m_ec² から出る。
- **R5** 二層構造：外部は包絡線（連続スペクトル、幅が拡がる、Gordon 分解の対流の流れ）、内部は受け渡し（離散スペクトル、毎周期元に戻る、スピンの流れ）。Compton 尺度のシュレディンガー波束は 0.44 周期で幅が倍になるので、内部の層はシュレディンガー方程式では記述できない。
- **R6** 四次のエネルギーを a⊗a の密度（振幅について二次）と読むと、準位は +ω、0、−ω でちょうど等間隔になる。したがって二本目の線はちょうど 2ν_ZB = 41.36 keV。二つの因子が同一でなければ、線は ω_A + ω_B に移り、うなりの線 |ω_A − ω_B| が加わる。
- **R7** 内部の受け渡しで電荷の双極子が振動してはならない。振動するなら、振幅 λ_C/4 で 4.1 W を放射し、静止エネルギーを約 2×10⁻¹⁴ s で失う。

### 未解決 O1–O6
- O1 搬送波の位相を内部の位相 θ と同一視すること（R3 はこれだけに依っている）
- O2 m_ec²（したがって電子全体の分散関係）を内部の受け渡しから導くこと
- O3 a⊗a の二つの因子の正体。核の離調がうなりの線として現れるか（**幹 T6 との接点**）
- O4 Dirac の周波数を、二次の層と四次の層のどちらの線と比べるべきか（#66 の因子 2 の言い直し）
- O5 20 keV 帯のコンプトン散乱の実測から、内部共鳴の強さと幅に上限を付けること
- O6 運動量の一致が示唆する反跳閉包（幹 T4）

### 8.1 判定
| 標的 | 判定 | 要点 |

### 8.2 崩れた点・訂正すべき点
1. **R3 の「導出」**: 仮定 n_ph = n_g と最低モード N = 1 を置いたときに整合する読み、に格下げ。「The closure is not an additional assumption」は撤回。
2. **θ と θ/2**: 本文 Sec. 3 自身が振幅は cos(θ/2) で ±ω/2 と書く。搬送波の位相を θ/2 と読めば一往復で π、J = h/2。往復（libration）の Bohr–Sommerfeld の最低値は Maslov 指数で h にも h/2 にもなる。
3. **de Broglie との比較**: 有質量の搬送波 M = m_e/(γβ) ≈ 24.7 m_e は分散があるのに λ = λ_C で閉じる。比較は「質量 m_e が v_ZB で往復するなら閉じない」に限られる。#66 は電子が静止していてよいと書いており、この読みを主張した者はいない。
4. **300 行「de Broglie の読みなら 2πβ」**: ΔS_dyn の率は #51 で ω_ZB に固定され、どの読みでも 2π。2π×0.0405 は空間の位相 pL/ħ で、ΔS_dyn と J/ħ の取り違え。
5. **「ちょうど 2π」**: #51 は位相を螺旋の弧の固有時で進める。v_ZB で動く物の固有時なら 2π/γ（欠け 8.2×10⁻⁴）。τ が何の固有時かを明記する。
6. **β = 1/n_g は #66 の再述**: #66 は「ν_C は不変の速さでの搬送波の周波数、ν_ZB は群速度での周波数、比 ν_C/ν_ZB は n」と既に書いている（#66 の 374 行・521 行）。#51 v3 の未解決が求めるのは「搬送波の伝播から β を導くこと」で、本稿は満たさない。abstract・R3・Conclusion の「#51 の未解決への答え」は撤回。
7. **Sec. 4 と Sec. 8 の運動量の食い違い**: Sec. 4 は搬送波の運動量 h/λ_C = m_ec、Sec. 8 は β m_ec を「搬送波の運動量」と呼ぶ。1/β 倍ずれる。
8. **n(2ω) = n(ω)**: 閉じる条件を 2ω の線にも課すと n(2ω) = n(ω) が強制され、#66 の未解決が閉じてしまう。課さないなら、ω の線だけに課す理由が要る。
9. **R6 の「導いた」「Heisenberg と整合」**: 撤回。2ν_ZB はエネルギーの時間変化の Fourier 成分で、放射の線であることは示されていない（相互作用のない直積なら一体の演算子で 2ω は出ない）。
10. **非同一因子の線**: cos²(θ_A/2)cos²(θ_B/2) = ¼ + ¼cosθ_A + ¼cosθ_B + ⅛cos(θ_A+θ_B) + ⅛cos(θ_A−θ_B)。ω の線が ω_A と ω_B の二本に割れることが本文から抜けている。ω_A = 2ω_B なら等間隔のままなので「同一でなければ等間隔が崩れる」も厳密には誤り。
11. **表 I 最終行**: 「share の二乗が 2ω を与えるのは等間隔のときだけ」は数学的に誤り（二乗すれば常に 2ω が出る）。
12. **Sec. 7 の「試験」と「自動的」**: モデルの中では外れようのない試験になっている。どちらかに決める（「θ の一様性の試験」と書くか、試験の段落を削る）。
13. **分枝の率**: #65 は ±ω/2 の成分を二つの Dirac 分枝とする → 分枝の位相は ±ω_ZB/2。Sec. 5・表 I・#51 は「各分枝は ν_C で進む」。2/β 倍の食い違い（O4 と同根）。
14. **双極子の放射**: (4/3)e²ω⁴|r|²/c³ の |r| は行列要素で、古典の振幅は 2|r|。振幅 λ_C/4 なら 1.02 W・8.0×10⁻¹⁴ s（本文 4.1 W・2.0×10⁻¹⁴ s は 4 倍）。結論は変わらない。**444 行「1.6×10 W」は誤植（16 W）。**
15. **倍化時間 0.44**: Tν_ZB = 0.44 (a/λ_C)²。幅の規約しだいで 0.11–0.88、逆転は a ≈ 1.51 λ_C。規約を明記する。「Schrödinger 力学では再帰を供給できない」は「自由な Schrödinger 包絡線では」に限定（束縛ポテンシャルのコヒーレント状態は毎周期戻る）。
16. **Klein–Gordon**: Dirac spinor の各成分が KG を満たすのは自由場のときだけ。四元ベクトルの成立は内部に流れのある系では von Laue の条件が要り、O6（反跳の閉包）に依存。
17. **小さな点**: 「the half-separation of the round trip」は語が混乱（λ_C/2 は核間隔＝往復の半分）。包絡線近似の条件は正確には |φ̈| ≪ 4πν_C|φ̇|。Gordon 分解のスピンの項には分極の時間微分の項もある。#66 の n = 1/β は位相と群を同一視したうえで与えたもの（本文 248 行の「群の屈折率として与えた」は不正確）。
